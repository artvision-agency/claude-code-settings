## Чек-лист оценки страницы

### 1. Определение типа страницы

- [ ] YMYL (Your Money Your Life)? — здоровье, финансы, безопасность, юридические вопросы
- [ ] Информационная / транзакционная / навигационная?
- [ ] Назначение страницы понятно?

### 2. E-E-A-T (Experience, Expertise, Authoritativeness, Trust)

#### Experience (Опыт)
- [ ] Автор имеет реальный опыт в теме?
- [ ] Есть примеры из практики, кейсы, личные наблюдения?
- [ ] Контент показывает "из первых рук"?

#### Expertise (Экспертиза)
- [ ] Автор — эксперт в данной области?
- [ ] Указаны квалификации, образование, опыт?
- [ ] Контент демонстрирует глубокое понимание темы?

#### Authoritativeness (Авторитетность)
- [ ] Сайт авторитетен в данной теме?
- [ ] Есть ссылки на авторитетные источники?
- [ ] Другие авторитетные сайты ссылаются на этот контент?

#### Trust (Доверие)
- [ ] Есть контактная информация?
- [ ] Есть страница "О нас" / "О компании"?
- [ ] Политика конфиденциальности, условия использования?
- [ ] HTTPS?
- [ ] Нет признаков мошенничества/обмана?

### 3. Основной контент (ОК)

- [ ] Достаточный объем для темы?
- [ ] Высокое качество написания?
- [ ] Оригинальный (не скопированный)?
- [ ] Добавляет ценность (не просто рерайт)?
- [ ] Актуальная информация?
- [ ] Без фактических ошибок?

### 4. Структура и UX

- [ ] Логическая структура (H1 → H2 → H3)?
- [ ] Легко сканировать глазами?
- [ ] Нет отвлекающей рекламы?
- [ ] Мобильная адаптация?
- [ ] Быстрая загрузка?

### 5. Семантическая разметка

- [ ] Schema.org Article/NewsArticle?
- [ ] author, publisher, datePublished?
- [ ] FAQPage если есть Q&A?
- [ ] BreadcrumbList?
- [ ] Open Graph для соцсетей?

### 6. Признаки низкого качества (RED FLAGS)

- ❌ Автогенерированный контент без добавленной ценности
- ❌ Тонкий контент (мало информации)
- ❌ Скопированный контент
- ❌ Кликбейтный заголовок не соответствует содержанию
- ❌ Много рекламы, мало контента
- ❌ Нет информации об авторе
- ❌ Устаревшая информация
- ❌ Грамматические/орфографические ошибки
- ❌ Вводящая в заблуждение информация

## Шкала оценки (по Google)

| Оценка | Описание |
|--------|----------|
| **Highest** | Исключительно высокий E-E-A-T, авторитетный источник |
| **High** | Высокий E-E-A-T, качественный контент, хорошая репутация |
| **Medium** | Средний E-E-A-T, достаточный контент |
| **Low** | Низкий E-E-A-T, недостаточный контент, проблемы с доверием |
| **Lowest** | Вредный, обманчивый, спамный контент |

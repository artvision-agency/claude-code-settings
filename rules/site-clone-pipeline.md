## ЖЁСТКОЕ правило
Клонирование дизайна по URL — **НЕ текст-спека → frontend-агент** (теряется дизайн+картинки). Только фиксированный пайплайн ниже. ВСЕГДА с реальными картинками (перерисованными/встроенными), не эмодзи/инициалы.

## Пайплайн (по шагам)
1. **Скриншот референса** (визуальный эталон): Playwright/agent-browser fullpage 1440 + 375. Без него агент «лепит по словам».
2. **Пиксель-точный клон** проверенным GitHub-тулом («что со звёздами»):
   | Тул | ⭐ | Что даёт |
   |-----|----|----------|
   | **single-file-cli** (gildas-lormeau) | ~14k | страница → ОДИН автономный HTML, CSS+шрифты+**картинки base64**. `npx --yes single-file-cli "<url>" out.html` |
   | **monolith** (Y2Z) | ~16k | то же на Rust. `brew install monolith` → `monolith <url> -o out.html` |
   | **SingleFile** расширение | ~14k | браузерное, если нужен JS-рендер |
   | HTTrack / `wget --mirror` | — | многостраничный фолбэк |
   - Это даёт ТОЧНЫЙ дизайн оригинала (его CSS, сетка, картинки) — фундамент клона.
3. **Замена контента на наш** прямо в клонe (структура/дизайн сохраняются, меняем тексты/контакты/бренд/врачей/метрики/цены). Цены клиента — по правилам (мед → «по КТ», ФЗ-323).
4. **Картинки**: чужие фото/лица/логотипы — **обязательно убрать/заменить** на наши (этика+право!). Наши фото из сайта клиента + соцсетей → `sips -Z 800 -s formatOptions 70` → base64. URL → `assets/external-urls.yaml`.
5. **Убрать чужое**: счётчики/пиксели/аналитику оригинала (mc.yandex, gtag), ссылки на чужой домен, чужой бренд.
6. **Полировка мультимодально**: секции, где клон «грязный» (чужой инлайн-мусор) → **gemini-rescue** (видит скриншот → пересобирает чисто) или `design-extract`/`website-to-hyperframes`/`frontend-design`.
7. Деплой на review-URL, factcheck, ui-visual 320/375/768/1440.

**Обязательно ПЕРЕД деплоем клона (чеклист):**
1. **Подставить контакты клиента из `config.yaml`** (тел/адрес/email/бренд) ВЕЗДЕ — и в `tel:`-href, И в видимый текст, И в формы. Антон: «адреса/телефон наши — это должно быть учтено при инициализации». Рыба = реальные контакты клиента, не placeholder.
2. **Аудит остатков чужого** (grep по клону):
   - чужие телефоны: `grep -oE '\+?7?\(?[0-9]{3}\)?[ -]?[0-9]{3}[- ][0-9]{2}[- ][0-9]{2}'` → всё, что НЕ клиента → заменить.
   - чужие счётчики/Метрика: `grep -iE 'mc\.yandex\.ru/metrika|ym\([0-9]+|gtag\(|googletagmanager|fbq\(|vk\.com/rtrg'` → удалить/заглушить (утечка данных конкуренту).
   - чужой бренд/домен источника, placeholder-телефоны `(000) 000-00-00` (в полях ввода — норма, в тексте — заменить).
3. **Картинки**: чужие фото/до-после → заменить на реальные фото КЛИЕНТА (из его облака/соцсетей). Лендинг с чужими фото НЕ финализировать.

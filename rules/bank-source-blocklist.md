# Источники, которые НЕ работают через прямой WebFetch — сразу через альтернативы

> Прецедент: session 9f7e1adc — 5 крупных банков заблокированы для direct WebFetch. Сразу через агрегаторы экономит время.

## Заблокированные офсайты (на 19.05.2026)

| Банк / Источник | URL | Ошибка | Workaround |
|-----------------|-----|--------|------------|
| Сбербанк | sberbank.ru/* | TLS-сертификат Минцифры РФ | bankinform.ru / banki.ru. **Финальная сверка** — приложение СберОнлайн |
| Альфа-Банк | alfabank.ru/make-money/* | HTTP 403 Forbidden | banki.ru/products/deposits/?bank=alfabank + 1000bankov.ru. **Звонок 8-800-200-00-00** |
| МКБ | mkb.ru/* | SPA, JavaScript не рендерится через WebFetch | banki.ru + bankinform.ru. Mobile app |
| ВБР (отчёты) | vbr.ru/banks/* | HTTP 401 Unauthorized | banki.ru/sравни |
| Sравни.ру | sravni.ru/* | Yandex Captcha при scrape | banki.ru как альтернативу |
| Yandex Search | yandex.ru/search/* | Captcha | google.com search (через WebFetch — менее агрессивен) |
| Brobank | brobank.ru/... | HTTP 404 на некоторые продукты | 1000bankov.ru + mainfin.ru |
| Реалистанг (страницы продуктов) | Многие банки | URL 404 / SPA | finuslugi.ru — официальный портал ЦБ для сравнения |

## Источники-агрегаторы (работают через WebFetch)

| Источник | Что хорошо | Что плохо |
|----------|------------|-----------|
| **banki.ru** | каталог продуктов + ставки + калькулятор | данные могут отставать на 1-7 дней |
| **finuslugi.ru** | официальный портал ЦБ — полу-официально | покрытие меньше banki.ru |
| **bankinform.ru** | новостные обновления — точная дата изменения ставки | не каталог, нужно искать |
| **1000bankov.ru** | детальные карточки продуктов | покрытие средне |
| **mainfin.ru** | каталог + обзоры | редко обновляется |
| **vbr.ru/help/novosti** | новости о снижениях/повышениях ставок | реклама в выдаче |
| **moex.com** | ОФЗ direct (всегда работает) | только биржевые инструменты |
| **cbr.ru** | ключ ЦБ, АСВ, нормативка | не банковские продукты |

## Workflow для заблокированных банков

1. **Сначала** — попробовать WebFetch офсайт. Если 403/404/JS-блок → сразу к шагу 2.
2. **Затем** — WebFetch banki.ru каталог + bankinform.ru новости + 1000bankov.ru карточка.
3. **Проверка свежести** — bankinform даёт дату изменения. Если >7 дней — добавить пометку UNCONFIRMED.
4. **Финальная сверка** — для критичных решений Антон сверяет в мобильном приложении при открытии счёта.

## Что НЕ работает как замена

- **Скриншоты в TG-каналах** — не источник, может быть фейк
- **Reddit / vc.ru обсуждения** — не источник конкретных ставок
- **Старые статьи >30 дней** — устаревшая информация о ставках
- **Маркетинговые баннеры** — часто показывают «до X%» без условий

## Workaround при критичных запросах

Если нужны точные данные на сегодня:
1. **Звонок в банк** — единственный 100%-надёжный способ
   - Сбер: 900
   - Альфа: 8-800-200-00-00
   - ВТБ: 1000
   - МКБ: 8-800-100-48-88
   - Газпром: 8-800-100-07-01
   - МТС Банк: 8-800-250-05-20
2. **Мобильное приложение банка** — показывает ставки для конкретного пользователя с учётом его статуса (зарплатный, премиум)
3. **Личный кабинет** — если уже клиент банка

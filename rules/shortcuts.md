# Быстрые команды

Антон и Андрей используют короткие команды и опечатки. Ключевые:
- го/da/uj = подтверждение, делай
- синк/sync = /sync-sessions
- туду = показать TODO
- рой/swarm/пара = параллельные агенты
- комбайн = /combine
- деплой = scp + pm2 restart на VPS
- конс = /cons стратсессия

Полный словарь опечаток и сокращений: skill `shorthand`.
Контексты клиентов (варикоз, творим, блумарт и т.д.): skill `shorthand`.

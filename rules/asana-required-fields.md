# Asana — обязательные поля при создании задачи

> ЖЁСТКОЕ ПРАВИЛО: задача СОЗДАЁТСЯ сразу, но если не заполнены обязательные поля — ТРЕБОВАТЬ от постановщика дозаполнить.

## Обязательные поля

| Поле | Параметр | Что проверять |
|------|----------|---------------|
| **Ответственный** | `assignee` | Кто делает? (Андрей, Антон, Стас) |
| **Дедлайн** | `due_on` | Когда крайний срок? (конкретная дата YYYY-MM-DD) |
| **Проект** | `project_id` | В какой проект? (Творим, BluMart, и т.д.) |

## Алгоритм

1. Пользователь даёт задачу для Asana
2. **Создать задачу сразу** с тем что есть (автоопределить из контекста если возможно)
3. Проверить: все 3 поля заполнены?
4. **Если чего-то не хватает** → ТРЕБОВАТЬ у постановщика:

```
Задача создана, но не хватает:
- [ ] Ответственный — кто делает?
- [ ] Дедлайн — до какого числа?
- [ ] Проект — в какой проект?
Заполни — обновлю задачу.
```

5. После получения данных → обновить задачу в Asana
6. Автоопределение допустимо если контекст однозначный (упомянут проект/человек)

## Примеры

**Плохо:** "задача — сделать отчёт" → создать молча без assignee и due_on
**Хорошо:** "задача — сделать отчёт" → создать + "Не хватает: ответственный, дедлайн, проект"

**Автоопределение ОК:** "задача Андрею по Творим — API до среды" → все 3 поля есть, создаём молча

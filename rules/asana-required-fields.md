# Asana — обязательные поля при создании задачи

> ЖЁСТКОЕ ПРАВИЛО: задача СОЗДАЁТСЯ сразу, но если не заполнены обязательные поля — ТРЕБОВАТЬ от постановщика дозаполнить.

## Обязательные поля

| Поле | Параметр | Что проверять |
|------|----------|---------------|
| **Ответственный** | `assignee` | Кто делает? (Андрей, Антон, Стас) |
| **Дедлайн** | `due_on` | Когда крайний срок? (конкретная дата YYYY-MM-DD) |
| **Проект** | `project_id` | В какой проект? (Творим, BluMart, и т.д.) |

## Алгоритм

1. Пользователь даёт задачу для Asana
2. **Создать задачу сразу** с тем что есть
3. Извлечь поля по алгоритму:

| Поле | Если ЯВНО указано | Если НЕ указано |
|------|-------------------|-----------------|
| `assignee` | Поставить (только явное: «Андрею», «Стас сделай») | Создать БЕЗ assignee, спросить «Кто исполнитель?» |
| `project_id` | По упоминанию клиента/проекта | Спросить «В какой проект?» |
| `due_on` | По смыслу из текста (см. ниже) | Если в тексте нет про сроки — спросить ОДИН раз «Когда?». Если задача явно «когда-нибудь / при возможности» — БЕЗ due_on |

### Извлечение due_on по смыслу (правило C, см. memory `feedback_no_invented_deadlines`)

| Текст | due_on |
|-------|--------|
| Конкретная дата («до 5 мая», «к 15.05») | Эта дата |
| Относительный срок («до пятницы», «завтра», «через неделю») | Извлечь и поставить |
| Срочно («сегодня», «горит», «срочно») | today |
| Без срочности («когда-нибудь», «при возможности», «потом») | БЕЗ due_on |
| Ничего про срок | Создать + спросить «Когда?» |

**ЗАПРЕТ:** не ставить «дефолт пятница» автоматически (старое правило отменено — даёт overdue-мусор).

4. После получения недостающих данных → обновить задачу в Asana

## ЗАПРЕТ автоназначения исполнителя (с 30.04.2026)

> Прецедент: голосовое Антона 30.04 — «Не надо ставить Андрея постоянно исполнителем. Я назначу его исполнителем, если надо.»

**Claude НЕ назначает assignee автоматически.** Только если:
- Пользователь **явно** указал исполнителя в тексте задачи («задача Андрею», «Стас сделай»)
- Задача — self-assign (пользователь ставит себе)

Если assignee не указан — создать задачу БЕЗ assignee и спросить: «Кто исполнитель?»

**Запрещено:** угадывать исполнителя по типу задачи, по клиенту, по истории. Только явное указание.

## Примеры

**Плохо:** "задача — сделать отчёт" → создать молча без assignee и due_on
**Хорошо:** "задача — сделать отчёт" → создать + "Не хватает: ответственный, дедлайн, проект"

**Автоопределение ОК:** "задача Андрею по Творим — API до среды" → все 3 поля есть, создаём молча

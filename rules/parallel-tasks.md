# Параллельное выполнение задач

## Правило: 4+ задач в TODO → параллельные агенты

При наличии **4 и более** pending задач в TODO.md текущего контекста:
- Запускать **параллельных агентов** (Agent tool с `run_in_background: true`)
- Группировать независимые задачи и запускать одновременно
- НЕ ждать завершения одного агента перед запуском следующего
- Максимум 3-4 агента одновременно (баланс скорость/стоимость)

## Исключения (НЕ параллелить)

- Задачи с зависимостями (одна блокирует другую)
- Задачи требующие подтверждения пользователя (CONFIRM-уровень)
- Задачи на один и тот же файл/модуль (конфликт записи)

## Порядок приоритетов при параллельном запуске

1. Revenue-задачи (КП, клиенты, продажи)
2. Продуктовые задачи (код, скрипты, MVP)
3. Инфраструктурные (мониторинг, деплой)
4. Документация и cleanup

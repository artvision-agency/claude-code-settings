# Структуры в документах = СПИСКИ, не деревья и не таблицы

> **ЖЁСТКОЕ ПРАВИЛО** Антона. Загружается во ВСЕ мои сессии. Не зависит от моей памяти.
> **Установлено:** 2026-05-13 (сессия DENTIX 4f6bcd4c). Повтор правила «много раз», поэтому переведено в hard-enforce.

## Правило

Любая **структура** (заголовки, секции, URL-tree, иерархия H1-H6, оглавление, навигация, пункты плана) в документах для Антона и клиентов выводится **СПИСКАМИ** (`<ul>` / `<ol>` в HTML, `-` / `1.` в Markdown).

## Что считается СТРУКТУРОЙ (= обязательно список)

| Содержимое | Формат |
|------------|--------|
| Иерархия H1-H6 страницы | `<ul>` вложенный |
| URL-tree сайта | `<ul>` с вложенностью |
| Пункты плана / этапов | `<ol>` нумерованный |
| Секции главной с пометками (KEEP/EDIT/ADD) | `<ul>` |
| Структура внутренних страниц | `<ul>` |
| Чек-лист требований | `<ul>` с чекбоксами |

## Что НЕ структура (можно таблица/код)

- **Сравнения** (мы vs конкурент vs клиент) — таблица OK
- **Числовые данные** (цены, метрики) — таблица OK
- **Код / JSON / YAML** — code block OK
- **Картинки/макеты** — изображения OK

## ❌ Анти-паттерны (нельзя)

| Анти-паттерн | Почему запрет |
|--------------|----------------|
| `<div class="h-tree">` с цветными `<span class="h1/h2/h3">` | Это не список, это раскрашенный текст — не парсится глазом как иерархия |
| ASCII-tree (`├── H2:` / `│   ├── H3:`) | Хорошо в терминале, плохо в HTML/PDF |
| Таблица «уровень / название / комментарий» для иерархии H1-H6 | Уровни не очевидны, надо считать колонку |
| Bullet списком БЕЗ вложенности (`H2: ...` / `H3: ...` на одном уровне) | Теряется иерархия |

## ✅ Правильный паттерн (HTML)

```html
<ol class="page-structure">
  <li><strong>H1:</strong> Стоматология Дентикс в СПб
    <ul>
      <li><strong>H2:</strong> Конкурентный разрыв <span class="tag tag-crit">CRIT</span></li>
      <li><strong>H2:</strong> Услуги клиники
        <ul>
          <li><strong>H3:</strong> Здоровье зубов</li>
          <li><strong>H3:</strong> Красота улыбки</li>
          <li><strong>H3:</strong> Если зуб болит</li>
        </ul>
      </li>
      <li><strong>H2:</strong> Лицензии и сертификаты</li>
    </ul>
  </li>
</ol>
```

## ✅ Правильный паттерн (Markdown)

```markdown
1. **Главная** — `https://dentix.ru/`
   - **H1:** Стоматология Дентикс в СПб
   - **H2:** Конкурентный разрыв
   - **H2:** Услуги клиники
     - **H3:** Здоровье зубов
     - **H3:** Красота улыбки
   - **H2:** Лицензии
2. **О компании** — `https://dentix.ru/o-klinike/`
   - **H1:** ...
```

# Tool Adoption — Social Proof обязателен

> Перед внедрением ЛЮБОГО внешнего инструмента/скилла/продукта (Obsidian, Notion, новый MCP, SaaS, библиотека) — обязательная объективная проверка.
> Причина: Claude предвзят к своим реализациям ("NIH bias"). Один голос ≠ решение.

## Когда срабатывает

Любой из триггеров:
- Пользователь предлагает новый инструмент ("а давай поставим X?")
- Claude рекомендует новый инструмент/скилл
- Сравнение "наше решение vs внешний продукт"
- Решение о замене существующего инструмента

## Протокол (ОБЯЗАТЕЛЬНО до внедрения)

### Шаг 1. Round Table через llm-consilium (2-3 внешние модели)

```
mcp__llm-consilium__round_table с моделями: llama,kimi-k2,qwen3
Промпт формата:
  - Что даёт инструмент X сверх текущей системы Y?
  - Риски/издержки?
  - Вердикт: внедрять / не внедрять / условно?
```

Результат = первичный внешний голос, не замутнённый мнением Claude.

### Шаг 2. Фиксация в hypotheses.md

Создать запись в `knowledge/<domain>/hypotheses.md`:
```markdown
## Hn: Внедрить X для Y
- **Source:** round_table 2026-MM-DD
- **Verdict (round_table):** внедрить / не внедрять / условно
- **Confirmations:** 0/3
- **Test plan:** какой кейс проверит гипотезу
```

### Шаг 3. 3 подтверждения до промоушена в rule

Каждое использование/отказ в реальной задаче = +1 confirmation.
После 3 подтверждений — переносится в `rules.md` как зафиксированное правило.

## Формат ответа пользователю

Когда триггер сработал — ответить структурно:

```
## Вердикт round_table: [ВНЕДРЯТЬ / НЕ ВНЕДРЯТЬ / УСЛОВНО]

| Критерий | Что даёт X | Есть у нас |
|----------|------------|------------|
| ...      | ...        | ...        |

**Уверенность:** HIGH / MEDIUM / LOW
**Условие пересмотра:** <когда вернуться к вопросу>
```

## Что НЕ требует round_table

- Разовые CLI-утилиты (grep, jq, curl) — стандарт
- Claude-скиллы из superpowers — уже проверены
- Локальные скрипты <50 строк — не инструмент, а код

## Анти-паттерны

| ❌ | ✅ |
|---|---|
| "Opsidian хорош, внедрим" | Round table → вердикт → запись в hypotheses |
| "У нас лучше, не нужно" | Опровергнуть объективно через round_table |
| Одно мнение Claude = решение | Минимум 2 внешних модели |
| Внедрить → забыть зафиксировать | Каждое решение в hypotheses.md |

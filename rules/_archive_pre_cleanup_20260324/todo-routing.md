# TODO-маршрутизация по контексту

## 5 контекстов = 5 TODO-файлов

| Контекст | Триггеры | TODO файл |
|----------|----------|-----------|
| **ops** | брифинг, отчёт, операционка, план | `artvision-data/TODO.md` |
| **bot** | бот, telegram, tvorim, flow | `artvision-tg-bot/TODO.md` |
| **infra** | vps, сервер, деплой, мониторинг | `devops-agent/TODO.md` |
| **presale** | кп, клиент, продажи, presale, лид | `artvision-data/presale/TODO.md` |
| **products** | продукт, aivision, разработка, mvp | `artvision-data/products/TODO.md` |

## Правила

1. **Начало КАЖДОЙ сессии (ОБЯЗАТЕЛЬНО):**
   - `git pull` + прочитать **`artvision-data/PROJECTS.md`** (source of truth, единый обзор)
   - Прочитать TODO.md текущего проекта (по cwd) для детализации
   - **ПОКАЗАТЬ пользователю** все `>>` действия из PROJECTS.md + открытые `[ ]` задачи
   - Создать TaskCreate для каждой pending задачи
   - Это НЕ опционально — делать ВСЕГДА, даже если пользователь не просит
   - **Проактивно запрашивать выполнение:** "По [проекту] следующий шаг — [>>]. Делаем?"
2. **Новая задача:** добавить в нужный TODO по контексту
3. **Завершение:** переместить в секцию "Завершено" с `[x]`
4. **Кросс-проект:** если задача не для текущего контекста — записать в нужный TODO, не в текущий
5. **Команда "туду":** показать задачи ТЕКУЩЕГО контекста (по cwd или последнему упоминанию)
6. **Конец сессии:** `git add TODO*.md && git commit && git push` — чтобы другой аккаунт видел

## Синхронизация между аккаунтами (justtrance / adw.artvision.pro)

TODO.md файлы живут В GIT → видны обоим аккаунтам через `git pull`.

**Протокол:**
- Начало сессии: `git pull` подтягивает чужие изменения в TODO
- Конец сессии: коммит + push обновлённых TODO
- Конфликт: merge вручную (секции по клиентам не пересекаются)

**Session Task tool** — эфемерный, только для текущего окна.
При старте Claude читает TODO.md → создаёт TaskCreate для pending задач.
При завершении → обновляет TODO.md из состояния задач.

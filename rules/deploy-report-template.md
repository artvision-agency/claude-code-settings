# Deploy Report — обязательный отчёт после публикации документа клиента

> **Триггер:** любой deploy документа клиента (КП, лендинг, презентация, отчёт) — `scp` на VPS, `git push` в клиентский репо, публикация на artvision.pro/kp/*.
> **Цель:** Антон видит явно, какие инструменты отработали, а какие — пропущены, и может решить стоит ли довесить.

## Обязательные блоки отчёта

### 1. Шапка
- Документ: <путь локально>
- Live URL: <с HTTP статусом>
- Размер: HTML N KB, media M MB
- Версия / что сделано в этом заходе (1–2 строки)

### 2. Таблица инструментов (ВСЕГДА)

> **HARD-RULE (поднято из memory 2026-05-28):** каждая ячейка «✅ Прошёл / ❌ Не прошёл / Результат» обязана иметь **источник** в той же строке: путь к логу, команда + stdout, git commit hash, или строка в context-log.md. Без источника → пиши `❓ не проверено` или `UNCONFIRMED`, не «прошёл».
>
> **Прецедент:** Madwave 02.05.2026 — я выдумал что `pre-scp-factcheck.sh ➖ Прошёл` и `post-client-html-validate.sh ➖ Прошёл`. На самом деле хуки не запускались (прямой scp), записей нет. Антон поймал.

### 3. Блок «Что НЕ применялось и почему»
Для каждого `❌` — одна строка:
- **<инструмент>** — причина (нерелевантно / пропущено ради скорости / технически недоступно / задача была правка, не создание)

### 4. Блок «Что стоит добавить»
Рекомендации следующего шага. Например: «перед отправкой клиенту прогнать factcheck-v2.py», «снять Playwright-скриншоты с реального viewport».

## Когда отчёт НЕ нужен
- Правка меньше 3 Edit-операций (опечатка, цена, контакт)
- Внутренние заметки, черновики в `_drafts/`
- Технический деплой не-клиентского контента (статик, assets, дашборды для себя)

## Формат в ответе пользователю
Таблица + 2 коротких блока (3 и 4). Не расписывать подробно — одна строка на пункт.

## Связка со скиллом /presale-kp
Если документ — КП / лендинг клиента, и скилл **НЕ** был явно вызван: в отчёте ПЕРВЫМ пунктом пометить `❌ /presale-kp не вызывался` и дать подсказку: «Для нового документа с нуля вызови `/presale-kp <url>` — отработает все 9 шагов автоматически».

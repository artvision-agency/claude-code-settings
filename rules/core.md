# Artvision — Core Rules

Автономный режим: получил цель → разбей на шаги → выполни. Короткие сообщения = команды.
4+ независимых задач → параллельные агенты (Agent tool, макс 3-4).
Язык: русский. Ответы: кратко, таблицами, без воды.

## Обязательные skills по задаче

Перед работой — вызвать Skill tool: КП → `presale-kp`, SEO → `seo-master`, контент → `content-writer`, бот-деплой → `telegram-bot-deployment`, код-ревью → `code-audit`, CRO → `cro`. Скилл = ПЕРВЫЙ шаг.

## Данные

Числа в документы клиента — только с источником и перекрёстной проверкой (2+ источника).
Спарсенные данные — указывать дату + источник. HTML-документы — TOC в начале.

## Поиск перед вопросом

Прежде чем спрашивать — grep по ~/artvision-data/, git log, clients/, tokens.json, Asana. Спрашивать только если все проверки пусты.

## Массовые операции (>5 файлов)

dry-run → бэкап → 1-2 файла → проверка → остальные. Удалено >20% = ALERT.

## VPS

Код на VPS — только через git → deploy script. Прямое редактирование на VPS запрещено.
После деплоя бота — 5 мин мониторинг логов. 3+ рестарта = алерт.

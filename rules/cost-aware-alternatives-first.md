## Правило (DEFAULT — всегда)
Когда задача требует РЕСУРСА со стоимостью (платный API, наша квота, токены, деньги, время) — в ПЕРВОМ же предложении дать **спектр вариантов от дешёвого к дорогому**, а не сразу самый дорогой/нашу квоту:

1. **Уже собрано / кэш** — переиспользовать существующие данные (grep по проекту: `*serp*`, `*cache*`, прошлые выгрузки). Ноль стоимости.
2. **Бесплатные инструменты** (сами делают работу) — Coolakov (SERP-кластеризация Яндекс, free), SeoQuick, open-source, наши скрипты.
3. **Баланс КЛИЕНТА / его аккаунты** — Arsenkin, его SEMrush/keys.so, его кабинеты (не наша квота).
4. **Наш платный API / квота** — Яндекс Cloud Search, DataForSEO, OpenAI и т.п. — ТОЛЬКО как явный последний вариант, с пометкой стоимости.

**Формат:** таблица/список «вариант · стоимость для НАС · качество · возня» + рекомендация. Антон выбирает. Никогда не подавать «наша квота» как единственный/первый путь, если есть free/client-balance альтернатива.

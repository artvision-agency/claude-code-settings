# Расчёты в документах клиентам — всегда с источником, датой и автором

> **HARD-RULE** Антона 2026-05-20 (сессия DEGA).
> Применяется ко ВСЕМ числам в КП, аудитах, отчётах, дашбордах, ТЗ.
> Связано: `~/artvision-data/.claude/rules/factcheck.md`, `~/.claude/rules/quality.md`, `feedback_deploy_report_cite_sources.md`.

## Главное правило

Каждое число / расчёт / процент / денежная сумма / частотность / рейтинг / позиция в видимом тексте документа клиенту **обязано** иметь три атрибута:

1. **Источник** — конкретный URL или название инструмента
2. **Дата сбора** — день/месяц/год когда данные получены
3. **Автор** — кто провёл замер (всегда = Artvision / artvision.pro)

## Форматы

### A. Блок «Методология и источники» в конце документа (обязательно)

```html
<section class="sources">
  <h2>Методология и источники</h2>
  <p>Аудит проведён командой <strong>Artvision</strong> (artvision.pro) <strong>20 мая 2026 года</strong>. Все цифры в документе получены из следующих источников:</p>
  <ul>
    <li><strong>Позиции в Яндексе СПб</strong> — проект «dega-clinic.com СПб» в Topvisor, выгрузка от 20.05.2026, 4 даты замера: 11.04.2025 / 17.04.2025 / 16.09.2025 / 20.05.2026.</li>
    <li><strong>Прайс DEGA</strong> — <code>dega-clinic.com/price/</code>, получено 20.05.2026.</li>
    <li><strong>Lighthouse</strong> — <code>pagespeed.web.dev/analysis/https-dega-clinic-com/</code>, замер 20.05.2026, mobile + desktop.</li>
    <li><strong>Sitemap.xml</strong> — <code>dega-clinic.com/sitemap-ru-0.xml</code>, выгружено 20.05.2026.</li>
    <li><strong>Рейтинги каталогов</strong> — ProDoctorov.ru/lpu/48473, yandex.ru/maps/org/dega/63615171730, 2GIS, DocTu, НаПоправку — все проверены 20.05.2026.</li>
    <li><strong>SERP-анализ конкурентов</strong> (МЕДИ, ForMe, Галактика, MedSwiss) — ручной анализ выдачи Яндекс СПб от 20.05.2026.</li>
    <li><strong>Отраслевые CTR по позициям</strong> — Backlinko CTR Study (backlinko.com/google-ctr-stats), SISTRIX Index (sistrix.com/blog/why-almost-everything-you-knew-about-google-ctr-is-no-longer-valid).</li>
    <li><strong>Wordstat частотности</strong> — wordstat.yandex.ru, регион Санкт-Петербург, апрель–май 2026.</li>
  </ul>
</section>
```

### B. Inline-сноски `<sup>N</sup>` на ключевые числа

```html
<p>≈ 4 млн ₽ упущенной выручки в&nbsp;месяц<sup>1</sup></p>
<!-- ... -->
<p><sup>1</sup> Расчёт: средний чек DEGA × конверсия лидов × прогноз дельты трафика при выходе в ТОП-3. Источники см. в разделе «Методология».</p>
```

### C. Дисклеймер для оценочных чисел

Если число — **прогноз/оценка/моделирование** (а не замер): обязательная метка «оценочно», «целевой ориентир», «по отраслевым бенчмаркам». Не «гарантировано N%».

## Чек-лист перед отправкой клиенту

- [ ] Каждое число имеет источник (URL или название tool)?
- [ ] Каждая выгрузка имеет дату?
- [ ] Указано что аудит проведён Artvision (artvision.pro)?
- [ ] Прогнозы помечены как «оценочно / целевой ориентир»?
- [ ] Блок «Методология и источники» есть в документе?
- [ ] Нет «магических» процентов без обоснования («обычно», «в среднем», «как правило»)?

## Что считается «числом» (требует источника)

- Денежные суммы (₽, USD, EUR)
- Проценты (CTR, конверсия, доля рынка, прирост)
- Частотности (Wordstat показы/мес)
- Позиции в выдаче (1-100)
- Рейтинги и количество отзывов на каталогах
- Кол-во страниц / URL / документов
- Lighthouse-метрики (Performance, LCP, CLS)
- Доли видимости (% запросов в ТОП-10)
- Сроки (3/6/12 месяцев — допустимо без источника, но прирост за период требует обоснования)

## Что НЕ требует источника

- Год основания клиника (берётся из ЕГРЮЛ — указать ОДИН раз в блоке источников)
- Названия услуг (общеотраслевая терминология)
- Цены Artvision (наши собственные)

## Антипаттерны

- ❌ «Обычно конкуренты получают 30-40% доп. трафика» — без источника = магия
- ❌ «Lighthouse mobile 91» без указания даты замера и URL PSI
- ❌ «980 отзывов на ПроДокторов» без URL и даты (рейтинг живой, на завтра уже 985)
- ❌ «По нашим данным» — какие данные, чьи, когда собраны?
- ❌ «Прирост трафика +18-25%» без обоснования (на чём основан прогноз)
- ❌ «4 млн ₽ упущено» без раскрытия методики расчёта

# КП/документы клиенту: реальные скриншоты узнаваемых сервисов вместо рисованного (HARD, DEFAULT ON)

> **Установлено:** 2026-06-26 (Антон, DS-Lab КП, повторил 2×). Дословно: «Нужно больше интерфейсов, скриншотов, узнаваемых сервисов, а не просто рисования. Люди уже работали с сервисами — у них будет проще восприятие. Если данные взяты из сервиса либо из выдачи — показывай скриншот, меньше рисованного.»
> **Связано:** `calculations-need-sources.md` (скриншот = доказательство источника), `visual-content-not-just-ratio.md`, `feedback_deploy_report_cite_sources`, `document-structure-general-to-specific.md`, `html-clients.md` (base64-автономность), `kp-brand.md`.

## Принцип (применять ко ВСЕМ клиентским документам: КП, аудиты, отчёты)
Если данные/вывод взяты **из сервиса или из поисковой выдачи** — показывать **реальный скриншот интерфейса этого сервиса / выдачи**, а НЕ перерисованную CSS-диаграмму. Узнаваемый интерфейс (Wordstat, выдача Яндекса/Google, PageSpeed, дашборд позиций, карта) люди уже видели → быстрее и доверчивее воспринимают. Рисованное (CSS-круги, бары, схемы) — по минимуму.

## Правила
1. **Число/факт из сервиса → скриншот сервиса рядом.** Частотность → скрин Wordstat. «Конкуренты выше вас» → скрин выдачи Яндекса. Скорость → скрин PageSpeed. Позиции → скрин дашборда/Вебмастера. Видимость/конкуренты → наш собранный визуал-отчёт (если из наших инструментов).
2. **Скриншот = доказательство (calculations-need-sources).** Подпись под скрином: что за сервис + дата снятия + (для клиента — наш бренд/«данные Artvision», без светки сторонних тулов где запрещено — kp-brand). В КП раскрытие источника обязательно.
3. **Рисованное (CSS) допустимо ТОЛЬКО когда:** реального скрина нет; ИЛИ это концептуальная СХЕМА (сегментная схема, воронка, план-этапы) — там рисунок уместен. Метрики/данные/сравнения из сервисов — скрин, не рисунок.
4. **Технически (html-clients):** скрин встраивать base64 (автономность, 0 внешних URL), оптимизировать (`sips -Z 1000 -s formatOptions 60`, <120KB), кликабельный lightbox на полный размер.
5. **Если нужного скрина нет** — снять: наш дашборд/отчёт (есть в `clients/<slug>/seo/`), либо браузером выдачу/сервис (⚠️ Яндекс-выдача = captcha-риск, `scraping.md`; снимать с VPS/через наш визуал-отчёт). Не выдумывать «как бы скрин».

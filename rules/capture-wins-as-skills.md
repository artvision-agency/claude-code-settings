> **Установлено:** 2026-06-12 (Антон). Источник: совет автора канала «ИИзнанка» (t.me/prompt_design/1953, пересл. в Artvision Portal 14:02) + пост про Skill Creator (t.me/prompt_design/1978).
> **Совет дословно:** «Каждый раз, когда модель делает что-то ДЕЙСТВИТЕЛЬНО КРУТОЕ — просите упаковать это в навык как **Agent Skill**, и он останется у вас и после того, как закроется бесплатное окно [Fable 5 free до 22.06.2026]».
> **Зачем:** новые моменты/находки, которые получились в работе, — фиксировать в скиллы, чтобы применялись потом автоматически, без повторного промпта и без потери при смене модели/закрытии окна.
> **Связано:** `/умнею` (`umneyu` — ловит ОШИБКИ→правило), это правило — **зеркало для УСПЕХОВ→скилл**; `/skill-generator`, `superpowers:writing-skills`, `model-bakeoff.md` (измерение качества), `tool-adoption-proof.md` (round_table перед adopt Skill Creator), `bulletproof-patterns.md`, `cherny-tips.md` #1 (mistake-log).

## Принцип (DEFAULT — почти всегда)

У нас есть петля для ОШИБОК (`/умнею` → правило/хук/memory). Нет петли для УСПЕХОВ. Это правило закрывает GAP: **когда модель (Claude/Fable/любая) выдала что-то реально крутое/новое/работающее — СРАЗУ предложить/упаковать это в Agent Skill** (или правило/воркфлоу), чтобы осталось навсегда и переиспользовалось.

«Крутое» = воспроизводимая ценность, не разовый ответ:
- рабочая техника/метод (как решили нетривиальную задачу),
- сильный паттерн артефакта (структура КП/дашборда/промпта, которая зашла),
- удачный пайплайн/последовательность вызовов,
- найденный надёжный рецепт API/инструмента (endpoint, обход бага),
- стиль/голос, попадающий в бренд (как в примере: пост-райтер 41%→94% попадания в стиль).

## Когда захватывать (триггеры)
- Антон сказал «вот это круто / то что нужно / так и делай / запомни этот подход».
- Я сам вижу, что выданное решение — повторяемо и сильнее обычного (mindset-huang #1: превентивно, до просьбы).
- Fable 5 (или другая модель) в бесплатном окне выдала что-то качественное → **успеть упаковать ДО закрытия окна** (Fable 5 free до 22.06.2026, потом только API $50/1M out — вдвое дороже Opus).

## Когда НЕ захватывать
- Разовый ответ без переиспользования · тривиальная правка · уже покрыто существующим скиллом/правилом (grep перед созданием — `no-false-negative`, `task-instruction-coverage`).
- Это ОШИБКА/коррекция → туда `/умнею` (другая петля), не сюда.

## Как упаковывать (по возрастанию веса)
1. **Принцип/запрет/стандарт** → правило в `~/.claude/rules/` (или `artvision-data/.claude/rules/` если только Артвижн).
2. **Повторяемый процесс с шагами** → **скилл** через `/skill-generator` (или `superpowers:writing-skills`).
3. **Детерминированный многошаговый процесс** → named workflow `.claude/workflows/*.js` (ось #1 `orchestration-method-selection`).
4. **Подпись автора** (PROVENANCE, `model-bakeoff`): в скилле/правиле — какой моделью/в какой сессии находка получена (для лидерборда и выбора).

## Измерять качество скилла (метод Skill Creator — закрепить как стандарт)
Из поста 1978: Anthropic **Skill Creator** (мета-навык: создаёт скиллы + гонит тесты/бенчмарки + слепое A/B версий). Пример: без скилла Опус попадал в стиль 41%, со скиллом 94% — **числа, не «вроде похоже»**.
- Применять принцип к нашим скиллам: где возможно — давать скиллу **тест/бенчмарк** (вход → ожидаемый критерий) + слепое сравнение «с скиллом / без» (стыкуется с `model-bakeoff` self-оценкой и `eval-harness`).
- **Skill Creator = кандидат на adopt** (официальный Anthropic: `anthropics/skills/skills/skill-creator` + `claude-plugins-official/plugins/skill-creator`). Перед внедрением vs наш `/skill-generator` — **round_table** (`tool-adoption-proof.md`) + ОК Антона. Не adopt'ить молча. Главная ценность кандидата = test/benchmark/blind-A/B (у нашего `/skill-generator` этого нет).

## Принцип (HARD)
В любой задаче, где смешаны **точные данные (числа/цены/коды/координаты/даты/единицы)** и **смыслы (текст/перевод/классификация/УТП)** — разделять обработку:
- **Числа и точные токены → детерминированным кодом** (regex/парсер/CSS-селектор/арифметика/сверка), НЕ доверять выводу LLM.
- **Смыслы → нейросеть** (перевод, переформулировка, извлечение сути, классификация).

**Корень:** LLM теряет/искажает числа даже при идеальном смысле (прецедент: перевод datasheet — модель потеряла 2-11 чисел из 132 при верном тексте). Число «прошло через» нейросеть = по умолчанию **UNCONFIRMED**, пока не сверено кодом.

## Рабочие рецепты (из практики Fable, переиспользовать)
1. **Перевод/рерайт документа с числами** → **mask-numbers**: до LLM заменить числа на плейсхолдеры → перевести смысл (T=0, glossary-lock) → вернуть числа из оригинала → **pofilter-gate** (детерминированная сверка что все числа на месте). Числа НЕ проходят через модель.
2. **Скрейп цен/характеристик с сайта** → цены/числа тянуть **CSS-селектором/regex без LLM**; УТП/описание — LLM (+Pydantic-схема). Каждое поле: `source_url` + `checked_at`.
3. **Расчёты (финансы/ROI/прогноз)** → арифметика кодом, не «в уме модели»; сверка по периодам (welcome-vs-base-math); 2+ источника (calculations-need-sources).
4. **Координаты/гео/коды** → reverse-geocode/валидатор, не доверять сгенерённому (rootcause-fix-template фактчек парсинга).

## Чеклист (где есть и числа, и смыслы)
- [ ] Числа/цены/коды извлечены/перенесены ДЕТЕРМИНИРОВАННО (regex/CSS/парсер/арифметика), не выводом LLM
- [ ] Если данные «прошли через» LLM (перевод/суммаризация) — есть код-сверка что числа целы (gate)
- [ ] Каждое число — source + дата (calculations-need-sources)
- [ ] Смысловая часть — отдельным проходом LLM (не смешивать с числами в одном вызове где числа критичны)

## Антипаттерны
- ❌ Доверять числам, которые LLM «перевела/пересказала/извлекла» без код-сверки (теряет/искажает молча).
- ❌ Скрейпить цену запросом к LLM «найди цену на странице» вместо CSS-селектора.
- ❌ Считать ROI/проценты «прикидкой модели» вместо арифметики кодом.
- ❌ Число из парсинга/генерации = факт без проверки другим методом (rootcause-fix-template).

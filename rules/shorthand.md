# Словарь коротких команд (Антон + Андрей)

## Команды-действия (1-2 слова = ДЕЛАЙ)

| Пишут | Значит |
|-------|--------|
| го / go | Выполняй, подтверждаю, продолжай |
| да / da | Подтверждение, согласие |
| деплой | Задеплоить на VPS (scp + pm2 restart) |
| ссы / ссылка | Покажи URL / дай ссылку |
| синк / sync | git pull + push все репо |
| пуш | git push |
| рой / swarm | Запусти параллельных агентов |
| туду / тудуго | Покажи TODO / покажи и делай |
| чисть / почисти | Удали мусор, дубли, лишнее |
| стоп / stop | Прекратить текущее действие |

## Формат документов

# ЗАПРЕТ сглаживания углов

> Это правило загружается КАЖДУЮ сессию. Нарушение = потеря доверия Антона.

## Запрещённые паттерны

| Сглаживание | Честный вариант |
|-------------|-----------------|
| "контекст не потерян" | "после компактинга потеряны: [конкретно что]" |
| "собирает данные" (когда агент фейлит) | "агент не получил данных, потому что [причина]" |
| "частично реализовано" | "не сделано: [что именно], сделано: [что именно]" |
| "предположительно" | "не знаю, нужно проверить" |
| "в целом всё работает" | "[что работает], [что НЕ работает]" |
| "скоро будет готово" | "осталось [N] шагов, текущий блокер: [что]" |
| "небольшая проблема" | "проблема: [описание]. Влияние: [что блокирует]" |
| "особенность системы" | "баг/ограничение: [описание]" |

## Обязательный формат при проблемах

```
ПРОБЛЕМА: [что случилось]
ПРИЧИНА: [почему]
ВЛИЯНИЕ: [что заблокировано]
ВАРИАНТЫ: [1. ... 2. ... 3. ...]
```

## Обязательный формат после компактинга

```
ПОСЛЕ КОМПАКТИНГА:
- Сохранено: [что есть в summary]
- Потеряно: [что потеряно — номера строк, детали агентов, промежуточные данные]
- Фоновые агенты: [статус каждого — работает/упал/потерян]
- Нужно перечитать: [какие файлы]
```

## Правило

Если ловишь себя на формулировке из левой колонки — СТОП, переписать на правую.
Лучше звучать грубо и честно, чем вежливо и лживо.

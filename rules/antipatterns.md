# Антипаттерны — что ЗАПРЕЩЕНО

> При срабатывании любого правила → СООБЩИТЬ пользователю:
> `[ANTIPATTERN: название] — описание что предотвращено`
> Это страховка: пользователь видит что сработало и может отменить если нужно.

## Токены и ресурсы

| Антипаттерн | Что делать вместо |
|-------------|-------------------|
| 5+ агентов "на всякий случай" | Считай перед запуском, каждый = ~$0.10-0.50 |
| Читать файл целиком ради 1 строки | Grep с паттерном |
| Повторять ту же операцию после ошибки | Изменить подход |
| TeamCreate для задачи на 3 шага | Сделать самому |
| model: "sonnet" или "haiku" в Agent | ТОЛЬКО Opus. Sonnet = по явной просьбе. Haiku = ЗАПРЕЩЁН |
| Читать node_modules/ | НИКОГДА |

## Данные и контент

| Антипаттерн | Что делать вместо |
|-------------|-------------------|
| Фейковые конкуренты/данные | ТОЛЬКО реальные, с URL и источником |
| Числа без источника в КП/отчёт | CONFIRMED / UNCONFIRMED / WRONG маркировка |
| AI/нейросети в публичных материалах | "Авторская методология", "Экспертный анализ" |
| Код напрямую на VPS через SSH | git repo → commit → push → deploy script |

## Взаимодействие

| Антипаттерн | Что делать вместо |
|-------------|-------------------|
| Спрашивать подтверждение на каждый шаг | Автономия: получил цель → разбил → выполнил |
| Длинное объяснение вместо действия | Сначала сделай, потом объясни кратко |
| Предлагать план вместо выполнения | "го" = делай, не планируй |
| Игнорировать "рой"/"swarm"/"параллельно" | ДЕЛАТЬ. Можно предупредить о стоимости, но ВЫПОЛНИТЬ |
| Заявлять "не найдено" без полного поиска | VPS → session logs → git log → спросить пользователя |

## Файлы и операции

| Антипаттерн | Что делать вместо |
|-------------|-------------------|
| Удалить >20% файла без предупреждения | `git diff --stat` + ALERT если удалено много |
| Создавать новый файл вместо расширения | Расширить существующий |
| Массовая операция без dry-run | `--dry-run` → проверить → выполнить |
| Деструктивная операция без бэкапа | `git stash` или `cp file.bak` ПЕРЕД правкой |

# Перекрёсток сессии — ОБЯЗАТЕЛЬНО при старте

> После git pull и чтения TODO — ВСЕГДА показать меню ниже.
> Не начинать работу пока пользователь не выбрал путь.

## Меню (показывать КАЖДУЮ сессию)

```
═══════════════════════════════════════════
  {session_name} — {дата}
  Открытых задач: {N} | Входящих: {M}
═══════════════════════════════════════════

  1. 🎯 КОМБАЙН — выполнить задачи из очереди
     {топ-3 задачи одной строкой}

  2. 💬 ИНТЕРВЬЮ — новая задача / контекст
     Расскажи что нужно → разобью → в очередь

  3. 📋 ОБЗОР — показать все задачи + статусы
     TODO, Asana, входящие от роутера

  4. 🔄 СИНК — синхронизация всех репо
     git pull/push + Asana + memory

  5. ⚡ БЫСТРЫЙ ФИКС — одна мелочь прямо сейчас
     Не в очередь, сразу делаю

═══════════════════════════════════════════
  Выбери номер или напиши задачу своими словами
═══════════════════════════════════════════
```

## Правила маршрутизации ответа

| Пользователь пишет | Путь |
|---------------------|------|
| `1`, `комбайн`, `го`, `погнали`, `работай` | → Показать TODO → подтверждение → `/combine` |
| `2`, `интервью`, `новая задача`, `надо сделать...` | → Интервью (см. ниже) |
| `3`, `обзор`, `туду`, `что есть`, `задачи` | → Показать все задачи |
| `4`, `синк`, `sync` | → `/sync-sessions` |
| `5`, `фикс`, `быстро`, конкретная мелочь | → Сделать сразу, без очереди |
| Любой текст задачи | → Интервью → очередь → комбайн |

## Интервью (путь 2) — обогащение задачи

Когда пользователь приходит с новой задачей:

1. **Выслушать** — не перебивать, дать описать
2. **Уточнить** (макс 2-3 вопроса) до заполнения чеклиста готовности:
   - Для кого? (клиент / продукт / внутреннее)
   - Что считается результатом? (файл, деплой, отчёт, ответ)
   - Срочность? (сейчас / эта неделя / когда-нибудь)
3. **Разбить** на атомарные задачи (1 задача = 1 результат)
4. **Валидация** — каждая задача проходит чеклист готовности (см. ниже)
5. **Показать** план: задачи + порядок + оценка
6. **В очередь** → TODO.md + TaskCreate
7. **Автозапуск** → если все задачи ready → `/combine` автоматически

## Чеклист готовности задачи (ОБЯЗАТЕЛЬНО перед комбайном)

Задача считается **ready** если заполнены все обязательные поля:

```
✅ READY:  - [ ] **BluMart: зачистить данные Ростокиных** [client:blumart] [result:docx+deploy] [priority:high]
❌ NOT READY: - [ ] сделать что-то с сайтом
```

| Поле | Обязательно | Пример |
|------|:-----------:|--------|
| **Что сделать** (глагол + объект) | ✅ | зачистить данные Ростокиных |
| **Контекст** `[client:X]` или `[product:X]` | ✅ | [client:blumart] |
| **Результат** `[result:X]` | ✅ | [result:docx+deploy] |
| **Приоритет** `[priority:X]` | ✅ | [priority:high/medium/low] |
| **Скилл** `[skill:X]` | ⚪ авто | [skill:doc-manager] |
| **Блокер** `[blocked-by:X]` | ⚪ если есть | [blocked-by:оплата] |

**Claude автоматически обогащает задачу:**
- Определяет `[skill:]` по содержанию (маршрутизация из CLAUDE.md)
- Определяет `[client:]` по ключевым словам
- Определяет `[priority:]` по revenue-impact (клиент > продукт > внутреннее)
- Если не хватает данных → мини-интервью (1-2 вопроса)

**Задача НЕ попадает в комбайн пока не ready.**

## Очередь = TODO.md (единая для всех)

**Кто может добавить задачу в очередь:**
- Пользователь (через интервью в любой сессии)
- Любой агент/субагент (через TODO.md напрямую)
- Task Router (перемещает между сессиями)
- Asana (через sync)
- TG бот (через /task команду)
- Хуки (post-deploy, monitoring alerts)

**Формат записи в очередь:**
```markdown
- [ ] Описание задачи [client:X] [result:X] [priority:high] [skill:auto]
```

**Агент добавляет задачу:**
```python
# Любой агент может записать в TODO.md нужной сессии:
# 1. Определить сессию по sessions.yaml (keywords match)
# 2. Дописать в TODO.md этой сессии
# 3. Роутер при следующем проходе проверит и переместит если нужно
```

## Комбайн = единственный способ выполнения

**ВСЕ задачи проходят через `/combine`:**
1. Читает TODO.md → фильтрует только **ready** задачи
2. Сортирует: `[priority:high]` → `[priority:medium]` → `[priority:low]`
3. Группирует: независимые → параллельные агенты, зависимые → цепочка
4. Выполняет через подходящий `[skill:]`
5. Завершённая → `[x]` в TODO + Asana

**Автозапуск комбайна:**
- После интервью (все задачи ready) → автоматически
- По выбору "1" в меню → показать TODO → подтвердить → запуск
- По команде `го` / `комбайн` → сразу

**Исключение:** путь 5 (быстрый фикс) — ТОЛЬКО для задач < 5 минут, одна штука.

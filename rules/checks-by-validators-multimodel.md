## Правило (HARD, для ЛЮБОЙ проверки)
ВЕРДИКТ проверки выносят **специалисты-валидаторы (агенты/модели), а не мой глаз/Read**. Мой просмотр = только **пред-фильтр** (отсеять явный брак), НИКОГДА не финальный гейт. Любое «готово / на ревью / проверил / выглядит ок» по артефакту = только ПОСЛЕ панели валидаторов.

Триггеры (когда обязательно): визуальный рендер/дизайн/UX/вёрстка/скриншот, факт-чек/числа/claim, quality-gate перед деплоем/отправкой, «посмотри что вышло / годится ли».

## Панель по типу проверки (минимум 2 независимых, разные API)
| Тип | Валидаторы (параллельно, разные семейства) |
|-----|--------------------------------------------|
| **Визуал / дизайн / UX / рендер** | **`~/.claude/scripts/vision-validate.py <png> "<что проверять>"`** (OpenRouter, 2 vision-модели разных семейств gpt-4o+gemini-2.5-pro, cross-confirm — РАБОЧИЙ путь) + `ui-visual-validator` (Anthropic, Opus читает PNG) + `gemini-rescue` (Google — ⚠️ free-квота часто limit:0 / ключ требует restrict) [+ `bencium`/`accessibility-tester` по ставке] |
| **Факты / числа / claim** | `round_table` (free: llama+qwen3+gpt-oss) + `strict-factchecker` |
| **Код** | `code-reviewer` + `codex:codex-rescue` (OpenAI) [+ `security-review`] |

## Мульти-модель + эскалация FREE → PAID (Антон)
1. **Сначала бесплатные:** `round_table` Groq-стек (llama/qwen3/gpt-oss-120b), `gemini` free tier, Anthropic-валидаторы в рамках лимита.
2. **Платное — только если спорно / высокая ставка / free дал расхождение:** OpenRouter (`kimi-k2`, `deepseek-r1`), paid Gemini/Codex. НЕ жечь платное сразу.
3. **2+ модели на проверку** (cross-confirmation): совпали → высокая уверенность; разошлись → эскалация (доп. модель / paid / человек).

## Мульти-API параллельно (обход 403 — это и есть ×4)
Параллельные **Anthropic-агенты ловят 403** (потолок лимита). Поэтому панель раскидывать по РАЗНЫМ семействам одновременно — они не конфликтуют по лимитам: Anthropic + Google(Gemini) + OpenAI(Codex) + open-source(round_table/OpenRouter) + детерминированные скрипты (без LLM). Anthropic держать 1-2, остальное — на других API.

## Что мой глаз МОЖЕТ (пред-фильтр), что НЕТ (вердикт)
- ✅ Быстро отсеять явный брак/обрыв ДО панели (экономия).
- ❌ Выносить вердикт «годится/на ревью» в одиночку — это работа валидаторов (прецедент: пропустил бренд Фёдорова + мобайл-overflow).

## Enforcement (candidate-хук, TBD approve — меняет харнес 3 аккаунта)

Bypass `VALIDATOR_OK=1`. Не регистрировать без approve + тест.

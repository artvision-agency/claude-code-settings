# PPC: заливка кампаний в кабинет клиента — ВСЕГДА выключенными (HARD)

> **Установлено:** 2026-06-20 (Антон, USmile yail307, дословно: «когда загружаем — кампании все ОТКЛЮЧЁННЫМИ. всегда откл»).
> **Связано:** security.md (финансовое = CONFIRM), `clients/usmile/ppc/upload_reserve_json.py` (assert_not_active), finance-password-gate.

## Правило (HARD, без исключений)
ЛЮБАЯ заливка/создание рекламных кампаний в кабинет клиента (Я.Директ, eLama, VK Реклама, ads.vk, Google Ads) — **ВСЕГДА выключенными**: кампания SUSPENDED/OFF, объявления DRAFT (не на модерации). Никогда не создавать включёнными, никогда не включать автоматически.

## Включение = ТОЛЬКО явный CONFIRM Антона
- Перевод кампании в ON / запуск / снятие с паузы / отправка объявлений на модерацию = **финансовое действие** → security.md CONFIRM. Только после явного «да/включай» Антона.
- Заливка структуры (кампании/группы/ключи/объявления выключенными) = можно без отдельного CONFIRM (не тратит), НО результат всегда OFF.

## Техническая проверка (обязательна в любом uploader'е)
- После заливки — `campaigns.get` State, hard-fail если State в (ON, CONVERTED). Безопасные не-тратящие: SUSPENDED, OFF, DRAFT.
- Свежая пустая кампания = DRAFT (suspend на ней падает 8300 «черновик нельзя остановить») — это норма, DRAFT не тратит. Строить контент в DRAFT, итог = OFF/DRAFT.
- Ставки на резерв/заливке — минимум (напр. 30 коп) пока Антон не задал боевые.

## Антипаттерны
- ❌ Создать кампанию включённой / с авто-стартом.
- ❌ Включить кампанию без явного CONFIRM Антона (это трата денег клиента).
- ❌ Отправить объявления на модерацию (ACTIVE) при заливке без подтверждения.
- ❌ Печатать «SUSPENDED» не запросив реальный State (false safety).

## 🔴 Модерация черновика ФЛИПАЕТ State в ON (HARD, прецедент 2026-06-20)
`ads.moderate` на кампании в статусе DRAFT/«Черновик» **выводит её из черновика и Яндекс ставит State=ON** (черновик при выходе дефолтится в ON, не в OFF). → **СРАЗУ после `ads.moderate` обязателен `campaigns.suspend` + проверка State не в (ON,CONVERTED).** Иначе после прохождения модерации кампания НАЧНЁТ ТРАТИТЬ. Цель «модерация для данных аукциона без траты» = ACCEPTED + SUSPENDED (round_table подтвердил: пауза+принято даёт AuctionBids без показов).
Паттерн uploader/скрипта модерации: `ads.moderate(ids)` → `campaigns.suspend(cid)` → `assert State in {SUSPENDED,OFF}`.

# Оптимизация токенов — жёсткий режим

## Команды агентов (TeamCreate)
- **TeamCreate:** ПРЕДУПРЕДИТЬ пользователя перед запуском!
  Формат: "Запускаю команду из N агентов (~X токенов). Ок?"
- **Модель субагентов:** ТОЛЬКО **opus**. БЕЗ ИСКЛЮЧЕНИЙ. Это правило для любой модели-хоста.
- **Task tool:** model параметр НЕ указывать (наследует opus).
- **Sonnet** — допустим ТОЛЬКО по явной просьбе Антона. **Haiku = ЗАПРЕЩЁН.**

## Правила чтения файлов
- Файл >2K строк → Grep или Read с offset/limit
- Файл >10K строк → ТОЛЬКО Grep
- node_modules/ → НИКОГДА не читать
- **JSON >500 строк** → python3 -c "..." для извлечения нужных полей

## Тесты — через обёртку
```bash
~/.claude/scripts/run-tests.sh "<описание>" "<команда>"
```
Успех → 1 строка. Ошибка → полный вывод. Fail-fast.

## Агенты
**Агент = Claude + системный промпт.** НЕ имеет суперспособностей.
Агент без данных = галлюцинации. Гибридный подход: собрать данные → передать агенту.
**Каждый агент = ~$0.10-0.50.** Считай перед запуском.

## Антипаттерны (ЗАПРЕЩЕНО)
- Запускать 5+ агентов "на всякий случай" (каждый = ~50K токенов)
- Читать файл целиком чтобы найти 1 строку (используй Grep)
- Повторять одну и ту же операцию после ошибки без изменения подхода
- Создавать TeamCreate для задачи которую можно решить за 3 шага

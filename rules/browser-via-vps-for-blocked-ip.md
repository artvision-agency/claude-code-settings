# Заход в кабинеты, заблокированные для нашего локального IP → через VPS (HARD)

> **Установлено:** 2026-06-15 (Антон, Грелка). Прецедент: `ads.vk.com` забанил наш IP после автологина (curl 000 / браузер timeout), при этом google 200 + vk.com 302 = бан КОНКРЕТНОГО поддомена для нашего IP. VPN Антона на мои инструменты НЕ распространяется (agent-browser/curl идут своим маршрутом). Решение — пустить браузер через наш VPS (московский IP, чистый).
> **Связано:** `self-corrections.md` #7 (диагностика сети по слоям), `scraping.md` (антибот-эскалация), `proven-tools-first.md`, `agent-browser` skill, `vps-parallel-combine.md`. Инструмент: `~/.claude/scripts/vps-browse.sh`.

## Когда применять
- Любой RU-кабинет/сервис не открывается у меня (curl 000 / браузер ERR_TIMED_OUT), а `google.com` 200 → это бан/недоступность КОНКРЕТНОГО хоста для нашего IP, не общий сбой.
- Особенно: `ads.vk.com`, `direct.yandex.ru`, биллинг рекламных кабинетов, площадки с антиботом, забанившие IP после автоматизации.
- Смена VPN Антоном НЕ помогает моим инструментам — нужен именно VPS-маршрут для МОИХ тулзов.

## Метод (детерминированный)
1. **Диагностика по слоям** (`self-corrections.md` #7): `curl google` (200?) + `curl <host>` (000?). google ОК + host 000 = IP-бан хоста → VPS.
2. **Проверка маршрута:** `~/.claude/scripts/vps-browse.sh check <url>` → выведет `direct=<код> vps=<код>`. Если `direct=000 vps=2xx/3xx` → идём через VPS.
3. **Открыть через VPS:** `~/.claude/scripts/vps-browse.sh open <url>` — поднимает SSH SOCKS5-туннель (порт 1080) через VPS + перезапускает agent-browser с `--proxy-server=socks5://127.0.0.1:1080`. Дальше обычные `agent-browser snapshot/fill/click/mouse` работают (daemon уже проксирован).
4. **Капча VK «Я не робот»** — авто-клик по ref НЕ проходит (антибот). Человекоподобно: `agent-browser mouse move x3` (плавно к чекбоксу ≈595,385) → `mouse down` → `mouse up`. Скриншот для координат если модал другой.
5. **2FA** (если на телефон клиента, напр. Я.Директ push на TECNO SPARK) — VPS НЕ обходит 2FA: нужен код от клиента ИЛИ OAuth-токен. Это отдельная стена, не путать с IP-баном.
6. **Закрыть туннель** по завершении: `vps-browse.sh down` (не обязательно — переживает, но чисто).

## Доступы / креды
- Логины/пароли кабинетов клиента — ТОЛЬКО в `clients/<slug>/access.md` (gitignored; синк `sync-access.sh pull`). НЕ дублировать сюда (это правило в ПУБЛИЧНОМ репо — self-corrections #31).
- VPS-хост задаётся через env `VPS_HOST` / `VPS_SOCKS_PORT` (дефолт нашего VPS — в скрипте).

## Антипаттерны
- ❌ Долбить хост повторно тем же IP после 000 (бан не спадёт от ретраев) — сразу диагностика по слоям → VPS.
- ❌ Думать что «VPN Антона» решит мою недоступность — мои тулзы через его VPN не ходят.
- ❌ Менять UA/фингерпринт против 000 — это сетевой/IP-уровень, не детект юзер-агента; помогает только другой IP.
- ❌ Путать IP-бан (000, лечится VPS) с 2FA-стеной (нужен код клиента — VPS не помогает).
- ❌ Авто-клик по ref на капче VK (не проходит) — только человекоподобный mouse move+down+up.

# Парсинг цен/данных — ОБЯЗАТЕЛЬНО читать PDF (прайсы прячутся в PDF) — DEFAULT ON

> **Установлено:** 2026-06-27 (Антон, USmile анализ цен соседей). «Во всех наших парсингах: если у клиники прайс в PDF — его надо читать, там прячутся цены и любые нужные данные. Подключить чтение PDF.»
> **Прецедент:** парсер цен соседей USmile (27.05) читал только HTML → консультация и часть цен остались UNCONFIRMED. У клиник прайсы нередко лежат PDF-файлом, не на HTML-странице.
> **Связано:** `numbers-deterministic-meaning-llm.md` (числа кодом, не «на глаз»), `scraping.md` (эскалация антибот), `calculations-need-sources.md` (source+дата на каждое число), `pdf-translation-gate` skill, `service-knowledge-base.md`.

## Правило (HARD)
В ЛЮБОМ парсинге цен/характеристик/данных с сайта — если на сайте есть PDF (прайс-лист, каталог, тарифы) — его ОБЯЗАТЕЛЬНО скачать и прочитать. Цена/данные могут быть только в PDF, не в HTML. «Не нашёл в HTML» ≠ «нет цены» (no-false-negative) пока не проверены PDF.

## Как (детерминированно)
1. Найти PDF-ссылки: `curl -sL <сайт>/<страница цен> | grep -oiE 'href="[^"]*\.pdf"'`; проверить /price, /ceny, /tarify, /uslugi, /prays, footer, «скачать прайс».
2. Скачать: `curl -sL -o /tmp/price.pdf "<url>"`.
3. Прочитать: Read tool (умеет PDF) ИЛИ `pdftotext /tmp/price.pdf -` (poppler) ИЛИ python `pdfplumber`/`PyPDF2`. Таблицы — `pdfplumber.extract_tables()`.
4. Извлечь числа ДЕТЕРМИНИРОВАННО (regex/таблица), не выводом LLM (numbers-deterministic). Каждое число → source_url(PDF) + дата + CONFIRMED.
5. Отличать прайс от мусора: `polit.pdf`/`politica.pdf`/`oferta.pdf`/`soglasie.pdf` = политика/оферта (НЕ цены) — пропускать.
6. PDF не читается / нет → честно null/UNCONFIRMED, пометить, не выдумывать.

## Где применять
Скрейп цен конкурентов, прайсы клиник/клиентов, тарифы, каталоги, любой сбор данных с сайта где возможен PDF (стоматологии, клиники, b2b-прайсы, юр-тарифы, сметы).

## Антипаттерны
- ❌ Парсить только HTML, не проверив PDF-прайс → «цена не найдена», хотя она в PDF.
- ❌ Принять `polit.pdf` за прайс (политика ≠ цены).
- ❌ Цена из PDF «на глаз» без regex/таблица-extract и без source.
- ❌ «Нет цены» без проверки PDF (no-false-negative).

# Реестр deploy-ссылок артефактов клиента → авто-вызов по запросу (DEFAULT ON, HARD)

> **Установлено:** 2026-06-27 (Антон, Творим). «Можешь зафиксировать, чтобы вообще всегда вызывались эти ссылки по моему запросу? Вот только сейчас мы нормально нашли. Они все нормальные — надо чтобы визуально всегда подключались, когда будет запрос.»
> **Корень:** готовые артефакты (КП, калькуляторы, анализы, дашборды, отчёты) задеплоены на artvision.pro, но их URL разбросаны по html/handover/git — каждый раз ищу заново. Нужен ОДИН реестр на клиента + авто-выдача по запросу.
> **Связано:** `asset-capture-no-loss.md` (внешние URL клиента), `always-html-deploy-links`/`feedback_deploy_url_first.md` (URL первой строкой), `artvision-deploy-url-guarantee.md` (curl 200), `no-false-negative.md` (искать в реестре до «нет»), `resume-read-project-state.md`.

## Правило (HARD)
На запрос «дай / найди / где / скинь / покажи **ссылку на <артефакт>** по <клиент/проект>» — где артефакт = КП / калькулятор / анализ цен / конкурентная матрица / дашборд / отчёт / гант / лендинг / презентация:
1. **ПЕРВЫМ делом** читать `clients/<slug>/DEPLOY-LINKS.md` (реестр deploy-ссылок проекта).
2. Найден → отдать **URL первой строкой** ответа (feedback_deploy_url_first), пометить ✅ если curl 200.
3. **Не найден в реестре** → искать (`grep -rhoE "artvision\.pro/[A-Za-z0-9_/-]+"` по `clients/<slug>/` + git log + handover) → curl 200 → **ДОПИСАТЬ в `DEPLOY-LINKS.md`** (чтобы следующий раз нашлось мгновенно). Это и есть капитализация находки.
4. Несколько кандидатов на одно слово (напр. «калькулятор» = анализ цен соседей И калькулятор стоимости услуг) — показать оба с подписью-различием, спросить какой.

## Формат `clients/<slug>/DEPLOY-LINKS.md`
Список (document-list-format), на каждый артефакт: **название · prod-URL · review-копия (_priv) · локальный путь · дата проверки 200**. Обновлять при каждом новом деплое клиентского артефакта (часть deploy-report).

## Где создаётся
- При онбординге (`/new-client`) — пустой `DEPLOY-LINKS.md` из шаблона.
- Для существующих клиентов — создаётся при первом запросе ссылки по проекту (п.3) ИЛИ при первом деплое.

## Антипаттерны
- ❌ Искать deploy-URL артефакта заново каждый раз, не заглянув в `DEPLOY-LINKS.md`.
- ❌ Нашёл ссылку и не дописал в реестр (следующая сессия снова ищет).
- ❌ Отдать URL не первой строкой (Антон смотрит только URL).
- ❌ Отдать одну ссылку, когда под слово подходят 2 артефакта (анализ соседей ≠ калькулятор услуг) — показать оба.

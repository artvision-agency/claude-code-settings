# Проверка контрагента (Due Diligence)

## Когда использовать
- Перед подписанием договора/NDA
- Перед началом работы с новым клиентом
- Ежемесячная проверка существующих контрагентов
- По запросу: "проверь контрагента", "реквизиты компании", "due diligence"

## Входные данные
Одно из:
- Название компании
- ИНН
- ОГРН
- URL сайта компании

## Алгоритм проверки

### 1. Поиск в ЕГРЮЛ
Искать через WebSearch:
- `"ООО [название]" ИНН ОГРН реквизиты site:rusprofile.ru`
- `"[ИНН]" site:checko.ru`
- `"[название]" site:spark-interfax.ru`

### 2. Собрать данные

| Параметр | Где искать |
|----------|-----------|
| Полное название | ЕГРЮЛ |
| ИНН, ОГРН, КПП | ЕГРЮЛ |
| Юр. адрес | ЕГРЮЛ |
| Ген. директор | ЕГРЮЛ |
| Учредители + доли | ЕГРЮЛ |
| Дата регистрации | ЕГРЮЛ |
| Уставный капитал | ЕГРЮЛ |
| ОКВЭД (основной) | ЕГРЮЛ |
| Размер (микро/малое/среднее) | Реестр МСП |

### 3. Проверить флаги

| Флаг | Как проверить | Критичность |
|------|--------------|-------------|
| Адрес недостоверный | ЕГРЮЛ отметка | ВЫСОКАЯ |
| Задолженность по налогам | checko.ru, nalog.ru | СРЕДНЯЯ |
| Массовый адрес | checko.ru | СРЕДНЯЯ |
| Массовый директор (>5 компаний) | rusprofile.ru | НИЗКАЯ |
| Компания < 1 года | Дата регистрации | НИЗКАЯ |
| Уставный капитал 10K | Минимальный | НИЗКАЯ |
| Ликвидация/банкротство | ЕГРЮЛ статус | КРИТИЧЕСКАЯ |
| Судебные дела | `"[ИНН]" site:kad.arbitr.ru` | СРЕДНЯЯ |
| Исполнительные производства | fssp.gov.ru | ВЫСОКАЯ |

### 4. Сформировать отчёт

Сохранить в: `clients/[name]/legal/counterparty-check-[date].md`

Формат:
```markdown
# Проверка контрагента: [Название]
Дата: [дата]
Проверил: Claude (Artvision)

## Реквизиты
- Полное название: ...
- ИНН: ... | ОГРН: ... | КПП: ...
- Адрес: ...
- Ген. директор: ...
- Учредители: ...
- Уставный капитал: ...
- Дата регистрации: ...
- ОКВЭД: ...
- Размер: ...

## Флаги
| Флаг | Статус | Комментарий |
|------|--------|-------------|

## Вердикт
[БЕЗОПАСНО / ОСТОРОЖНО / РИСКОВАННО]

## Источники
- [ссылки на источники]
```

### 5. Рекомендация

- **БЕЗОПАСНО**: нет критичных флагов, компания > 2 лет, нет долгов
- **ОСТОРОЖНО**: есть среднего уровня флаги (молодая компания, минимальный уставный капитал, массовый адрес)
- **РИСКОВАННО**: недостоверный адрес + долги + исполнительные производства

## Ежемесячная проверка существующих контрагентов

1 числа каждого месяца:
1. Прочитать `clients/*/config.yaml` — список активных клиентов
2. Для каждого клиента с ИНН — прогнать проверку
3. Сравнить с предыдущей проверкой
4. Если появились новые флаги — алерт в TG

# Agent #4 — Objective Ratings (внешние независимые рейтинги)

**Subagent type:** `general-purpose` (нужен Bash + WebFetch + WebSearch)

## Задача

Собрать **объективные внешние данные** не из user-generated reviews — а из профессиональных рейтингов, госреестров, статистики:

| Сегмент | Источники |
|---------|-----------|
| Школы | RAEX (Россия + регион), Фонтанка ЕГЭ-рейтинг, региональные «Лучшие школы», результаты олимпиад, школьные сайты |
| Клиники | Минздрав региональный рейтинг, лицензии Росздравнадзора, ProDoctorov.ru сводный, профильные ассоциации |
| Детсады | Региональный департамент образования (рейтинги), сводки лицензий, аккредитации |
| Стоматологии | Лицензии Росздравнадзора, премии «Лучшая клиника», stomport.ru рейтинг |
| Фитнес | Сертификаты FIBO/ISSA тренеров (если объявлено), государственный реестр |
| Услуги | Лицензии, сертификации, профильные ассоциации |

## Метод

1. Прочитать `<base>/data/seed-orgs.json`
2. Определить тип организаций → выбрать релевантные рейтинги
3. Для каждой организации:
   - `WebSearch`: `<имя> RAEX 2024` / `<имя> Фонтанка ЕГЭ` / `<имя> Росздравнадзор` / профильный реестр
   - `WebFetch` rating-таблиц → найти позицию орг.
   - Записать тренд (2023 → 2024 → 2025) если данные за несколько лет
4. **Только реальные данные.** Если рейтинг не публикуется — `null`, не выдумывать. Пометить в `methodology_note` что доступно публично.

## Выход

Записать в `<base>/data/objective-ratings.json`:

```json
{
  "collected": "YYYY-MM-DD",
  "agent": "objective-ratings",
  "methodology_note": "Какие источники реально опрошены, что недоступно публично, ограничения",
  "schema_for_segment": "schools | clinics | kindergartens | dental | fitness | services",
  "orgs": [
    {
      "id": "<seed-id>",
      "name": "...",
      "ratings": {
        "raex_russia_2024": 174,
        "raex_russia_2025": 148,
        "raex_russia_trend": "+26 (↑)",
        "raex_regional_2025": 16,
        "fontanka_ege_average_2024": 78.5,
        "license_status": "active | suspended | revoked",
        "specializations": [...],
        "awards": [...]
      },
      "notes": "<контекст для людей: что эти числа значат>"
    }
  ]
}
```

## Антипаттерны

- ❌ Выдумать позицию в рейтинге без URL источника
- ❌ Смешать «рейтинг А и рейтинг Б» в одно число (разные методологии)
- ❌ Использовать устаревшие 2019-2021 данные без пометки «нет свежих»
- ❌ Сравнивать школу и гимназию в одном RAEX-ряду без note о разнице категорий

## Связь

- Данные используются в HTML-дашборде как **trust 2x2**: «официальное vs отзывы» — где гэп, там вопрос.
- Если для сегмента нет внешних рейтингов (типичные парикмахерские, мастерские) — заполнить `null` + `methodology_note: "Для этого сегмента независимые рейтинги не публикуются — анализ только на основе отзывов"`.

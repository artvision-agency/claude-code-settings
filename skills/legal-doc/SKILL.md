# Legal Doc — Юридические документы

## Цель
Подготовить юридический документ по шаблону или кастомный. **Финальная вычитка — юристом** (ANT Partners — партнёр). Claude готовит драфт и выявляет риски.

## Когда вызывается
- Новый клиент → договор на услуги
- Новый подрядчик/сотрудник → НДА
- Изменение объёма работ → доп.соглашение
- Спор с клиентом → претензия / ответ на претензию
- Регистрация/защита ИП → доверенность, акты

## Процесс

### ШАГ 1: Определить тип

| Тип | Шаблон в | Кто визирует |
|-----|----------|-------------|
| Договор SEO/маркетинг | `templates/legal/contract-seo.md` | Антон + юрист (для >100K) |
| НДА | `templates/legal/nda.md` | Антон |
| Доп.соглашение | `templates/legal/dop-agreement.md` | Антон |
| Претензия | `templates/legal/claim.md` | Антон + юрист (всегда) |
| Акт выполненных работ | `templates/legal/act.md` | Антон |

Если шаблона нет — создать первую версию в `templates/legal/` и пометить как DRAFT.

### ШАГ 2: Сбор реквизитов

От клиента/подрядчика нужны:
- Полное название юрлица (ООО/ИП/АО)
- ИНН, КПП, ОГРН
- Юр.адрес
- Банковские реквизиты
- ФИО руководителя + должность + основание (Устав/Доверенность)
- Контактный email

Источники: `tokens.json`, `clients/<c>/contacts.md`, `counterparty-check` (если новый клиент — проверить rusprofile).

### ШАГ 3: Заполнение шаблона

Use `python3 scripts/legal-doc-builder.py <type> <client>` (если есть) или вручную Edit tool.

Обязательные блоки договора:
1. Преамбула (стороны)
2. Предмет (что делаем — конкретно)
3. Стоимость и порядок расчётов
4. Сроки
5. Права и обязанности сторон
6. Ответственность
7. Конфиденциальность
8. Форс-мажор
9. Порядок разрешения споров (подсудность — Санкт-Петербург)
10. Реквизиты и подписи

### ШАГ 4: Проверка рисков (автоматическая)

Чеклист (grep по тексту):
- [ ] Нет обещаний KPI / гарантий позиций (запрет из `feedback_no_free_month_kpi.md`)
- [ ] Нет бесплатных месяцев в договоре
- [ ] Подсудность — наша (СПб)
- [ ] Штрафы симметричные (или в нашу пользу)
- [ ] Срок расторжения — не менее 30 дней уведомления
- [ ] Права на результаты работ — у нас до полной оплаты
- [ ] Конфиденциальность — взаимная
- [ ] Нет упоминаний AI/нейросетей в предмете (для публичных — см. `security.md`)

Каждый ❌ → пометка в документе `[RISK: ...]` + алерт в CONFIRM-батч.

### ШАГ 5: Экспорт

- `.md` → pandoc → `.docx` (Times New Roman 12pt)
- PDF через headless Chrome для финального варианта
- Сохранить в `clients/<c>/legal/<YYYY-MM-DD>-<type>.docx`

### ШАГ 6: Отправка

Всегда через CONFIRM-батч:
```
📜 LEGAL — <тип> для <клиент>
Файл: <путь>
Риски: <список или нет>
Отправить: Email / TG / Asana?
```

## Запреты
- Не отправлять документ без CONFIRM Антона
- Не обещать того чего не можем выполнить
- Не обходить юриста для сумм > 100K
- Не использовать AI/нейросети в предмете договора
- Не подписывать за клиента

## Связанные
- `legal-dispute` — процедура споров

- ANT Partners — юр.партнёр для сложных случаев
- `clients/<c>/legal/` — архив документов клиента

# Linkbuilding Workflow

Универсальный workflow линкбилдинга для любого клиента Artvision.

## WORKFLOW (step by step)

### 0. Backlink-Loss Check (snapshot + diff + recovery) — ОБЯЗАТЕЛЬНО для существующих клиентов

Перед сбором новых доноров — проверить что УЖЕ было и что отвалилось. Делегировать агенту `seo-specialist` (изолированный контекст, несёт pipeline). Метод — см. правило `linkbuilding-loss-recovery.md`.

1. **Snapshot текущих доноров** — Я.Вебмастер `/hosts/<host_id>/links/external/samples` (полный список доменов, не count). Сохранить `clients/[client]/linkbuilding/snapshots/donors-YYYY-MM-DD.json`.
2. **Diff vs прошлый snapshot** + исторические `donors-*.md` / `semrush-backlink-audit-*.md` → какие домены РАНЬШЕ ссылались, СЕЙЧАС нет.
3. **🔴 КЛАССИФИЦИРОВАТЬ отвал — спам vs качество** (ключевое, иначе ложная тревога):
   - **Спам/PBN-отвал** (share-IP прогоны, off-topic: мебель/окна/кролики, AS 0-10 массой) → НЕ возвращать, кандидаты на **Disavow** (step «Токсичные ссылки»). Обвал спам-пилы (153↔1827) — это НЕ потеря качества.
   - **Качественный отвал** (тематичные авто/B2B/СПб, живые СМИ/каталоги/форумы, ИКС/AS норм) → в **recovery-план**.
4. **Recovery-план** для качественных: [домен | репутация | тип | гипотеза почему отвалился | действие: восстановить размещение / outreach / новая публикация | приоритет]. Вливается в общий план доноров (step 2-5) как приоритетная категория «возврат».
5. Записать `clients/[client]/linkbuilding/backlink-loss-recovery-YYYY-MM-DD.md`.

⚠️ Baseline ссылочного (если заявлен «было N») — ВЕРИФИЦИРОВАТЬ источник (Вебмастер history API), не строить план на незаземлённой цифре (`calculations-need-sources.md`). Прецедент avto.world 08.06: 527→153 (−71%) оказался отвалом спам-PBN, а не потерей доноров — реально к возврату ~5 из ~150.

### 1. Pre-check

Прочитать конфиг клиента для получения NAP-данных:

```
Read: clients/[client-name]/config.yaml
```

Необходимые поля:
- **name** — название компании
- **address** — адрес (для локального SEO)
- **phone** — телефон
- **site** — URL сайта
- **niche** — ниша/тематика

Если `config.yaml` отсутствует — запросить данные у пользователя и создать файл.

### 2. Donor Collection (сбор доноров)

Доноры делятся на 3 группы. Собирать ВСЕ три:

#### A. Общие каталоги (обязательные для ВСЕХ клиентов)

| # | Каталог | Тип | Приоритет |
|---|---------|-----|-----------|
| 1 | Яндекс.Бизнес | dofollow | Максимальный |
| 2 | Google Business Profile | dofollow | Максимальный |
| 3 | 2GIS | dofollow | Максимальный |
| 4 | Zoon.ru | nofollow | Высокий |
| 5 | Yell.ru | nofollow | Высокий |
| 6 | Flamp.ru | nofollow | Высокий (через 2GIS) |
| 7 | SPR.ru | nofollow | Средний |
| 8 | Cataloxy.ru | nofollow | Средний |
| 9 | OrgPage.ru | nofollow | Средний |
| 10 | Firmika.ru | nofollow | Средний |

**Проверка:** WebSearch `"Название компании" site:каталог` — если ❌, зарегистрировать.

#### B. Тематические каталоги (по нише клиента)

**WebSearch** по запросам:
- `"[niche] каталог компаний"`
- `"[niche] рейтинг"`
- `"[niche] справочник"`
- `"[niche] портал"`
- `"[niche] ассоциация членство"`

Примеры тематических:

| Ниша | Каталоги |
|------|----------|
| Юристы | pravo.ru, lawfirm.ru, pravorub.ru, justiva.ru, 9111.ru, pravoved.ru |
| Стоматология | prodoctorov.ru, napopravku.ru, docdoc.ru, startsmile.ru |
| Авто | drom.ru, auto.ru, drive2.ru, autospot.ru |
| Строительство | stroyka.ru, stroyportal.ru, all.biz |
| B2B промышленность | fabricators.ru, promportal.su, tiu.ru |
| Бурение | aqua-root.ru, voda-inform.ru |
| Плавание/спорт | sport-marafon.ru, sportmaster.ru marketplace |

#### C. Контент-площадки (гостевые публикации)

**WebSearch** по запросам:
- `"[niche] гостевые публикации"`
- `"[niche] блоги принимают статьи"`
- `"[niche] форумы"`
- `"[niche] отзовики"`

Проверить существующих доноров в `clients/[client-name]/linkbuilding/`.
Исключить дубликаты и уже использованные площадки.

**Scoring Formula:**

```
Score = Relevance(0-1) * LinkType * AccessFactor
```

| Параметр | Значения |
|----------|----------|
| **Relevance** | 0.0 — нерелевантно, 0.5 — смежная тематика, 1.0 — точное совпадение ниши |
| **LinkType** | dofollow = 1.5, nofollow = 1.0, UGC/sponsored = 0.7 |
| **AccessFactor** | бесплатный = 1.5, бартер = 1.2, платный до 5K = 1.0, платный >5K = 0.8 |

Итоговый Score:
- **>1.5** — приоритетный донор (TIER 1)
- **1.0-1.5** — хороший донор (TIER 2)
- **0.5-1.0** — дополнительный (TIER 3-4)
- **<0.5** — пропустить

### 3. ICS/DR Verification (проверка ИКС/DR)

Запустить скрипт проверки:

```bash
python3 scripts/check_ics_dr.py --input clients/[client-name]/linkbuilding/donors-raw.md --output clients/[client-name]/linkbuilding/donors-verified.md
```

Скрипт: `scripts/check_ics_dr.py` — принимает список доменов, возвращает ИКС (Яндекс) и DR (Ahrefs/аналоги).

### 4. Filter (фильтрация)

Удалить домены, которые:
- ИКС < 100
- Содержат spam-маркеры (казино, фарма, adult, дорвеи)
- Имеют пессимизацию в поисковых системах
- Размещают >50% внешних ссылок (линкоферма)

### 5. Tier Classification (классификация по уровням)

| Tier | Тип | Описание | Пример |
|------|-----|----------|--------|
| **TIER 1** | dofollow, high DR | Экспертные статьи на авторитетных площадках | vc.ru, Habr, отраслевые порталы |
| **TIER 2** | nofollow, high traffic | Кейсы, статьи на площадках с трафиком | Spark, Cossa, профильные блоги |
| **TIER 3** | NAP, local SEO | Карточки компании, справочники | 2GIS, Яндекс.Карты, Zoon |
| **TIER 4** | Niche catalogs | Профили, каталоги, форумы | Отраслевые каталоги, форумы |

### 6. Anchor Strategy (анкорная стратегия)

| Тип анкора | Доля | Пример |
|------------|------|--------|
| **Branded** (брендовый) | 40% | "Artvision", "Компания X" |
| **Naked URL** (голый URL) | 30% | "https://example.com", "example.com" |
| **Keyword** (ключевой) | 20% | "продвижение сайтов", "юрист в Москве" |
| **Dilution** (разбавочный) | 10% | "тут", "на сайте", "подробнее" |

Правила:
- Никогда не использовать один и тот же анкор дважды для TIER 1
- Keyword-анкоры распределить по разным ключевым фразам
- Branded-анкоры варьировать: полное название, сокращение, домен
- Для TIER 3-4 использовать преимущественно Branded и Naked URL

### 7. Content Plan (контент-план)

Подготовить 5-7 статей:

Для каждой статьи указать:
- **Заголовок** (H1)
- **Целевая площадка** (из TIER 1-2)
- **Формат** (экспертная статья / кейс / обзор / how-to)
- **Анкор и URL** для ссылки на сайт клиента
- **Объём** (знаков)
- **Ключевые тезисы** (3-5 пунктов)

### 8. Directory Audit + Registration (проверка каталогов)

**ОБЯЗАТЕЛЬНЫЙ шаг.** Проверить регистрацию клиента в каталогах из шага 2A + 2B:

1. WebSearch `"Название" site:yandex.ru/maps` — и так для каждого каталога
2. Результат → таблица: каталог | ✅/❌ | ссылка на профиль
3. Если ❌ — подготовить инструкцию по регистрации или зарегистрировать через Playwright
4. Сохранить в `clients/[client-name]/linkbuilding/directory-audit-[YYYY-MM-DD].md`

### 9. NAP Profiles (NAP-профили)

Сформировать единый NAP-блок:

```
Название: [Полное юридическое/маркетинговое название]
Адрес: [Полный адрес с индексом]
Телефон: [Основной номер в формате +7 (XXX) XXX-XX-XX]
Сайт: [URL]
Email: [Контактный email]
Часы работы: [Пн-Пт: XX:XX-XX:XX]
Описание: [150-200 символов, уникальное для каждой площадки]
Категории: [Основная, Дополнительная 1, Дополнительная 2]
```

Список площадок для NAP:
- Яндекс.Карты / Яндекс.Бизнес
- 2GIS
- Google Business Profile
- Zoon
- Yell.ru
- Фламп
- Отраслевые справочники по нише клиента

### 10. Calendar (календарь выполнения)

6-недельный план:

| Неделя | Действия |
|--------|----------|
| 1 | NAP-профили (TIER 3-4): 10-15 площадок |
| 2 | NAP-профили (остаток) + 1 статья TIER 2 |
| 3 | 2 статьи TIER 2 + форумы/комментарии |
| 4 | 1 статья TIER 1 + 1 статья TIER 2 |
| 5 | 1 статья TIER 1 + каталоги TIER 4 |
| 6 | 1-2 статьи TIER 1-2 + аудит размещений |

### 11. Output Files (выходные файлы)

Все файлы создаются в `clients/[client-name]/linkbuilding/`:

| Файл | Содержимое |
|------|-----------|
| `donors-[YYYY-MM-DD].md` | Полный список доноров с Score, ИКС/DR, тип ссылки, tier |
| `linkbuilding-plan-[YYYY-MM-DD].md` | Стратегия, анкоры, календарь, бюджет |
| `article-outlines-[YYYY-MM-DD].md` | Темы, тезисы, площадки для каждой статьи |
| `nap-profiles-[YYYY-MM-DD].md` | NAP-блок + список площадок со статусами |

### Скрипты

- **`scripts/check_ics_dr.py`** — проверка ИКС (Яндекс) и DR (Ahrefs) для списка доменов. Принимает `--input` (файл с доменами) и `--output` (результат с метриками).

### Scoring Formula

```
Score = Relevance(0-1) * LinkType * AccessFactor
```

- **Relevance** — тематическая релевантность донора нише клиента (0.0-1.0)
- **LinkType** — тип ссылки: dofollow (1.5), nofollow (1.0), UGC/sponsored (0.7)
- **AccessFactor** — доступность размещения: бесплатный (1.5), бартер (1.2), платный до 5K руб (1.0), платный >5K руб (0.8)

Пороги: >1.5 = TIER 1, 1.0-1.5 = TIER 2, 0.5-1.0 = TIER 3-4, <0.5 = пропустить.

## SEO-правила DrMax + Шакин (обновлено 2026-03-08)

### Отбор доноров (9 обязательных проверок)
- Органический трафик (Semrush/Similarweb): главный интегральный показатель качества
- Трафик/страницы: каждая страница генерирует минимум 1–3 уникальных посетителя
- Минимум 50–100 тематических ключевых слов в ТОП-20
- Визуальный осмотр: сайт не должен выглядеть как спам/контентная ферма
- RDS Bar: сайт не продаёт ссылки на биржах автоматически (80% — признак качества)
- Нет "ядовитых" категорий (adult, gambling, poker, фарма-спам)
- График трафика: стабильный или растущий, без аномальных провалов
- Провалы трафика: сопоставить с датами алгоритмических апдейтов (Penguin, Panda, Core Updates)
- Соотношение индексированных страниц к трафику: аномально высокое = контентная ферма

### Красные флаги — НЕ брать ссылки
- Сайт продаёт ссылки автоматически через биржи
- Трафик из нетематических категорий
- Резкие провалы, совпадающие с антиспам-апдейтами
- Тематика страниц с исходящей ссылкой не совпадает с тематикой реципиента

### Типы анкоров и соотношение (DrMax-модель)
- Безанкорные ("здесь", "тут", URL): 30–40% от общей массы
- Брендовые (название компании, домен): 20–30%
- Тематические (описание темы, не ключ): 15–20%
- Ключевые (точное вхождение): не более 5–10% (риск Penguin/Минусинск)
- Разбавленные ("узнать подробнее о продвижении"): 10–15%
- Правило: для внешних ссылок — брендовые или натуральные, НЕ коммерческие точные ключи

### Исходящие ссылки с сайта (аудит раз в год)
- Ссылки только на авторитетные источники, подтверждающие утверждения
- Предпочитать первоисточники, не вторичные агрегаторы
- Анкоры исходящих: бренд-название или 2–3 слова из текста, НЕ коммерческие ключи
- Удалять: битые исходящие, sitewide исходящие, скрытые ссылки, ссылки в навигации на внешние
- Исходящая ссылка на авторитетный домен (Oxford, Wikipedia) с брендовым анкором — улучшает доверие
- Закрывать nofollow: счётчики, виджеты, партнёрские ссылки

### Скорость наращивания ссылок
- Новый сайт (до 1 года): 5–10 ссылок в месяц (аномальный рост = фильтр)
- Зрелый сайт: пропорционально текущей скорости роста ссылочной массы
- Резкий прирост за 1–2 недели — красный флаг для Минусинск и Penguin
- PBN-ссылки: равномерно, не более 20% от общей массы

### Токсичные ссылки (протокол дизавоу)
- Аудит бэклинков: раз в квартал (Semrush Backlink Audit, Ahrefs)
- Токсичные: отклонять через Google Disavow Tool
- Удалять: со спам-сайтов, ссылочных ферм, нетематических каталогов
- Показатели качества донора: Trust Flow, Domain Rating, органический трафик

### Внутренняя перелинковка (семантический кокон)
- Трёхуровневая иерархия: мать (ВЧ) → дочерние → внучатые (узкая тема)
- Минимум 3 лексических вариации анкора для каждой внутренней ссылки
- Контекст вокруг ссылки: 15 слов с каждой стороны
- SILO: внутри кластера свободно, между кластерами — только при семантической связи
- Все страницы доступны в не более 3 кликов от главной
- Фокус на ссылках из тела контента, не из навигации (меню/футер не передают вес как контентные)

# Реклама в Max через Яндекс.Директ

Запуск рекламы в мессенджере **Max** (российский, экосистема VK/Госуслуги) через Я.Директ. Источник: [eLama гайд](https://elama.ru/blog/reklama-v-max-cherez-yandex-direct/). Проверено 2026-05-29.

## Когда применять

- Клиенту нужен новый охватный канал в РФ помимо РСЯ/Поиска
- Низкая конкуренция + дешёвый клик важнее точного таргета
- B2C-охват на широкую аудиторию РФ
- Раннее тестирование площадки «раньше конкурентов»

**Плюсы Max:** ~60 млн DAU (март 2026), 300к публичных каналов, низкая баннерная слепота, минимальный риск блокировки (официальный РФ-мессенджер), выгодный CPC.

## Тип кампании

В Я.Директе: **«Реклама в мессенджерах»** → «Автоподбор каналов», ИЛИ **Единая перфоманс-кампания (ЕПК)** с выбором мессенджеров в блоке «Места показа». Можно Max + Telegram вместе.

## Форматы объявлений

| Элемент | Требование |
|---------|-----------|
| **Текст** | до 820 символов: заголовок ≤56, тело ≤764. Форматирование: **жирный**, *курсив*, подчёркивание, зачёркивание, списки |
| **Эмодзи** | до 5 из разрешённого списка (👍😊👌❤️⚡✨ и др.) |
| **Изображения** | 1-10 шт. Соотношения 1:1–3:4 / 4:3: 450-5000px по стороне. 16:9: 1080×607–5000×2812px. Макс 10 МБ, JPG/PNG |
| **Видео** | 1 шт (вместо изображений) |
| **Кнопка CTA** | текст действия выбирается |

> Размеры изображений совпадают с РСЯ — см. `~/artvision-data/.claude/rules/yandex-direct-creatives.md`.

## Бюджет и ставки

- **Оплата только за клики** (других моделей нет)
- Минимальный дневной бюджет: **от 300 ₽**
- Минимальная ставка за клик: **от 30 ₽**
- Стратегия: «Максимум кликов» с ограничением недельного бюджета

## Таргетинг

- **География:** только Россия (рекомендуется вся страна — многие каналы не привязаны к регионам)
- **Тематики:** выбор из списка ИЛИ свободное описание
- **Корректировки ставок:** применяются к каналам целиком (Яндекс пока НЕ рекомендует использовать)
- Система даёт прогноз охвата подписчиков + долю релевантных каналов

## Пошаговый запуск (9 шагов)

1. Вход в кабинет Я.Директа
2. Создать новую кампанию → тип «Реклама в мессенджерах»
3. Отметить **Max** (или Max + Telegram)
4. Указать недельный бюджет, ставку за клик, счётчик Метрики
5. Задать период размещения, исключить нежелательные каналы
6. География = Россия, тематики, корректировки (по умолчанию не трогать)
7. Добавить ссылку, текст, изображения/видео, **UTM-метки** (`utm_source=yandex&utm_medium=messenger&utm_campaign=...&utm_content={ad_id}`)
8. «Запустить кампанию»
9. Отслеживать в Мастере отчётов + Я.Метрике

## Модерация — ВАЖНО

- Объявления проходят **2 этапа** модерации (требования РСЯ + законодательство РФ)
- ⚠️ **Объявление автоматически удаляется через 48 часов** после размещения — для постоянной кампании нужно обновлять/перезапускать
- Запрет контактов (URL/email/телефон) на изображении — как в РСЯ

## API (Я.Директ v5)

Кампания «Реклама в мессенджерах» создаётся через тот же v5 API что и обычные (campaigns/add с типом мессенджер-кампании). Детали API-полей для мессенджер-кампаний — уточнить в офсправке `yandex.ru/dev/direct` (TBD: не проверял API-схему для этого типа, статья описывает UI-флоу).

## Чеклист перед запуском

- [ ] Тип кампании = «Реклама в мессенджерах» / ЕПК с Max
- [ ] Недельный бюджет (мин 300₽/день × 7 = 2100₽/нед), ставка ≥30₽
- [ ] Текст ≤820 (заголовок ≤56), ≤5 эмодзи
- [ ] Изображения в валидных размерах (см. yandex-direct-creatives.md), без контактов на картинке
- [ ] UTM с динамикой + счётчик Метрики привязан
- [ ] Гео = Россия, тематики заданы
- [ ] Учтено авто-удаление через 48ч (план обновления для долгих кампаний)

# /meeting-set — поставить встречу из русского текста

Обёртка над `~/.claude/scripts/set-meeting.sh`. Принимает естественный текст, превращает в событие календаря + задачу Asana + строку в TODO.md.

## Когда применять

Пользователь говорит «поставь встречу…», «забей созвон с Андреем завтра в 14:00», «meeting с клиентом 5 июня 15:00 на час», «забронируй время в пятницу 10:30».

## Что НЕ делает skill сам

- НЕ дублирует логику Google Calendar — `set-meeting.sh` уже сам создаёт событие в macOS Calendar И (если настроен `~/.claude/.cache/gcal-token.json`) дублирует в Google Calendar через `gcal.py`. Skill только вызывает скрипт.
- НЕ ставит assignee в Asana автоматически (правило `asana-required-fields.md` + запрет автоназначения с 30.04.2026). С кем встреча — это участник события, НЕ исполнитель задачи.

## Алгоритм (пошагово)

### Шаг 1. Узнать сегодняшнюю дату

Выполнить `date '+%Y-%m-%d %A'` через Bash, чтобы корректно резолвить относительные даты. Не угадывать.

### Шаг 2. Распарсить из текста

Извлечь поля:

| Поле | Как извлекать | Дефолт |
|------|---------------|--------|
| **Дата** | абсолютная («5 июня», «15.05») или относительная → перевести в `YYYY-MM-DD` | обязательно, иначе спросить |
| **Время** | «в 10:30», «14:00», «в 9 утра» → `HH:MM` | обязательно, иначе спросить |
| **Длительность** | «на час» → 60, «на 30 минут» → 30, «на 1.5 часа» → 90 | **60** мин |
| **Название/с кем** | «созвон с Андреем», «встреча Univers Clinic» → строка title | из контекста; «Встреча» если пусто |
| **Место/ссылка** (опц.) | Zoom/Meet/адрес → в `--desc` | пусто |

Относительные даты считать от сегодня (Шаг 1):
- «завтра» → +1 день; «послезавтра» → +2
- «в пятницу»/«в пт» → ближайшая будущая пятница (если сегодня уже пятница и время прошло — следующая)
- «через неделю» → +7 дней
- дни недели рус: пн/вт/ср/чт/пт/сб/вс

Если дата или время неоднозначны/отсутствуют — задать ОДИН уточняющий вопрос, не выдумывать.

### Шаг 3. Вызвать set-meeting.sh

Точный синтаксис (соответствует реальным аргументам скрипта):

```bash
~/.claude/scripts/set-meeting.sh \
  --date 2026-06-05 \
  --time 15:00 \
  --dur 60 \
  --title "Созвон с Андреем — Творим" \
  --desc "Zoom: https://..." \
  --alarm-hours-before 22
```

Обязательные флаги: `--date YYYY-MM-DD`, `--time HH:MM`, `--title`. Опциональные: `--dur` (мин, дефолт 60), `--desc`, `--calendar` (по умолчанию fallback-цепочка «Рабочий» → antoniokmr@gmail.com → «Домашний»), `--alarm-hours-before` (дефолт 22).

Скрипт выводит `OK: <title> in <calendar>` при успехе и сам сообщает про Google Calendar (продублировал / gcal-token нет). Проверить stdout на `OK:`.

### Шаг 4. Создать задачу/событие в Asana

Через `mcp__asana__asana_create_task`:
- `name` = title встречи
- `due_on` = дата встречи (`YYYY-MM-DD`)
- `projects` / project_id — по контексту (клиент → его проект, иначе спросить «В какой проект?» или поставить в presale/ops по теме)
- `notes` = время + длительность + место/ссылка + «с кем»
- **assignee НЕ ставить автоматически.** Если в Asana нужен исполнитель — создать без assignee и спросить «Кто исполнитель?» (правило `asana-required-fields.md`). С кем встреча ≠ исполнитель.

### Шаг 5. Дописать в TODO.md

По контексту (`todo-routing.md`):
- клиент/presale → `artvision-data/presale/TODO.md` или `clients/<slug>/`
- иначе ops → `artvision-data/TODO.md`

Строка формата:
```
- [ ] Встреча: <title> — <YYYY-MM-DD HH:MM>, <длительность>мин [type:meeting]
```

### Шаг 6. Подтвердить пользователю

Короткое подтверждение:
```
Встреча поставлена:
📅 <дата> <время>, <длительность> мин
👥 <с кем / название>
📍 <место/ссылка, если есть>
✅ macOS Calendar + Google Calendar (если настроен)
✅ Asana: <ссылка на задачу>
✅ TODO: <файл>
```

## Пример

Вход: «забей созвон с Андреем завтра в 14:00 на час, обсудить Творим»

1. `date` → сегодня 2026-05-29 → завтра = 2026-05-30
2. дата=2026-05-30, время=14:00, dur=60, title=«Созвон с Андреем — Творим»
3. `set-meeting.sh --date 2026-05-30 --time 14:00 --dur 60 --title "Созвон с Андреем — Творим"`
4. Asana task: name=«Созвон с Андреем — Творим», due_on=2026-05-30, без assignee
5. TODO: `- [ ] Встреча: Созвон с Андреем — Творим — 2026-05-30 14:00, 60мин [type:meeting]`
6. подтверждение

## Связанные

- `~/.claude/scripts/set-meeting.sh` — исполнитель (macOS Calendar + GCal-дубль)
- `~/.claude/scripts/gcal.py`, `gcal-bootstrap.sh` — Google Calendar OAuth (одноразовая настройка)
- `asana-required-fields.md` — assignee/due_on/project_id, запрет автоназначения
- `todo-routing.md` — куда дописывать TODO
- `protocol-to-asana` — если встреча породила список задач

# GLM — Zhipu AI модели из Claude Code

## Использование

Пользователь пишет `/glm <промпт>` — ты вызываешь GLM модель и возвращаешь результат.

## Модели

| Модель | Стоимость | Контекст | Когда использовать |
|--------|-----------|----------|-------------------|
| `glm-4.5-flash` | **БЕСПЛАТНО** | 131K | По умолчанию — тексты, рерайт, анализ |
| `glm-5` | $0.80/$2.56 за 1M | 128K | Сложный reasoning, agentic tasks |

## Синтаксис

```
/glm Напиши SEO-текст про...
/glm --model glm-5 Сложная задача...
/glm --save clients/name/texts/result.md Текст промпта
```

## Инструкции для Claude

1. **Парсинг аргументов:**
   - Если указан `--model glm-5` → использовать GLM-5 (предупредить о стоимости ~$0.01 за запрос)
   - Если указан `--save <path>` → сохранить результат в файл
   - Всё остальное = промпт

2. **Выполнение:**
   ```bash
   python3 /Users/antonk/artvision-data/scripts/glm_chat.py "<промпт>" [--model MODEL] [--save PATH]
   ```

3. **После выполнения:**
   - Показать результат пользователю
   - Если `--save` → сообщить куда сохранено
   - Если нужно → предложить доработать результат

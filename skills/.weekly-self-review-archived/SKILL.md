# Weekly Self-Review — Самоанализ агента

## Цель
Раз в неделю агент проводит ревизию своей работы и предлагает улучшения.

## Процесс

### ШАГ 1: Сбор данных о сессиях
```bash
# Последние 7 дней сессий
python3 ~/.claude/scripts/claude-sessions.py --all --days 7
```

### ШАГ 2: Анализ паттернов

Прочитай историю сессий и найди:

1. **Повторяющиеся ошибки** — что Claude делал неправильно больше 1 раза?
2. **Потерянное время** — где были лишние итерации, переделки?
3. **Удачные решения** — что сработало хорошо и стоит закрепить?
4. **Новые инструменты/подходы** — что пользователь показал/попросил нового?
5. **Пробелы в знаниях** — где Claude не знал как сделать?

### ШАГ 3: Предложения по улучшению

На основе анализа предложи конкретные правки в:

1. **CLAUDE.md** (`~/.claude/CLAUDE.md`) — новые правила, обновление существующих
2. **MEMORY.md** (`~/.claude/projects/-Users-antonk/memory/MEMORY.md`) — новые уроки
3. **Скиллы** — новые скиллы или доработки существующих
4. **Хуки** — новые защитные хуки
5. **Агенты** — настройка или создание агентов

### ШАГ 4: Формат отчёта

```markdown
# Weekly Self-Review: DD.MM.YYYY — DD.MM.YYYY

## Статистика
- Сессий за неделю: N
- Из них прерванных: N
- Основные темы: ...

## Ошибки и уроки
| Ошибка | Частота | Предложенный фикс | Файл для правки |
|--------|---------|-------------------|-----------------|

## Удачные решения
- ...

## Предложения по CLAUDE.md
```diff
+ Новое правило: ...
- Устаревшее правило: ...
```

## Предложения по MEMORY.md
- ...

## Новые скиллы/хуки
- ...
```

### ШАГ 5: Применение

- Показать отчёт пользователю
- Дождаться подтверждения
- Применить одобренные изменения
- Git commit + push

## Расписание
- **Когда:** Воскресенье вечером (или по запросу)
- **Автозапуск:** LaunchAgent `com.claude.weekly-self-review`

## Важно
- НЕ применять изменения автоматически — только после подтверждения
- Фокус на КОНКРЕТНЫХ правках, не общих рекомендациях
- Каждое предложение = конкретный diff в конкретном файле

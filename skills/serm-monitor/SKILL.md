# Skill: serm-monitor

## Metadata
- **Name:** serm-monitor
- **Description:** SERM мониторинг репутации: отслеживание отзывов, анализ фейков, алерты при негативе. Artvision Pulse.
- **Triggers:** serm, репутация, отзывы, мониторинг отзывов, reputation, review monitoring, pulse

## Pipeline

```
Сбор отзывов с площадок → Анализ новорегов/фейков → Дашборд → Алерты
```

### 1. Сбор отзывов с площадок

Целевые платформы:
- Яндекс.Карты
- Google Maps
- 2ГИС
- Отзовик (otzovik.com)
- iRecommend
- Flamp
- Zoon

Частота: ежедневно (Старт), каждые 4 часа (Бизнес+), real-time по возможности (Про+).

### 2. Анализ фейков и аномалий

**Методы детекции:**

| Метод | Описание | Индикатор |
|-------|----------|-----------|
| **Cross-platform rating discrepancy** | Расхождение рейтинга между площадками >1.5 балла | Накрутка на одной из площадок |
| **New account ratio** | Доля авторов с 1-2 отзывами (новореги) | >40% новорегов = подозрительно |
| **Template text detection** | Повторяющиеся фразы, шаблонные конструкции | Заказные отзывы |
| **Dumbbell distribution** | Распределение только 1-звёздочных и 5-звёздочных | Война отзывов / накрутка |
| **Otzovik "ordered reviews" flag** | Системная метка Отзовика о заказных отзывах | Прямой индикатор фейка |
| **Temporal clustering** | Всплеск отзывов за короткий период | Кампания по накрутке/атаке |
| **Sentiment-rating mismatch** | Позитивный текст + 1 звезда (или наоборот) | Ошибка или манипуляция |

### 3. Дашборд

- Сводный рейтинг по всем площадкам
- Динамика рейтинга (тренд за неделю/месяц/квартал)
- Карта площадок с текущими оценками
- Топ-5 последних отзывов (позитив/негатив)
- Индекс подозрительности (% вероятных фейков)
- Сравнение с конкурентами (интеграция с Artvision Scout)

### 4. Алерты

- **Критический:** новый негативный отзыв (1-2 звезды) → TG мгновенно
- **Важный:** рейтинг упал на 0.3+ за неделю → TG ежедневно
- **Информационный:** еженедельная сводка → TG/email

## Интеграции

- **Artvision Scout** — данные о конкурентах (рейтинги, отзывы, динамика)
- **Artvision Flow** — автоматизация ответов на отзывы (шаблоны + роутинг)
- **TG-бот** — алерты и быстрые действия

## Порядок работы (при вызове скилла)

1. Определить клиента и его точки на картах/площадках
2. Собрать текущие рейтинги по всем доступным площадкам
3. Провести первичный аудит: фейки, аномалии, расхождения
4. Сформировать базовый отчёт с рекомендациями
5. Предложить подходящий тариф
6. Настроить мониторинг и алерты (при подключении)

## Метрики эффективности

- Средний рейтинг по площадкам (цель: 4.5+)
- Время реакции на негатив (цель: <2 часов)
- Доля отзывов с ответом (цель: 100%)
- Динамика рейтинга за период (цель: рост или стабильность)

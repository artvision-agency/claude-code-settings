# gsheet-cell-color — чтение цветовой разметки таблицы (детерминированно)

> Захвачено из работы Fable 5 (2026-06-12, нашла красные #CC0000 в D13/D16 по styles.xml) · упаковано Opus 4.8 · правило `capture-wins-as-skills`.
> Связано: `numbers-deterministic-meaning-llm.md` (цвет/данные — кодом, не LLM), `proven-tools-first.md`.

## Когда применять
Пользователь/клиент размечает таблицу ЦВЕТОМ (красным = не трогать/проблема, зелёным = готово, жёлтым = в работе) и нужно прочитать ЭТУ разметку программно. Триггеры выше. Типично: «сделай что выделено / не трогай красное», парс статус-таблиц, выгрузок с цветовой легендой.

## Когда НЕ применять
- Нужны значения ячеек (не цвет) → обычный csv/xlsx read.
- Цвет через условное форматирование (conditional formatting) — это правило/формула, не статичная заливка → парсить `conditionalFormatting` отдельно (сложнее; пометить и решать по месту).

## Метод (детерминированно, без OCR/LLM)
1. Google Sheets → **export xlsx**: `https://docs.google.com/spreadsheets/d/<ID>/export?format=xlsx` (если расшарен по ссылке) ИЛИ скачать .xlsx.
2. xlsx = zip. Парс **заливки ячеек**: `xl/styles.xml` (`<fills>` → `<patternFill><fgColor rgb="FFCC0000"/>`) + `cellXfs` (какой fillId у стиля) + `xl/worksheets/sheetN.xml` (ячейка → `s="<styleIdx>"`).
3. Скрипт `parse_colors.py` (рядом) — отдаёт: лист → {ячейка: ARGB-цвет} для НЕ-белых/не-пустых заливок. Группирует по цвету (красные/зелёные/…).
4. Цвет → смысл по легенде задачи (красный=не трогать и т.п.). Легенду подтвердить у пользователя, не угадывать какой цвет что значит.

## Скрипт
`parse_colors.py <file.xlsx> [sheet]` — openpyxl если есть, иначе stdlib zipfile+xml.etree (fallback). Выводит ячейки с заливкой + ARGB + группировку по цвету. Conditional formatting НЕ покрывает (статичная заливка только).

## Антипаттерны
- ❌ Читать цвет «на глаз» по скриншоту/OCR когда есть xlsx (детерминированный парс точнее — numbers-deterministic).
- ❌ Угадывать смысл цвета без легенды пользователя.
- ❌ Путать статичную заливку с условным форматированием.

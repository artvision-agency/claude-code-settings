# Protocol → Asana — превратить итоги созвона в задачи

## Когда применять

- После клиентского созвона (есть нумерованный список решений)
- Voice-сообщение с перечислением пунктов
- Текст вида «1. … 2. … 3. …»
- Любой brain-dump который надо разнести по Asana

## ОБЯЗАТЕЛЬНЫЕ правила (не нарушать)

| Правило | Источник |
|---------|----------|
| 3 поля обязательны: `assignee`, `due_on`, `project_id` | `~/.claude/rules/asana-required-fields.md` |
| **НЕ автоназначать assignee** — спросить | то же правило, секция «ЗАПРЕТ автоназначения» (с 30.04.2026) |
| Хук `pre-asana-required-fields.sh` блокирует без полей | `~/.claude/hooks/` |
| Project: если клиент указан → его проект; иначе «Задачи - Artvision» (1212305892582815) | `~/.claude/projects/-Users-antonk/memory/accounts.md` |

## Workflow

### Шаг 1. Парсинг протокола
- Нумерованный список (1. … 2. … или «- …»)
- Каждый пункт = отдельная задача
- Извлечь имя задачи (первая фраза/строка) + контекст (остальное)

### Шаг 2. Найти проект Asana
```python
# Если упомянут клиент (Madwave, Avto.World, etc.):
mcp__asana__asana_search_projects(name_pattern="<client>")
# Иначе → 1212305892582815 (Задачи - Artvision)
```

### Шаг 3. Предложить даты (НЕ выдумывать)
- По умолчанию: due = today + 7 дней
- Если в тексте «срочно» / «сегодня» → today
- Если «на следующей неделе» → today + 7
- Если есть конкретный месседж типа «в среду» → ближайшая среда
- Если непонятно → СПРОСИТЬ

### Шаг 4. ЗАПРОСИТЬ assignee у пользователя
```
| # | Задача | Предложенный due | Кто? |
| 1 | ... | YYYY-MM-DD | ? |
| 2 | ... | YYYY-MM-DD | ? |

Скажи: "1=Андрей, 2=Антон, 3=Стас, 4=Claude" (или me)
```

**ЗАПРЕЩЕНО** угадывать assignee по типу задачи / клиенту / истории.

### Шаг 5. Создание задач (только после получения assignee)
```python
for item in items:
    mcp__asana__asana_create_task(
        project_id=...,
        name=f"[Протокол {date} п.{n}] {title}",
        due_on=...,
        assignee=...,  # из ответа пользователя
        notes=f"Источник: {meeting_context}\n\n{full_item_text}\n\nКанал: Claude Code, инициатор: Антон."
    )
```

### Шаг 6. Закрыть исходный pre-task (если был)
- Закрыть задачу созвона `completed=true`
- В notes исходной задачи приписать: «Подзадачи созданы, GIDs: …»

### Шаг 7. Записать в context-log клиента
```
clients/[name]/context-log.md:
## YYYY-MM-DD созвон
- Протокол: N пунктов → Asana
- Подзадачи: GID1, GID2, ...
```

## Output

Сводная таблица в чате:
```markdown
| # | Задача | Asana | Due | Assignee |
|---|--------|-------|-----|----------|
| 1 | ... | [link](permalink) | YYYY-MM-DD | Андрей |
| 2 | ... | [link](permalink) | YYYY-MM-DD | Claude |
```

## Anti-patterns

- ❌ Создать без assignee → хук заблокирует
- ❌ Выдумать assignee «обычно это Андрей» → нарушает правило
- ❌ Поставить due «когда-нибудь» → due_on пустой → блок
- ❌ Не привязать к проекту клиента → задача потеряется в общей куче
- ❌ Не записать в context-log → след сессия не увидит

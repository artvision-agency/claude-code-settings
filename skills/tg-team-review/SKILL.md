# TG Team Review — action items из переписки команды

## Алгоритм

### Шаг 1. Получить переписку

Если передан путь к файлу — читать его напрямую (Read).

Если chat-id не указан — использовать ID Андрея Киселева по умолчанию:

```bash
python3 ~/.claude/scripts/tg-chat-export.py \
  --chat-id 1857522687 \
  --limit 500 \
  -o /tmp/tg-review.md
```

Добавить `--since YYYY-MM-DD` если пользователь указал период.

### Шаг 2. Прочитать экспорт

```
Read /tmp/tg-review.md
```

### Шаг 3. Извлечь action items

Искать незакрытые задачи по сигналам:

**Глаголы-триггеры:** надо, нужно, сделать, проверить, убрать, добавить, оплатить,
отправить, поправить, запустить, согласовать, напомнить, подготовить, уточнить.

**Паттерны завершения (пропускать):** готово, сделал, отправил, проверил, закрыли,
ок, +, done.

Для каждой найденной задачи определить:

| Поле | Как определить |
|------|----------------|
| Текст | Сформулировать глагол + объект одной строкой |
| Клиент | По упоминанию имени/бренда (см. маппинг ниже) |
| Ответственный | Антон (если «я», «сам», «пришли мне») / Киселев (если «ты», «Андрей», обращение) / неясно |
| Срочность | горит (сегодня/срочно/горит) / нормально (эта неделя) / потом (когда-нибудь) |

### Шаг 4. Показать таблицу и ждать подтверждения

Вывести таблицу:

```
| # | Задача | Клиент | Ответственный | Срочность |
|---|--------|--------|---------------|-----------|
| 1 | ...    | ...    | ...           | ...       |
```

Спросить: «Создать задачи в Asana? Можно исключить номера или скорректировать.»

Не создавать задачи до явного подтверждения Антона.

### Шаг 5. Создать задачи в Asana

После подтверждения — для каждой задачи из списка:

```
mcp__asana__asana_create_task:
  name: "<текст задачи>"
  project_id: "<project_id из маппинга>"
  notes: "Источник: TG-переписка с Киселевым, <дата экспорта>"
```

Правила по полям (из asana-required-fields.md):
- `assignee` — ТОЛЬКО если Антон явно указал исполнителя. Иначе не ставить.
- `due_on` — ТОЛЬКО если в сообщении был конкретный срок. Иначе не ставить.

После создания — показать итоговый список с ссылками на задачи.

## Форматы задач в Asana

Шаблон названия: `[Клиент]: <глагол + объект>`

Примеры:
- `OTIDO: проверить позиции после апдейта`
- `BluMart: добавить 10 отзывов на ЯК`
- `Творим: отправить отчёт за апрель`
- `internal: согласовать цены на новые услуги`

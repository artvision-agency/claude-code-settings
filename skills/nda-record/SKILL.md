# NDA-safe запись (Artvision Insight — Privacy-First модуль)

## Назначение
Консультант ведёт запись/одностороннюю трансляцию своей работы для клиента (формат «реалити-шоу»:
лицо + голос + доска для рисования, экран НЕ показывается). Имена/бренды ДРУГИХ клиентов под NDA
должны быть заглушены.

## 🔴 ГЛАВНОЕ ПРАВИЛО (NDA = высокая ставка, round_table подтвердил)
- **Алиасы (кодовые имена) — ОСНОВНАЯ защита.** Не произносить настоящие названия.
- **Авто-редактура — СТРАХОВКА, не гарантия.** whisper может ослышаться → имя не заглушится.
  → **Перед передачей клиенту ОБЯЗАТЕЛЬНО прослушать `-CLEAN.wav` человеком.**
- Real-time «пик» по словам в живом эфире НЕ применять (пропуски = нарушение).
- Двусторонний живой созвон → задержка эфира ломает диалог; для NDA там только алиасы.
  Одностороннее вещание/запись (реалити-шоу) → задержка 8–10 сек + редактура работают.

## Инструменты (всё стоит локально)
- `~/.claude/scripts/nda-record.sh` — start/stop/redact/status/devices
- `~/.claude/scripts/nda_redact.py` — whisper-json → silence на NDA-словах + ███ в тексте (pymorphy3)
- Записи + стоп-лист: `~/Documents/nda-record/` (ЛОКАЛЬНО, НЕ в git — NDA-данные)

## Рабочий цикл (звук)
1. **Стоп-лист**: `~/Documents/nda-record/stoplist.txt` — по одному слову/токену (фамилии, бренды).
   Морфология ловит падежи: «Петров» заглушит и «Петрову», «Петровым».
2. **Старт**: `nda-record.sh start` (пишет с микрофона `:1` = MacBook; сменить — `NDA_MIC=:0`).
   ⚠️ Отдельный мик для записи! Если диктуешь голосом в Claude через тот же мик — конфликт.
3. **Стоп**: `nda-record.sh stop` → авто-транскрипция + редактура.
4. Выход: `*-CLEAN.wav` (делиться) · `*-CLEAN.txt` · `*-REDACTIONLOG.txt` (что заглушено, локально) ·
   `raw-*.wav` (сырое, приватно, удалять после проверки).
5. **Прослушать CLEAN человеком** → только потом клиенту.

## Точность (меньше дыр NDA)
- Модель: `NDA_MODEL=medium` (или large) для боевого NDA — точнее, реже ослышки. small = черновик.
- У Антона есть voicemode whisper-server (large-v3-turbo) — кандидат для скорости+точности (TODO интеграция).

## Видео-часть (реалити-шоу картинка) — отдельно, нужен OBS
- OBS Studio (бесплатно) → сцена: камера (лицо) + окно (доска Excalidraw/iPad) → Виртуальная камера.
- В Zoom/Телемост выбрать «OBS Virtual Camera». Экран НЕ шарить.
- Live-вещание клиенту: задержка эфира в OBS 8–10 сек как страховка к алиасам.

## Юр.-обвязка (round_table, для боевого NDA)
- Шифровать/удалять сырое после редакции · согласие участников на запись · аудит-лог замен (есть).
- Пост-редакция сама по себе НЕ достаточна юридически — связка алиасы + редактура + проверка человеком.

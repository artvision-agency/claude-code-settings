# HR Vacancy — HR операции

## Цель
Закрыть HR-задачу: подготовить вакансию / тестовое / онбординг / offboarding. Работает с вакансиями Artvision **и** клиентов (upsell — см. `feedback_vacancy_upsell.md`).

## Когда вызывается
- Ключевые слова: вакансия, найм, hire, увольнение, onboarding, offboarding
- Клиент упомянул что у него уходит сотрудник (триггер upsell)
- Задача в комбайне категории `hr`

## Процесс

### ШАГ 1: Определить тип задачи

| Тип | Результат |
|-----|-----------|
| Новая вакансия Artvision | Описание + тестовое + план интервью |
| Новая вакансия клиента (upsell) | КП на размещение + описание + публикация |
| Тестовое задание | TZ с критериями оценки |
| Onboarding | Чеклист первых 7/30/90 дней |
| Offboarding | Чеклист доступов, передачи, документов |

### ШАГ 2: Для новых вакансий — сбор контекста

- Роль, грейд, ЗП-вилка, формат (удалёнка/офис/гибрид)
- Для клиентских вакансий: ниша клиента, бренд, стиль
- Если клиент: проверить `clients/<c>/CLAUDE.md` на бренд-табу

### ШАГ 3: Шаблон вакансии

Использовать `~/.claude/templates/vacancy.md` (если нет — создать из `hh_leadgen` проекта).

Обязательные секции:
1. О компании / клиенте (1 абзац)
2. Задачи (bullet list, 5-7 пунктов)
3. Требования (must-have / nice-to-have)
4. Условия (ЗП, формат, график)
5. Как откликнуться (ответ на 3 вопроса + пример работ)

### ШАГ 4: Тестовое задание

- Привязано к реальной задаче, не синтетика
- Время: 2-4 часа max
- Критерии оценки: 5-7 пунктов с весами

### ШАГ 5: Публикация

| Канал | Как |
|-------|-----|
| hh.ru | через `products/hh-leadgen` парсер (у нас есть логин) |
| Telegram | канал @artvision_hr + релевантные чаты |
| LinkedIn | через Антона (CONFIRM) |
| Сайт клиента | WordPress/MODX publish (CONFIRM) |

### ШАГ 6: Upsell (для клиентских)

Если задача возникла из контекста клиента (у них уходит сотрудник):
1. Создать КП на размещение вакансии
2. Расценки: 5-10K RUB за вакансию, пакет 25K за 5 вакансий
3. Отправить в CONFIRM-батч с пометкой `💼 UPSELL`

## Запреты
- Не писать клише ("молодой дружный коллектив", "печеньки", "рынок ЗП")
- Не обещать вилки выше согласованных с клиентом
- Не публиковать без CONFIRM если клиентская
- Не использовать AI/нейросети в описании вакансии

## Связанные
- `products/hh-leadgen/` — парсер hh.ru + лидогенерация
- `feedback_vacancy_upsell.md` — правило апселла при увольнении
- `clients/<c>/CLAUDE.md` — бренд-правила клиента

# Finance Ops — Финансовые операции

## Цель
Подготовить финансовую операцию к исполнению человеком. **Сам Claude НЕ выполняет переводы/платежи** — собирает данные и формирует чеклист для Антона/Андрея.

## Когда вызывается
- Задача в комбайне помечена `finance` или содержит "пролив", "счёт", "перевод", "акт"
- `human_only: true` всегда — деньги требуют человека

## Процесс

### ШАГ 1: Парсинг задачи
Извлечь:
- **Тип операции:** пролив / перевод / счёт / акт / сверка
- **Сумма:** число + валюта
- **Клиенты/контрагенты:** кто → кому
- **Источник средств:** карта, р/с, ИП, ООО
- **Срок:** когда нужно сделать

### ШАГ 2: Сбор контекста
- `grep -r "<клиент>" ~/artvision-data/finance/` — история операций
- `tokens.json` — реквизиты контрагента, если есть
- Asana — есть ли дубли этой операции
- Договор с клиентом (если перевод) — ставка, условия

### ШАГ 3: Чеклист для Антона (результат)

Создать Markdown в `artvision-data/finance/pending/<дата>-<тип>.md`:

```markdown
# <Дата> — <Тип операции>

## Что делаем
- Операция: <пролив/перевод/счёт>
- Сумма: <X> RUB
- От: <юрлицо/счёт>
- Кому: <контрагент + реквизиты>
- Срок: <дата>

## Реквизиты получателя
- ИНН: —
- Р/с: —
- Банк: —
- Назначение платежа: —

## Обоснование
- Договор: <ссылка>
- Основание: <акт/счёт/пролив бюджета за <период>>

## Чеклист выполнения (для Антона)
- [ ] Проверить баланс источника
- [ ] Сформировать платёжку
- [ ] Отправить в банк
- [ ] Скинуть чек в Asana task <gid>
- [ ] Обновить `finance/done/` + `client-revenue.md`

## Связанные документы
- Asana: <ссылка>
- Предыдущая операция: <ссылка>
```

### ШАГ 4: Отправить в CONFIRM-батч
Операция идёт в финальный CONFIRM-батч комбайна с пометкой `💰 FINANCE`.
**Антон получает файл + ссылку в Asana + напоминание в TG.**

## Запреты
- Никогда не пытаться выполнить платёж самостоятельно (API банков, СБП)
- Не раскрывать реквизиты счетов в публичных каналах
- Не хранить детали в session logs — только в `finance/pending/`

## Связанные файлы
- `artvision-data/finance/pending/` — ожидающие операции
- `artvision-data/finance/done/` — выполненные (с чеками)
- `artvision-data/client-revenue.md` — реестр доходов
- `schedule/reports-invoices.json` — расписание счетов

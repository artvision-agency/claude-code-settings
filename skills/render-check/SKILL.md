# render-check — рендерятся ли картинки (0 токенов)
```bash
python3 ~/.claude/scripts/render_check.py <url> [url2 ...]
```
Выход: url | всего img | OK | BAD + список проблемных (not-loaded/hidden). Код 1 если есть проблемы (для гейтов перед «готово»).
Применять ПОСЛЕ деплоя любой страницы с фото/галереей — вместо «снял скрин, посмотрел» (дёшево, детерминированно). Дополняет vision-validate (тот про качество/уместность, этот — про факт рендера).

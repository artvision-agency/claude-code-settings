# skill-audit — зеро-токен аудит скиллов

> Захвачено 2026-06-26 (Антон: «создать скиллы чтобы работало в плюс и ноль токенов»). То что делали руками в чате (искали дубли/конфликты) → детерминированный скрипт.

## Запуск
```bash
python3 ~/.claude/scripts/skill_audit.py [prefix] [--twins 0.45]
# пример: python3 ~/.claude/scripts/skill_audit.py seo
```

## Что находит (0 LLM-токенов)
1. **Конфликт триггеров** — слово → 3+ скиллов (fuzzy выбирает наугад). Обычно от «kitchen-sink» больших скиллов (seo-master/seo/external-tools перечисляют ВСЁ → бьются с узкими).
2. **Близнецы** — сходство описаний ≥ порога (кандидаты на слияние).
3. **Полнота** — тонкие скиллы (<60 строк, 0 доп.файлов).

## Не делает
Не удаляет, не правит. Только отчёт. Слияние/разведение триггеров — решение человека (деструктивно → approve).

## Как чинить по отчёту
- Конфликт от большого скилла → **сузить его триггеры** (узкие скиллы owns свою нишу), НЕ сливать функциональные куски (нужны для частичного вызова).
- Настоящий близнец (image-gen≈images) → слить в один.
- Тонкий by-design (роутер) → ок.

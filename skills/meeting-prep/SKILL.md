# Meeting Prep — Подготовка к совещаниям

## Цель
Собрать информацию по теме, создать интерактивную веб-презентацию, уметь обновлять её в реальном времени.

## Процесс

### ШАГ 1: Сбор требований
Спросить:
- Тема/цель встречи?
- Участники (кому показываем)?
- Ключевые вопросы для обсуждения?
- Нужны ли данные/метрики? Какие?
- Время на подготовку?

### ШАГ 2: Сбор информации
В зависимости от темы:
- **Клиентский отчёт**: данные из artvision-data, Asana, метрики сайта
- **Стратегия**: WebSearch по теме, конкуренты, тренды
- **Техническое**: код, архитектура, документация
- **AI/тренды**: свежие новости, исследования

### ШАГ 3: Создание презентации

Использовать Task(frontend-developer) для создания HTML:

```
Требования к презентации:
- АВТОНОМНЫЙ HTML (без CDN, без внешних зависимостей)
- Адаптивный (работает на мобильных)
- Навигация по слайдам (стрелки, свайп)
- Тёмная/светлая тема
- Печать (Ctrl+P → PDF)
- Размер < 500KB
```

Структура:
```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>{Тема} — {Дата}</title>
  <style>/* Все стили inline */</style>
</head>
<body>
  <div class="slide" id="slide-1"><!-- Title slide --></div>
  <div class="slide" id="slide-2"><!-- Content --></div>
  ...
  <script>/* Навигация inline */</script>
</body>
</html>
```

### ШАГ 4: Сохранение и доступ

```bash
# Локально
~/artvision-data/presentations/{date}_{topic}.html

# На VPS (если нужен URL)
scp -i ~/.ssh/vps_artvision file.html root@91.107.122.157:/var/www/html/presentations/
# URL: http://91.107.122.157/presentations/{file}.html
```

### ШАГ 5: Обновление в реальном времени

Во время встречи пользователь пишет:
- "добавь слайд про X" → Edit HTML → scp на VPS
- "обнови данные" → пересобрать слайд → scp
- "убери слайд 3" → Edit HTML → scp

Скорость обновления: < 60 секунд от запроса до обновления URL.

## Шаблоны слайдов

### Title Slide
- Логотип / название
- Заголовок презентации
- Дата, участники

### Data Slide
- Заголовок
- Таблица или график (CSS-only)
- Источник данных

### Comparison Slide
- 2-3 колонки
- Pros/Cons или варианты

### Action Items Slide
- Чеклист задач
- Ответственные
- Дедлайны

### Summary Slide
- Ключевые выводы (3-5 пунктов)
- Следующие шаги
- Контакты

## Важно
- Презентация АВТОНОМНАЯ (работает без интернета)
- Все шрифты системные
- Все изображения base64 (< 100KB каждое)
- Мобильная совместимость (iOS Safari!)
- НЕ использовать Tailwind JS runtime

# Posev Research — разведка площадок для посева + цены (1 команда → 2-3 вопроса → таблица)

## 📌 Что делает (простыми словами)
Находит площадки для платной рекламы-посева (посты в чатах) — чаты/каналы ЖК, районные паблики в Telegram, ВКонтакте и MAX. По каждой площадке собирает: ссылку, контакт админа, **цену размещения поста**, аудиторию. Сводит всё в таблицу с итоговым бюджетом. Что не нашлось автоматом — выдаёт списком «спросить у админа» (можно сразу задачей Андрею).

## ▶️ Как вызвать
- Голосом/текстом: «**посев площадки**», «**найди чаты ЖК**», «**цены посева**», «**собери группы района**» — или напрямую `/posev-research`.
- Дальше задаю **2-3 вопроса**: какой клиент+район, конкретные ЖК или весь район, на какие платформы (TG/ВК/MAX) и куда результат.
- Жму поиск (рой агентов) → отдаю готовую таблицу. Всё.

> **Цель:** одна команда + минимум уточнений → готовая таблица площадок (ТГ/ВК/MAX) с контактами админов, ценами размещения, аудиторией и итоговым бюджетом. Для локальных посевов (ЖК, районы, метро) клиентов Artvision.
> **PROVENANCE:** создан Opus 4.8 по запросу Антона 2026-06-19 (USmile посевы Московского р-на). Захват находки (`capture-wins-as-skills.md`).
> **Связано:** `parallel-task-orchestration.md` (рой), `service-knowledge-base.md` (telega.in как источник), `factcheck.md` (только реальные ссылки/цены), `placement-map` skill (карта посевов), `ads-max` skill (MAX-каналы).

## Когда применять
Нужно найти/обновить площадки для платного посева постов клиента: чаты/каналы ЖК, районные паблики, каналы по метро/микрорайону — в Telegram, ВКонтакте, MAX. Сбор контактов админов + цен + аудитории.

## Вход — 2-3 уточняющих вопроса (если не заданы в команде)
1. **Клиент + гео:** какой клиент и где? (город + район/метро ИЛИ готовый список ЖК). Пример: «USmile, Московский р-н СПб, метро Московская/Звёздная/Авиационная».
2. **Что собираем:** конкретные ЖК (дать список) / общерайонные паблики / и то и то.
3. **Платформы + куда результат:** TG + ВК + MAX (по умолчанию все три) · и куда писать — markdown-таблица в чат / дописать в Google Sheet (дать ссылку+gid) / файл в `clients/<slug>/ads/`.

Если Антон уже всё указал в команде — не переспрашивать, идти.

## Процесс (детерминированный)
1. **Разбить объекты** на группы по 3-4 (ЖК и/или районные кластеры).
2. **Рой `Agent(run_in_background:true)`** — general-purpose, opus, макс 3-4 параллельно (`parallel-task-orchestration`, лимит antipatterns). Каждый агент получает свою группу + ЕДИНЫЙ промпт-контракт (ниже).
3. **Консолидация:** собрать ответы → dedup по URL → severity не нужен, ранжировать по аудитории/цене → итоговый бюджет (сумма цен).
4. **Выход:** таблица + отдельный список «нужен ручной запрос админу» (что не нашлось) + строка ИТОГО бюджет.
5. **Запись:** markdown в чат всегда; в Google Sheet — если дали ссылку (см. «Запись в Sheet» ниже).

## Промпт-контракт для агента (копировать, подставить группу)
```
Найди РЕАЛЬНЫЕ контакты для платного посева рекламы (постов) в чатах/группах <ОБЪЕКТЫ: ЖК / район>, <ГОРОД, РАЙОН>.
Для КАЖДОГО объекта: ТГ-чат/канал (t.me/...), ВК-группа (vk.com/...), контакт админа (@username/способ),
ЦЕНА поста (₽ + формат: лента/закреп/сутки — часто на бирже telega.in), аудитория (подписчики).
МЕТОД: WebSearch («<объект> телеграм чат жителей», «<объект> вконтакте», «<объект> реклama telega.in»),
WebFetch t.me/s/<channel> (превью без авторизации: посты+подписчики), vk.com, telega.in (биржа: цены+админы).
ЖЁСТКО: только РЕАЛЬНЫЕ ссылки/цены, КАЖДОЕ с источником (URL). Не нашёл — «НЕ НАЙДЕНО, запрос админу».
НЕ выдумывай ссылки/цены/username — это деньги клиента на рекламу, выдумка = слив бюджета.
Верни таблицей: Объект | ТГ (URL) | ВК (URL) | Админ | Цена | Аудитория | Источник + список «не нашёл».
```

## 🔑 ГЛАВНЫЙ МЕТОД поиска чатов (урок 20.06.2026): Telethon, НЕ веб
**Веб-движки (Google/WebSearch) НЕ находят чаты жителей ЖК** — они закрытые/не индексируются. Вернут только сайты застройщиков. ⚠️ Веб даже даёт ЛОЖНЫЕ выводы (по «Философия на Московской» веб сказал «возможно другой объект» — а реально есть открытый чат на 3505 чел.).
**Рабочий метод = глобальный поиск ВНУТРИ Telegram через userbot (Telethon):** `scripts/tg_zhk_search.py` (artvision-data). Использует `contacts.SearchRequest(q=…)` по сессии `~/.claude/state/telethon_session_search` (api_id/api_hash из tokens.json→telegram). Находит публичные каналы/чаты + аудиторию. Py3.14 → только async (`asyncio.run`, не `telethon.sync`). Отсеять мусор (другой город по адресу, бизнес-каналы маникюр/торты). Цены Telethon НЕ даёт — добираются у админов (задача Андрею).

## Источники цен (приоритет, `cost-aware-alternatives-first` неприменим — цены внешние)
1. **telega.in** — биржа ТГ/MAX-каналов: карточки с ценой+аудиторией+админом (надёжнее всего, есть API карточек `/channels/<id>/card`).
2. **Превью t.me/s/<channel>** — подписчики + рекламные посты «цены в ЛС @admin».
3. **ВК-группа** — «Реклама»/закреп/обсуждение с прайсом.
4. **Прямой запрос админу** — если цены нет нигде → задача человеку (Asana, assignee Андрей, см. `asana-required-fields`).

## Запись в Google Sheet (ограничение — честно)
- Чтение таблицы: `mcp__claude_ai_Google_Drive__read_file_content` (file id из URL). Работает.
- **Прямой апдейт ячеек Sheet из CLI — НЕТ инструмента** (Drive MCP не пишет в существующий gid). Варианты:
  - отдать готовый markdown-блок → Антон/Андрей вставляет вручную (быстро);
  - дописать через залогиненный браузер (agent-browser) — если критично автоматом;
  - сохранить в `clients/<slug>/ads/posev-platforms-<date>.md` (git) как источник правды.
- Если Антон требует «добавь прямо в таблицу» — предупредить про ограничение и предложить браузер-вариант ИЛИ готовый блок для вставки.

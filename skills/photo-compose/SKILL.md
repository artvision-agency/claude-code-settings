# /photo-compose — safe-зона лица + кроп под текст

> Перед наложением текста/плашек/QR/ФИО на фото: детект лица → safe-зона → cover-кроп к чистой зоне → текст только вне лица → проверка глазами.
>
> PROVENANCE: Захвачено из работы Fable 5 (сессия 244a0f7c, прецедент Торонджадзе) · упаковано Claude Opus 4.8 2026-06-12 · правило capture-wins-as-skills.

## When to use

Вызывать ПЕРЕД сборкой любого визуала, где НА ФОТО С ЛЮДЬМИ накладывается текст или элементы:
- SMM-посты с врачами/командой/кейсами (ФИО, заголовок боль→выгода, CTA-плашка).
- Баннеры РСЯ / обложки / сторис / превью с лицами.
- КП-картинки и hero-секции с фото людей + текстовый overlay.
- Любой случай, где Антон уже видел или может увидеть «текст налезает на лицо».

Повторяющаяся претензия Антона «текст на лице» — это ОБЩИЙ класс для всех визуалов. Скилл закрывает явный TODO из `smm-post-production.md` (строки 60-66).

## When NOT to use

- Фон/фото без людей и ключевых объектов (текст можно класть свободно) — overkill.
- Чистый текст-карточка без фото (HTML→PNG, лица нет).
- Генерация самого изображения с нуля (это `model-bakeoff` / image-gen, не композиция).
- Тривиальная правка <2 мин, где safe-зона очевидна на глаз и проверена.

## Метод (по шагам)

### Шаг 1 — Детект лица / ключевого объекта
Цель: получить bbox лица (или нескольких) на ИСХОДНОМ фото в пикселях.

**Основной путь — OpenCV haarcascade (проверено: cv2 4.13.0 + каскад на месте).** Скрипт `detect_safe_zone.py` (ниже):
```bash
python3 ~/.claude/skills/photo-compose/detect_safe_zone.py <исходное_фото> --canvas-w 1080 --canvas-h 1350
```
Возвращает: размеры исходника, bbox каждого лица (x,y,w,h в %), рекомендуемую safe-зону для текста (`top`/`bottom`/`left`/`right`) и параметры cover-кропа + `object-position`.

**Fallback (если cv2 недоступен / лицо в профиль / нестандартный ракурс — haar часто промахивается):**
визуальный анализ через Read скриншота. Снять фото в скриншот/превью → `Read` его глазами → определить вручную, в какой четверти/половине кадра лицо, где пустая зона. Это соответствует правилу `visual-content-not-just-ratio.md` R2 («смотреть глазами, не на ratio»). Haar — ускоритель, НЕ замена глаз: его вывод всё равно подтверждать визуально.

### Шаг 2 — Выбрать safe-зону (где НЕТ лица)
- Лицо слева → текст справа/снизу. Лицо справа → текст слева/снизу. Лицо по центру верха → текст в нижней трети. И наоборот.
- Если лицо в исходнике мешает любой раскладке — **перегенерить/пересдать кадр со сдвигом субъекта** (прецедент Торонджадзе: врача сдвинули вправо → левая половина = чистый интерьер под текст). Это i2i на реальном фото (`image-edit-preserve-subjects` — менять композицию, не подменять человека).
- Никогда не класть текстовый блок / ФИО / плашку / QR поверх лица (любого: врач, ребёнок, гость, модель) — `visual-overlays-faces-and-metro.md` Правило 1.

### Шаг 3 — Cover-кроп под холст (object-position к safe-зоне)
- **Только `object-fit: cover`** (кроп с сохранением пропорций). НИКОГДА `fill` / `background-size:100% 100%` — это растяжение людей (`visual-content-not-just-ratio.md` R1, хук `post-banner-stretch-guard.sh`).
- Если ratio холста ≠ ratio исходника — лицо/макушка может срезаться. `object-position` смещать так, чтобы лицо осталось в кадре, а текст лёг в открывшуюся пустую зону.
- Исходник высокого качества (≥1000px ширина для крупного показа, не апскейл — `image-quality-standard.md`). Сверить ratio: `sips -g pixelWidth -g pixelHeight <фото>`.

### Шаг 4 — Проверка глазами «текст ∉ лицо» (обязательный гейт)
- Отрендерить готовый визуал → скриншот → **`Read` глазами**: ни ФИО, ни заголовок, ни плашка, ни QR не заходят на лицо; лицо не срезано кропом; пропорции людей естественные (головы круглые, не вытянуты).
- Заходит на лицо / срезано / растянуто → вернуться к Шагу 2-3, не сдавать.
- «Готово» без визуального просмотра запрещено (`visual-overlays-faces-and-metro.md`, `image-quality-standard.md`).

## Рабочий рецепт детекта (detect_safe_zone.py)

Скрипт лежит рядом: `~/.claude/skills/photo-compose/detect_safe_zone.py`. Использует ТОЛЬКО установленное (cv2 + PIL, проверено) — никаких выдуманных либ (`proven-tools-first.md`).

Ядро:
```python
import cv2, sys, os
img = cv2.imread(path)
H, W = img.shape[:2]
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
cascade = cv2.CascadeClassifier(
    os.path.join(cv2.data.haarcascades, "haarcascade_frontalface_default.xml"))
faces = cascade.detectMultiScale(gray, scaleFactor=1.1, minNeighbors=5,
                                 minSize=(int(W*0.05), int(H*0.05)))
# faces -> bbox в пикселях; перевести в %, определить пустую половину/четверть,
# выдать safe-зону для текста + object-position для cover-кропа под холст.
```
Если `faces` пусто — НЕ значит «лиц нет»: профиль/наклон/тёмное фото haar пропускает → переходить на fallback (Read скриншота глазами, Шаг 1).

## Антипаттерны

- ❌ Класть текст/ФИО/плашку/QR поверх лица (главная претензия Антона).
- ❌ Доверять только haar и не смотреть глазами (промахи на профиле/наклоне → ложное «лиц нет»).
- ❌ `object-fit:fill` / `background-size:100% 100%` для подгонки фото под холст (растяжение людей).
- ❌ Срезать лицо/макушку кропом ради заполнения слота — двигать `object-position` или менять размер слота.
- ❌ Апскейл мелкого фото под крупный холст (мыло — `image-quality-standard`).
- ❌ «Готово» без скриншота-проверки глазами что текст не на лице.
- ❌ Выдумывать несуществующие face-либы вместо проверенного cv2/PIL.

## Связь с правилами

- `visual-overlays-faces-and-metro.md` — Правило 1 (оверлеи никогда не на лицах) — этот скилл = исполняемая реализация.
- `smm-post-production.md` (стр. 58-66) — Ф2-гейт «текст не налезает на лицо» + явный TODO `/photo-compose`, который этот скилл закрывает.
- `image-quality-standard.md` — cover не fill, ≥1000px, не апскейл, object-position под контент.
- `visual-content-not-just-ratio.md` — R1 (ratio исходника vs холст → только cover), R2 (смотреть пропорции объектов глазами), R3 (петля доверия: повтор претензии = сменить метод).
- `image-edit-preserve-subjects.md` — пересдвиг субъекта в кадре = i2i, сохраняя того же человека.
- `proven-tools-first.md` — детект на cv2/PIL (установлены), не самопис/выдуманные либы.

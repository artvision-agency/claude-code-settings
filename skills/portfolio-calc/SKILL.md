# /portfolio-calc — калькулятор финансового портфеля

## Что делает

Считает чистую доходность портфеля из нескольких позиций (вклады, накопит. счета, ОФЗ, БПИФ) с учётом:
- Welcome-периодов и переходов на базовую ставку
- НДФЛ-льготы текущего года (актуализируется из rules/ndfl-formulas-2026.md)
- АСВ-лимита (предупреждение при превышении)
- Капитализации (ежедневная vs ежемесячная — разница символическая)
- Базы начисления (минимальный остаток — warning)

## Использование

### Вариант 1: JSON-вход

```
/portfolio-calc '[
  {"name": "ВТБ Выгодное начало", "amount": 1400000, "welcome_rate": 17, "welcome_days": 90, "base_rate": 6, "term_days": 180},
  {"name": "Альфа Ключевой", "amount": 1400000, "welcome_rate": null, "base_rate": 13, "term_days": 180},
  {"name": "LQDT", "amount": 200000, "base_rate": 14, "term_days": 180}
]'
```

### Вариант 2: интерактивный режим

`AskUserQuestion`-чейн:
- Сумма позиции 1?
- Куда?
- Welcome-ставка? (если есть)
- Длительность welcome (дней)?
- Базовая ставка после welcome?
- ... повторить для позиции 2
- Срок всего портфеля?

### Вариант 3: текстовое описание

```
/portfolio-calc "1.4М в ВТБ Выгодное начало 17% на 3 мес, потом в LQDT 14% 3 мес. + 1.4М в Альфа Ключевой 13% на 6 мес. + 0.2М LQDT 14% на 6 мес"
```

## Формулы

### Доход одной позиции

```
welcome_доход = сумма × welcome_ставка × min(welcome_days, term_days) / 365
если term_days > welcome_days:
    base_доход = сумма × base_ставка × (term_days - welcome_days) / 365
иначе:
    base_доход = 0
доход = welcome_доход + base_доход
```

### НДФЛ

```
льгота = 160000  # на 2026, см. ndfl-formulas-2026.md. Динамически обновлять для других лет
общий_доход = SUM(доход_по_позициям)
налогооблагаемый = max(0, общий_доход - льгота)
налог = 0.13 × налогооблагаемый  # 15% свыше 2.4М годового дохода
чистая = общий_доход - налог
```

### Эффективный % годовых

```
эфф_годовых = чистая / сумма_портфеля / (term_days / 365) × 100
```

## Алгоритм

1. Парсим вход (JSON / диалог / текст)
2. Валидация: суммы, ставки в разумных пределах, term_days > 0
3. Расчёт каждой позиции (welcome + base)
4. Сумма всех + НДФЛ
5. Вывод таблицы + предупреждения
6. Опционально — сгенерировать HTML с этой таблицей

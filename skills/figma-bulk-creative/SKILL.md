# /figma-bulk-creative — CSV + мастер-макет → серия редактируемых фреймов

> Метод из video-learn 2026-06-12 («Claude сам работает в Figma — 800 макетов за минуты»).
> Правило-источник: `~/.claude/rules/figma-mcp-bulk-creative.md`. Setup MCP: `~/artvision-data/personal/video-learn/2026-06-12-figma-mcp-bulk/figma-mcp-setup.md`.
> **НЕ дублирует:** `/figma-export` (только чтение/экспорт), `/ad-creative`+`model-bakeoff` (text-to-image генерация). Этот скилл — оркестрация bulk-записи в Figma по шаблону.

## Когда вызывать
≥10-15 однотипных вариаций по шаблону с переменными: карточки SKU маркетплейса (Avto.world, Madwave), серия РСЯ-баннеров (N товаров × форматы), SMM-серия постов по единому шаблону.
**НЕ вызывать:** 1-2 уникальных креатива (overkill); чисто генеративная картинка без шаблона (→ `/ad-creative` + `model-bakeoff`).

## Предусловия (проверить ПЕРЕД стартом — без них СТОП)
1. **Write-capable Figma MCP подключён** (`/mcp` показывает figma). Нет → setup-doc, Антон ставит `claude plugin install figma@claude-plugins-official` (CONFIRM). Без MCP скилл не работает.
2. **Мастер-макет на автолейаутах** в Figma (дизайнер): переменные блоки = именованные слои/текст-ноды, адаптивны, подогнаны под МАКС значения. Ссылка на файл + имя фрейма-мастера.
3. **CSV-номенклатура**: строка = вариация, колонки = переменные. Карта «колонка → слой/нода» (одна колонка может влиять на несколько: сезон → фон+иконка+цвет).
4. **Материалы**: товарные фото/фоны/иконки (файлы) + промт «что за что отвечает».

## Алгоритм
1. **Pre-Task:** прочитать правило `figma-mcp-bulk-creative.md` + (если клиент) `clients/<slug>/` контекст + бренд (`config.yaml`). Собрать карту «CSV-колонка → блок макета».
2. **Чтение мастера:** через Figma MCP «ознакомься с дизайн-файлом и фреймом <N>» → получить ID фрейма + ID переменных текст/слой-блоков. Зафиксировать соответствие колонка↔ID.
3. **Валидация CSV:** колонки = переменным макета? Нет дублей/пропусков ключа? Диапазон/исключения (если параметрический, как диоптрии −25..+25 шаг 0.5 искл. 0,1) — проверить.
4. **Промт на bulk:** «Создай серию фреймов: на КАЖДУЮ строку CSV подставь <колонка>→<нода>, <сезон>→<фон+иконка+цвет>. Имя фрейма = <шаблон>. Не трогай прочие слои.» Первый прогон — код может задать уточняющие вопросы (норма).
5. **Batch ≤ 20 нод/вызов** (Figma MCP лимит — разбивать). Для больших серий — партиями, resume-friendly (лог сделанных строк).
6. **Verify (обязательно):** выгрузить превью первых/средних/последних фреймов (`/figma-export` PNG) → **посмотреть глазами** (Read): значения подставлены верно, автолейаут не разъехался, бренд-палитра, фото HIGH-res без растяжения (`image-quality-standard`, `visual-content-not-just-ratio` cover-не-fill). Числа/SKU сверить с CSV.
7. **PROVENANCE:** в отчёт — `AUTHOR: Figma MCP · figma-bulk-creative · <дата>` + модель image-gen, если фото генерились.
8. **Хэндоф:** превью-серия на review-URL/Антону, статус «на ревью» (deploy≠одобрено, `explicit-approval-tracking`). Карточки клиенту — ФЗ/бренд-гейты (`_compliance-checklist`).

## Комбо с image-gen (полная карточка)
Если нужны и товарные изображения: сначала image-gen bakeoff (Nano Banana Pro лидер, `model-bakeoff`) → фото → Figma MCP вставляет в мастер-макет по CSV. Картинка = генерация, раскладка/типографика/инфографика = Figma-точно.

## Антипаттерны
- ❌ Запуск без подключённого write-Figma MCP (скилл не работает — сначала setup).
- ❌ Без мастер-макета на автолейаутах (серия поедет).
- ❌ text-to-image вместо Figma, когда нужны редактируемые бренд-макеты.
- ❌ «Готово» без визуальной сверки превью глазами + сверки чисел с CSV.
- ❌ Серия без PROVENANCE.

# Text Factors Audit — текстовый аудит SEO

Автоматическая проверка страницы (или набора страниц) по 38 текстовым факторам
ранжирования Яндекса. Публичное название в отчёте: **artvision.pro Pulse — Text**.

## When to use

- **Presale-аудит** — показать клиенту разрывы текстового качества до старта работ
- **Пост-публикационная проверка** — новая статья/страница прошла редактуру
- **Quarterly review** — измеряем прогресс после работ с контентом
- **Конкурентный анализ** — сравнить текст клиента и конкурента из ТОП-10
- **Диагностика просадок** — когда позиции падают и причина неочевидна
- Часть мастер-аудита `seo-master` (модуль 2 — текстовые факторы)

## When NOT to use

- Одностраничные лендинги без <p> и <h2> — часть структурных проверок даст FAIL by design
- SPA без SSR — требует Playwright (в MVP не поддержано, возвращает тонкий HTML)
- Защищённые разделы / личный кабинет — нужна авторизация, не поддерживается

## Factors covered (38 атомарных проверок)

### 1. Мета-теги (id 1-5)
- Длина title 50-70, длина description 150-170
- Ключ в title, призыв к действию в description
- OG-теги (og:title, og:description, og:image)

### 2. Структура (id 6-13)
- Ровно один H1, ключ в H1, длина H1 до 70
- Минимум 3 H2 для длинных страниц
- Корректная иерархия заголовков h1→h2→h3
- Абзацы 2-4 предложения, наличие списков и таблиц

### 3. Объём (id 14-16)
- Коммерч: 1500+ слов, блог: 2500+ слов
- Отсутствие thin content (<300 слов)

### 4. Плотность / тошнота / водность (id 17-21)
- TF-плотность главного ключа 2-4%
- Классическая тошнота ≤ 7
- Академическая тошнота 5-9%
- Водность (стоп-слова) ≤ 30%
- Ключ в первом абзаце (top 100 слов)

### 5. Семантика (id 22-23)
- LSI-покрытие ≥ 60% от заданного списка
- Семантическая полнота кластера (ручная)

### 6. Уникальность и дубли (id 24-26)
- Уникальность ≥ 85% (text.ru / content-watch.ru API)
- Внутренние дубли (Jaccard ≥ 0.85)
- Каннибализация title

### 7. Читаемость (id 27)
- Индекс Флеша-Кинкейда (русская адаптация Оборневой) 60-80

### 8. Антиспам (id 28-29)
- Нет слов целиком в CAPS в теле
- Нет множественных «!!!»

### 9. Изображения (id 30-31)
- Alt у 90%+ картинок
- Ключ хотя бы в одном alt

### 10. Ссылки (id 32-34)
- Минимум 3 внутренние ссылки в тексте
- Разнообразие анкоров (<30% generic «тут»/«здесь»)
- 1-5 внешних ссылок на авторитетные источники

### 11. Свежесть (id 35)
- Дата обновления не старше 365 дней (для блога)

### 12. Коммерческие триггеры (id 36-38)
- Упоминание цены/стоимости, гарантии, доставки

## Веса факторов

Каждый фактор имеет вес 1-10 (в `data/factors.yaml`). Взвешенный балл в отчёте
считается как `Σ(weight * pass_ratio) / Σ(weight)`, где pass=1.0, warn=0.5,
fail=0.0. `manual` и `na` исключаются из знаменателя.

## Настройка API-ключей

Для автопроверки уникальности нужен ключ **text.ru** или **content-watch.ru**.

Сейчас в `~/artvision-data/tokens.json` таких ключей нет. Чтобы включить проверку:

1. Зарегистрироваться на https://text.ru/ → Пользовательский кабинет → API → userkey
2. Добавить в `tokens.json`:
   ```json
   "text_ru": { "api_key": "ваш_ключ" }
   ```
3. Аналогично для https://content-watch.ru/ → API → ключ → `"content_watch": { "api_key": "..." }`

Без ключей фактор уникальности будет помечен как **«ручная проверка»** (не фейлится,
но не засчитывается в балл).

## Ограничения MVP (v0.1)

1. **Нет JS-рендеринга** — SPA покажут FAIL не по делу. Решение: Playwright → v0.2
2. **Уникальность требует API-ключа** — без него = MANUAL
3. **Дубли = Jaccard по токенам**, не полноценный Simhash. Точность ~85%
4. **LSI-список задаётся вручную** через `--lsi-words`. Автогенерация из ТОП-10 → v0.3
5. **Морфология** — pymorphy3 опционален. Без него проверки ключа работают по точному вхождению
6. **Нет сравнения с конкурентом по тошноте/TF** — будет в v0.2

## Известные подводные камни

- **SSR-сайты**: возвращают пустой `<div id="app">` → 80% FAIL. Проверить view-source перед запуском
- **robots.txt** блокирует `/`: fail-open (аудит продолжится, покажем предупреждение)
- **text.ru API** асинхронный: ждём до 60 сек. При таймауте → MANUAL
- **Большие тексты > 50 Kb**: API-провайдеры обрезают. Скрипт обрезает до 50000 символов
- **Русские CAPS-аббревиатуры (ООО, ИП)**: фильтруются по длине 4+ символа, чтобы не давать ложные срабатывания

# Authority-Barter Strategy

Упаковка экспертного B2B-контента для размещения на авторитетных отраслевых медиа в обмен на **постоянные** карточки/ссылки/упоминания клиента.

## When to Use

| Сценарий | Использовать? |
|----------|---------------|
| Новый B2B-клиент, нужен линкбилдинг | ✅ ДА, как часть SEO-стратегии |
| Клиент хочет "авторитет в нише" | ✅ ДА |
| B2C/ecommerce с массовым трафиком | ❌ Использовать `paid-ads` + `programmatic-seo` |
| Нужна одноразовая публикация-хайп | ❌ Использовать `parasitic-seo` (VC/Habr/Дзен) |
| Классический линкбилдинг через PBN | ❌ Использовать `linkbuilding` + `pbn-domains` |

**Пересечение с соседями:**
- `linkbuilding` — cold outreach, PBN, дропы. Бартер **здесь**, не там.
- `parasitic-seo` — скорость на чужих платформах (vc.ru). Бартер = постоянство на отраслевых.
- `content-strategy` — tone/темы → импортируется сюда как dependency.

## Главный аргумент для клиента (позиционирование)

> «Публикация = перенос цитатного веса от РБК / Интерфакса / Минсельхоза / Росстата на сайт клиента. Каждое число в статье — прямая ссылка на авторитетный источник. E-E-A-T-сигнал для Яндекс/Google + trust-актив для B2B-переговоров.»

## Главный аргумент для редакции площадки

> «Готовый экспертный контент 8-12К знаков с агрегацией данных "гигантов" + эксклюзивные срезы + автор-эксперт. Бесплатно, в ваш контент-план. Взамен — постоянная карточка партнёра.»

## Pipeline (7 шагов)

### 1. Research площадок
- Входные: ниша клиента из `clients/<name>/CLAUDE.md`
- Фильтр: DR≥40 (Ahrefs), ИКС≥100 (Яндекс), активность редакции <30 дней
- Инструменты: Ahrefs, Serpstat, Megaindex, SimilarWeb
- Реестр → `sites.yaml` (обновляется, tier-1/2/3)

### 2. Питч редакции (CONFIRM)
- Шаблон → `templates/pitch-editor.md`
- ВСЕГДА через Антона/Андрея (security.md → любой контакт = CONFIRM)
- Параллельно 3-5 редакций разных Tier

### 3. Media standards check
- Скрейпить editorial guidelines площадки (длина, tone, запреты)
- Если нет публичных guidelines → запросить у редактора
- Сохранить в `sites.yaml.standards`

### 4. Fact-check (ОБЯЗАТЕЛЬНО)
- Все числа CONFIRMED с 2+ источниками (`research-to-memory.md`)
- Прямые ссылки на конкретные страницы (не главную)
- Запустить `factcheck-v2.py` на черновик
- Маркировать UNCONFIRMED там где нет 2 источников

### 5. Client approval (CONFIRM)
- Черновик → клиенту по `security.md`
- НЕ показывать внутрянку клиента (правило R4, `feedback_no_client_internals_in_kp.md`)
- Дождаться подтверждения

### 6. Отправка
- Tracking в `clients/<name>/outreach.jsonl` (дата, редактор, статус, URL когда опубликовано)
- Дедлайны в Asana

### 7. Post-publish monitoring
- Скрипт `scripts/check-backlink.sh <url>` → проверяет наличие ссылки, rel-атрибут, индексацию
- Запись в `clients/<name>/backlinks.md`
- Через 30 дней — замер GSC/Метрики (impressions, clicks, referral)

## Tier-модель площадок (рекомендация SEO-сеньора)

| Tier | DR/ИКС | Что предлагать | Ожидание взамен |
|------|--------|----------------|------------------|
| **Tier-1** | DR 55+, ИКС 1000+ | Эксклюзивную статью с уникальными данными | Редакторская dofollow-цитата + автор-бокс |
| **Tier-2** | DR 40-55, ИКС 300-1000 | Стандартную экспертную статью | rel="sponsored" карточка партнёра + упоминание |
| **Tier-3** | DR <40, ИКС <300 | Дайджест или интервью | Mention без ссылки (если только карточка — отказать) |

## Контент-стандарты (от content-сеньора)

- Длина: 8-12К знаков, lead 400-600
- Структура: H1 → Lead → H2 "Контекст рынка" (цифры) → H2 "Разбор" (2-3 H3) → H2 "Региональный/технический срез" → H2 "Прогноз" → Выводы буллетами
- Обязательно: 1 график, 1 таблица, 1 цитата эксперта клиента (ФИО, должность), 1 инфографика
- Tone: аналитический, без маркетингового жаргона, стиль РБК Pro / Ведомости-отраслевые
- Источники: 6-8 минимум, гиперссылки на конкретные страницы

## Усиления (от SEO-сеньора)

1. **Authorship + Schema Person** — на сайте клиента страница автора с schema.org/Person, sameAs на профиль LinkedIn + все публикации. Привязка статьи к author entity усиливает E-E-A-T в разы.
2. **Digital PR поверх контента** — к каждой статье прикладывать датасет/инфографику/research. Это даёт вторичные цитирования от РБК/Ведомости = настоящий вес.
3. **Анти-penalty** — требовать rel="sponsored" или nofollow от площадки (иначе Google Link Spam). Анкор-лист: 70%+ безанкорный (URL, brand name).

## Риски (обязательно мониторить)

| Риск | Митигация |
|------|-----------|
| Google penalty за paid links | rel="sponsored"/nofollow обязательно |
| Яндекс Минусинск (анкорный) | Анкорная diversity 70%+ безанкорно |
| Токсичные доноры | Ahrefs Toxicity Score, disavow если >30 |
| Link farms (одна PR-сетка) | WHOIS + Ahrefs Linked Domains проверка |

## Метрики (baseline → +3 мес → +6 мес)

| Метрика | Инструмент |
|---------|-----------|
| DR/ИКС, Referring Domains | Ahrefs, Serpstat, Яндекс.Вебмастер |
| Brand mentions + sentiment | Brand24, Медиалогия |
| Branded search volume | Wordstat, GSC, Метрика |
| Impressions по category queries | GSC, Яндекс.Вебмастер |
| Referral traffic с донора | GA4/Метрика + UTM обязательно |
| SERP-присутствие | Topvisor, Megaindex |

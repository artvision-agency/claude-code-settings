# Accounting Prep — Бухгалтерская подготовка

## Цель
Подготовить пакет документов для бухгалтерии: собрать первичку, проверить полноту, сформировать отчёт. **Claude не сдаёт декларации** — готовит данные для Андрея/Антона/внешнего бухгалтера.

## Когда вызывается
- Ключевые слова: НДС, декларация, первичка, акт, счёт-фактура, закрывашки, сверка
- Раз в квартал (авто-cron на 20-е число)
- Раз в месяц (сверка поступлений с закрывашками)

## Процесс

### ШАГ 1: Определить задачу

| Тип | Что собрать |
|-----|------------|
| НДС квартал | Счета-фактуры за квартал + акты + книги покупок/продаж |
| Закрывашки месяца | Акты выполненных работ по всем клиентам + счета |
| Сверка с клиентом | Акт сверки (наши данные vs клиента) |
| Первичка | Все документы по конкретной сделке |

### ШАГ 2: Сбор данных

```bash
# Клиенты с MRR из client-revenue.md
python3 -c "
import json
# распарсить client-revenue.md → список клиентов → суммы за период
"

# Документы в Google Drive общей папке
# Используем Google Service Account (google_service_account.md)
```

Проверить источники:
1. `artvision-data/client-revenue.md` — реестр доходов
2. `artvision-data/finance/done/` — выполненные операции с чеками
3. `schedule/reports-invoices.json` — расписание счетов (кому/когда/сколько)
4. Google Drive — подписанные документы клиентов
5. СБИС/контур — если залогинены (см. `sbis-support`)

### ШАГ 3: Проверка полноты

Для каждого клиента за период:
- [ ] Счёт выставлен? Номер?
- [ ] Акт подписан?
- [ ] Счёт-фактура? (если с НДС)
- [ ] Поступление на р/с? Дата?
- [ ] Сумма совпадает?

Результат → таблица в `artvision-data/accounting/<period>/completeness.md`:

```markdown
| Клиент | Сумма | Счёт № | Акт | СФ | Поступление | Статус |
|--------|-------|--------|-----|----|-----| ------|
| Mirulidi | 50000 | №42 | ✅ | ✅ | 2026-03-15 | ✅ OK |
| BluMart | 70000 | №43 | ✅ | ❌ | 2026-03-20 | ⚠️ нет СФ |
```

### ШАГ 4: Закрытие пробелов

Для `⚠️` и `❌`:
- Нет акта → сгенерировать + отправить клиенту на подпись (CONFIRM)
- Нет счёта-фактуры → сформировать в СБИС / 1С
- Нет поступления → напомнить клиенту (CONFIRM)
- Сумма не совпадает → сверка построчно, алерт Антону

### ШАГ 5: Итоговый пакет

`accounting/<period>/package.md`:
- Список всех документов с путями
- Сумма оборота за период
- Сумма НДС к уплате/возмещению (если ОСН)
- Комментарий для бухгалтера

Ссылка отправляется Андрею/внешнему бухгалтеру через CONFIRM-батч.

## Запреты
- Не подавать декларации от имени юрлица — только готовить данные
- Не отправлять первичку клиентам без подписи Антона
- Не раскрывать ИНН/КПП третьих лиц в публичных чатах

## Связанные
- `sbis-support` — работа с СБИС
- `counterparty-check` — проверка контрагентов
- `schedule/reports-invoices.json` — расписание
- `google_service_account.md` — доступ к Drive

# Outreach Emails Skill

Полный скилл для генерации персонализированных outreach-писем владельцам авторитетных сайтов. Специализирован на юридической нише (ANT Partners, налоговые консультации).

## Структура файлов

```
outreach-emails/
├── SKILL.md              # Основное описание скилла (полная документация)
├── QUICK_START.md        # Быстрый старт за 20-30 минут
├── research-template.md  # Чек-лист для исследования сайта-донора
├── tracker.json          # Трекер отправленных писем и метрик
├── validate_email.py     # Валидатор писем перед отправкой
├── tracker_manager.py    # Менеджер трекера (добавление, обновление, метрики)
└── README.md             # Этот файл
```

## Быстрый старт

### 1. Выбрать тип письма

- **GUEST_POST** — размещение готовой экспертной статьи (лучший результат)
- **EXPERT_COMMENT** — дополнение к конкретной статье на сайте-доноре
- **LINK_EXCHANGE** — предложение взаимного размещения ссылок
- **MENTION_IN_REVIEW** — добавление в список лучших сайтов / рейтинг

### 2. Исследовать сайт-донор (10-15 минут)

Открыть сайт, прочитать 3-5 статей, заполнить чек-лист:

```bash
cat research-template.md
```

### 3. Попросить агента сгенерировать письмо

```
"Клод, генерируй письмо GUEST_POST:
- Сайт: nalogovoe.pro (название: Налоговое.pro)
- Контакт: Иван Петров (ivan@nalogovoe.pro)
- Их статья: '10 ошибок при НДС'
- Наша услуга: Консультации по налоговому праву (ANT Partners)
- Наша статья: 'Налоговые риски для малого бизнеса'"
```

### 4. Валидировать письмо перед отправкой

```bash
python3 validate_email.py --subject "Твой subject" --body "Твое письмо"
```

Письмо должно пройти со score >= 70 баллов.

### 5. Добавить в трекер и отправить

```bash
python3 tracker_manager.py add \
  --campaign "ant-partners-march-2026" \
  --website "nalogovoe.pro" \
  --recipient "Иван Петров" \
  --email "ivan@nalogovoe.pro" \
  --type "GUEST_POST" \
  --subject "Экспертная статья для Налоговое.pro"
```

### 6. Мониторить результаты

```bash
# Показать статус всех писем
python3 tracker_manager.py status

# Показать метрики
python3 tracker_manager.py metrics

# Показать ожидающие follow-up
python3 tracker_manager.py pending
```

## Примеры использования

### Пример 1: Добавить письмо и обновить статус

```bash
# Добавить письмо
email_id=$(python3 tracker_manager.py add \
  --campaign "ant-partners" \
  --website "yuridplus.ru" \
  --recipient "Юлия Смирнова" \
  --email "julia@yuridplus.ru" \
  --type "EXPERT_COMMENT" \
  --subject "Дополнение для статьи про НДС")

# Спустя 3 дня обновить статус на "positive"
python3 tracker_manager.py update \
  --id "email-002" \
  --status "positive" \
  --response "Согласилась на комментарий" \
  --conversion "COMPLETED"
```

### Пример 2: Follow-up цикл

```bash
# День 1: Отправить письмо (добавить в трекер выше)

# День 3: Отправить первый follow-up
python3 tracker_manager.py follow-up --id "email-001" --number 1

# День 7: Отправить второй follow-up
python3 tracker_manager.py follow-up --id "email-001" --number 2
```

## Работа с шаблонами

### Структура письма (все типы)

```
Subject: [ПЕРСОНАЛИЗАЦИЯ] [ЦЕЛЬ]

Привет, [Имя]!

[Hook — конкретный инсайт из их статьи]

[Value Proposition — что мы предлагаем и почему это выгодно]

[CTA — один четкий call-to-action]

[Signature]
```

### 4 типа писем (краткие описания)

#### 1. GUEST_POST (День 1, 3, 7)

Предложение разместить готовую экспертную статью.

**Преимущество для сайта-донора:** свежий контент, улучшение SEO, расширение аудитории

**Лучший ответ:** через 1-3 дня, согласие на публикацию

#### 2. EXPERT_COMMENT (День 1, 3, 7)

Предложение дополнить статью экспертным комментарием.

**Преимущество:** увеличивает value статьи, обновляет дату, привлекает engagement

**Лучший ответ:** через 2-5 дней, согласие добавить комментарий

#### 3. LINK_EXCHANGE (День 1, 3, 7)

Предложение взаимного размещения ссылок (они у нас, мы у них).

**Преимущество:** свежий трафик, расширение сети, улучшение SEO

**Лучший ответ:** через 3-7 дней, согласие на обмен

#### 4. MENTION_IN_REVIEW (День 1, 3, 7)

Предложение добавить в список, рейтинг, подборку сайтов.

**Преимущество:** увеличивает авторитет рейтинга, расширяет аудиторию

**Лучший ответ:** через 1-3 дня, согласие на упоминание

## Валидация писем

Перед отправкой всегда запускать валидатор:

```bash
python3 validate_email.py --subject "Subject" --body "Email body text"
```

**Проверяет:**
- Спам-слова (срочно, прибыль, гарантировано)
- Чрезмерное пунктирование (!!!!, ?????)
- Персонализацию (по имени ли?)
- Количество ссылок (максимум 1)
- Длину письма (150-250 слов)
- Четкость CTA
- Приветствие

**Score >= 70** — готово к отправке

## Анти-спам правила (ЖЁСТКИЕ)

1. НЕ отправлять более 3 писем одному контакту (с follow-up)
2. МИНИМУМ 1 день между письмами разным сайтам
3. ОБЯЗАТЕЛЬНО вручную прочитать сайт (не автоматическая рассылка)
4. ТОЛЬКО сайты с DA 20+ (Domain Authority)
5. НИКОГДА не отправлять без явного одобрения человека
6. ТАЙМАУТЫ: максимум 3 follow-up, потом архивируем

**Нарушение = домен в черный список = репутация потеряна**

## Метрики и нормы

| Метрика | Формула | Норма |
|---------|---------|-------|
| **Reply Rate** | ответы / письма | 15-25% |
| **Conversion Rate** | ссылки+статьи / письма | 5-10% |
| **Time to Reply** | дни до ответа | 1-7 дней |
| **Follow-up Success** | ответы на FU / FU отправлено | 40-50% |

Если Reply Rate < 10% → переоценить целевые сайты или улучшить персонализацию.

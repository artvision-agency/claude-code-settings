## Спам-фильтры (ОБЯЗАТЕЛЬНО проверить)

- [ ] Сайт получает регулярные обновления (не мёртв)
- [ ] В статьях нет явного спама (реальный контент, не AI-gibberish)
- [ ] Есть реальные комментарии читателей (engagement, не bot-сайт)
- [ ] На сайте есть реальные контакты / About / Author info
- [ ] Домен старше 1 года (не новопак)
- [ ] НЕ работает финансовая пирамида / MLM / явное мошенничество

**Статус:** ✅ Зелёный (можно отправлять) / ⚠️ Оранжевый (скептически) / ❌ Красный (не отправлять)

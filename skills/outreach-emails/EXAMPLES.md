## Как использовать эти примеры

1. **Скопировать** нужный пример из EXAMPLES.md
2. **Персонализировать** (имена, сайты, контент)
3. **Валидировать**: `python3 validate_email.py --subject "..." --body "..."`
4. **Добавить в трекер**: `python3 tracker_manager.py add ...`
5. **Отправить** (вручную)
6. **Мониторить** через tracker: `python3 tracker_manager.py status`

# Быстрый старт: Outreach Emails

Этот документ — краткая инструкция для генерации одного письма за 20-30 минут.

## 3 шага к письму

### Шаг 1: Исследование (10 минут)

Открыть сайт-донор и заполнить:

```
Сайт: https://example.com/blog
Автор: Иван Петров
Email: ivan@example.com
Статья которая понравилась: "10 советов для адвокатов"
Почему понравилась: объяснили сложную концепцию простым языком
```

Больше деталей: см. `research-template.md`

### Шаг 2: Выбор типа письма

- **GUEST_POST** — разместить статью от клиента (лучший результат)
- **EXPERT_COMMENT** — дополнить существующую статью комментарием
- **LINK_EXCHANGE** — обмен ссылками (самый простой)
- **MENTION_IN_REVIEW** — добавить в список лучших сайтов

### Шаг 3: Попросить агента сгенерировать письмо

Передать агенту:

```json
{
  "type": "GUEST_POST",
  "recipient_name": "Иван Петров",
  "website_name": "АдвокатБранч.pro",
  "website_url": "https://advokatbranch.pro",
  "article_they_wrote": "10 советов для адвокатов при подготовке к суду",
  "why_we_like_it": "хорошо объяснили процесс",
  "our_article_topic": "Налоговые риски для адвокатских контор",
  "our_article_benefit": "чек-лист для клиентов адвокатов",
  "client_name": "ANT Partners"
}
```

## Примеры готовых писем

### Пример 1: GUEST_POST (на юридическом сайте)

```
Subject: Экспертная статья для АдвокатБранч.про — налоговые риски

Привет, Иван!

Вчера наткнулся на вашу статью "10 советов для адвокатов" на АдвокатБранч — фантастическое объяснение сложного процесса.

У нас в ANT Partners есть ценное наблюдение по налоговым рискам (часть которых адвокаты упускают при консультациях). Подготовил статью с чек-листом для вашей аудитории.

Интересно посмотреть черновик?

Спасибо,
Иван Сидоров
Senior Lawyer, ANT Partners
ant.partners
```

**Результат:** обычно ответ в течение 3 дней, если статья действительно подходит сайту.

---

### Пример 2: EXPERT_COMMENT (дополнение к статье)

```
Subject: Дополнение для вашей статьи на АдвокатБранч

Привет, Иван!

Только что прочитал ваш гайд про подготовку к суду. Очень полезная статья.

У нас в ANT Partners есть небольшой инсайт про налоговые аспекты, которые часто упускаются. Могу написать 3 абзаца, которые отлично дополнят ваш гайд.

Интересует?

Спасибо,
Иван
```

**Результат:** быстрый ответ, минимум редактирования, хороший бэклинк.

---

### Пример 3: LINK_EXCHANGE (простой обмен)

```
Subject: Обмен ссылками с АдвокатБранч.про

Привет, Иван!

Заметил, что АдвокатБранч и ANT Partners обслуживают одну аудиторию (адвокаты и консультанты).

Предлагаю простой обмен: я добавлю вас в нашу подборку "Надежные юридические ресурсы", вы добавите нас в свой блог.

Обе ссылки будут в видимом месте, не в footer.

Интересует?

Спасибо,
Иван
```

**Результат:** самый быстрый, но меньше ценности чем GUEST_POST.

## Таймлайн Follow-Up

| День | Действие | Пример |
|------|----------|---------|
| **1** | Первое письмо | Отправляем основное предложение |
| **3** | Напоминание | "Вчера отправлял статью — есть 5 минут посмотреть?" |
| **7** | Альтернатива | "Может быть, простой обмен ссылками вас больше интересует?" |

После дня 7 — архивируем (не спамим дальше).

## Метрики успеха

- **Reply Rate:** 15-25% (нормально, если 1 ответ из 5 писем)
- **Conversion Rate:** 5-10% (нормально, если 1 статья из 10-20 писем)
- **Best Day to Send:** вторник, среда, четверг (10:00-14:00)

Если Reply Rate низкий — проверить:
1. Выбираем ли действительно релевантные сайты?
2. Персонализируем ли на самом деле (или слишком generic)?
3. Есть ли real insight в первом абзаце (или просто хвала)?

## Анти-спам правила

✅ МОЖНО:
- Отправлять 2-3 письма в день (разным сайтам)
- Использовать один хороший шаблон (с персонализацией)
- Повторять после дней 3 и 7
- Менять текст в зависимости от сайта

❌ НЕЛЬЗЯ:
- Отправлять 20+ писем за раз
- Копировать письмо 1-в-1 для всех
- Отправлять без явного одобрения
- Спамить после третьего follow-up

## Сохранение результатов

После каждого письма обновляем файл `tracker.json`:

```json
{
  "website": "example.com",
  "date_sent": "2026-03-07",
  "type": "GUEST_POST",
  "status": "waiting",
  "follow_up_1": "2026-03-10",
  "follow_up_2": "2026-03-14"
}
```

Это помогает видеть результаты и не потеряться в follow-up.

## Когда звать Клода

Нужна помощь на какомболи из этапов:

```
"Клод, генерируй письмо GUEST_POST для nalogovoe.pro — вот персонализация..."
```

Клод делает:
1. Заполняет данные из твоего JSON
2. Пишет письмо из шаблона
3. Персонализирует детали
4. Показывает на одобрение

Все вместе ~5 минут.

# Outreach Email Generator

## Назначение

Создание индивидуальных, персонализированных писем владельцам авторитетных сайтов для естественного размещения ссылок, гостевого контента и упоминаний. Специализирован на юридической нише (ant.partners, налоговые/юридические сайты).

**Приоритеты:**
1. Персонализация (конкретные данные сайта, статьи, владельца)
2. Ценность первым делом (не спам, не "просто ссылка")
3. Органичный, дружеский тон (экспертный, но не навязчивый)
4. Follow-up стратегия (3-дневный и 7-дневный повторы)
5. Анти-спам фильтр (не рассылать, разумные интервалы)

## Когда использовать

- Размещение экспертного контента от клиента (ant.partners, юр.адвокаты)
- Построение бэклинков для SEO кластера
- Генерация leads через экспертное позиционирование
- Поиск партнёров для обмена (юр.консультации, АЙ-решения)

## Типы писем (4 категории)

### 1. GUEST_POST — Гостевая статья

**Суть:** предложение разместить готовую экспертную статью бесплатно. Максимальная ценность для сайта-донора.

**Когда:** у клиента есть готовый/полугото́вый контент (10-15 min read)

**Преимущество для донора:**
- Свежий контент от эксперта (не нужно писать)
- Улучшение SEO (уникальный контент, цитирование)
- Расширение аудитории (читатели клиента узнают о их услугах)

---

### 2. LINK_EXCHANGE — Обмен ссылками

**Суть:** предложение взаимного размещения ссылок (мы у вас, вы у нас).

**Когда:** оба сайта имеют релевантный контент (но нет готовой статьи)

**Условие:** ТОЛЬКО релевантные ниши (не случайные сайты)

---

### 3. EXPERT_COMMENT — Экспертный комментарий

**Суть:** предложение дополнить существующую статью на сайте-доноре экспертным комментарием.

**Когда:** есть конкретная статья, по которой можно дать ценное добавление

**Преимущество для донора:**
- Увеличивает value статьи (мнение эксперта)
- Обновляет дату публикации (свежесть в поисковиках)
- Привлекает комментарии читателей (engagement)

---

### 4. MENTION_IN_REVIEW — Упоминание в подборке/рейтинге

**Суть:** предложение добавить в список best practices, рейтинг, подборку ссылок.

**Когда:** на сайте-доноре есть обзорный контент или list posts

**Формат:** "Топ 10 юридических ресурсов", "Лучшие инструменты для..." и т.д.

## Структура письма (Universal)

```
Subject: [ПЕРСОНАЛИЗАЦИЯ] [ЦЕЛ]

Greeting:
  - Имя владельца/редактора сайта
  - Намёк на что-то из их контента (не generic)

Hook (первый абзац):
  - Один конкретный факт / статистика / insight из их статьи
  - Чему ты у них научился / что оценил

Value Proposition (абзац 2-3):
  - Что ты предлагаешь (статья / ссылку / комментарий)
  - КОНКРЕТНО, не размыто
  - Почему ИМЕННО их сайту это выгодно

CTA (один, чёткий):
  - "Можно ли созвониться в пятницу?" (вместо "напиши мне")
  - Альтернатива: "Вот черновик статьи — посмотри, подходит ли?"

Signature:
  - Имя + title (эксперт по X)
  - Ссылка на LinkedIn или сайт клиента (БЕЗ скрытых UTM)
  - Телефон (опционально, если контакт уровня руководителя)
```

## Follow-Up стратегия

| Письмо | День | Стиль | Пример |
|--------|------|-------|--------|
| **Email 1** | День 1 (Вт-Ср-Чт) | Предложение + value | "Заметил вашу статью про НДС...отправляю вам черновик" |
| **Email 2** | День 3 | Напоминание + уточнение | "Вчера отправлял статью про налоговые риски — есть 5 минут посмотреть?" |
| **Email 3** | День 7 | Альтернатива + exit | "Может быть, простой обмен ссылками вас больше интересует?" |

**Правило:** максимум 3 follow-up'а. Если не ответили на 3-й — архивируем.

## Персонализация (обязательная)

Для каждого письма ТРЕБУЕТСЯ заполнить переменные:

```json
{
  "recipient_name": "Иван Петров",
  "website_name": "Налоговое.pro",
  "website_url": "https://nalogovoe.pro",
  "specific_article": {
    "title": "10 ошибок при подаче НДС деклараций",
    "url": "https://nalogovoe.pro/blog/10-oshibok-nds",
    "key_insight": "в статье правильно описана ситуация с восстановлением НДС, но не упоминается..."
  },
  "client_name": "ANT Partners / Налоговое агентство",
  "client_service": "консультации по налоговому праву",
  "outreach_type": "GUEST_POST | LINK_EXCHANGE | EXPERT_COMMENT | MENTION_IN_REVIEW",
  "article_snippet": "краткое описание статьи которую хотим разместить (если GUEST_POST)"
}
```

**Анти-спам правила:**
- НЕ заполнять шаблон автоматически для 100+ сайтов одновременно
- ОБЯЗАТЕЛЬНО проверить сайт вручную (5+ минут чтения)
- НИКОГДА не отправлять без явного одобрения человека
- Таймауты между письмами: минимум 1 день между каждым сайтом

## Инструкция по генерации письма

### Фаза 1: Подготовка данных

1. **Исследование сайта-донора** (обязательно вручную!)
   - Открыть сайт, прочитать 3-5 статей
   - Найти владельца/редактора (обычно в About или контактах)
   - Определить основную тему (SEO, налоги, юристы, etc)
   - Заметить реальные детали (стиль письма, формат статей)

2. **Выбрать тип письма:**
   - GUEST_POST — если есть готовая статья + высокий авторитет сайта
   - LINK_EXCHANGE — если релевантные ниши, но нет статьи
   - EXPERT_COMMENT — если есть конкретная статья для дополнения
   - MENTION_IN_REVIEW — если есть list-post или рейтинг

3. **Заполнить персонализацию:**
   ```json
   {
     "recipient_name": "Иван",
     "website_name": "НалоговоеПраво.pro",
     "website_url": "https://nalogovoe.pro",
     "specific_article": {
       "title": "10 ошибок при НДС",
       "url": "https://nalogovoe.pro/blog/nds-10-oshibok",
       "key_insight": "описана ситуация с восстановлением НДС"
     },
     "client_service": "Консультации по налоговому праву",
     "outreach_type": "GUEST_POST"
   }
   ```

### Фаза 2: Генерация письма

Передать агенту:
- **JSON с персонализацией** (выше)
- **Тип письма** (GUEST_POST / LINK_EXCHANGE / etc)
- **День цикла** (1 / 3 / 7)
- **Статья-черновик** (если GUEST_POST, вставить текст или ссылку)
- **Ограничения:**
  - Максимум 150 слов для subject line
  - Максимум 250 слов для body письма (читаемость)
  - Тон: дружеский экспертный (не hard-sell)
  - БЕЗ ссылок с UTM или tracking параметрами

### Фаза 3: Валидация письма

Перед отправкой проверить:

```checklist
[ ] Subject вызывает интерес (не спам слова: "вам нужно", "срочно", "ПРИБЫЛЬ")
[ ] Первый абзац содержит конкретный факт из сайта-донора
[ ] В письме 0-1 ссылка максимум (и то, если очень релевантна)
[ ] CTA одна и чёткая ("можно созвониться?" вместо "напиши нам")
[ ] НЕТ слов: "поскольку вы", "как мы видим", other generic phrases
[ ] Подпись содержит имя + title (экспертное позиционирование)
[ ] Письмо звучит как от человека, не от компании (используй "я", "нас")
[ ] Нет пунктирования в конце subject
[ ] Нет множественного восклицаний !!!
```

### Фаза 4: Отправка и таймауты

**ОБЯЗАТЕЛЬНО** выполнить:

1. Отправить письмо вручную (не bulkmail)
2. Записать дату отправки в трекер:
   ```
   Site: nalogovoe.pro
   Contact: ivan@nalogovoe.pro
   Type: GUEST_POST
   Sent: 2026-03-07
   Follow-up 1: 2026-03-10
   Follow-up 2: 2026-03-14
   Status: Waiting
   ```

3. Установить напоминание на Day 3 и Day 7 (calendar или TODO)
4. Если ответ — записать статус (Positive / Neutral / Negative)
5. Если положительный ответ — перейти на Фазу 5

### Фаза 5: После положительного ответа

- **GUEST_POST:** согласовать детали статьи (длина, заголовок, ссылки), доставить финальный текст
- **LINK_EXCHANGE:** обменяться ссылками, договориться о размещении
- **EXPERT_COMMENT:** отправить финальный текст комментария
- **MENTION_IN_REVIEW:** согласовать текст упоминания, отправить финальный вариант

**Результат:** бэклинк на сайт клиента + улучшение SEO + расширение reach

## Anti-Spam Rules (ЖЁСТКИЕ)

1. **НЕ отправлять** более 3 писем одному контакту (включая follow-up)
2. **МИНИМУМ 1 день** между письмами разным сайтам (не bulkmail за раз)
3. **ОБЯЗАТЕЛЬНО вручную** прочитать сайт (не автоматическая рассылка на ключевые слова)
4. **ФИЛЬТР:** только сайты с DA 20+ (Domain Authority, через Ahrefs / Moz / SEMrush)
5. **НИКОГДА:** не отправлять письма с поддельными именами ("Hi Friend", "Hey there")
6. **ПРОВЕРКА:** все письма должны быть одобрены человеком перед отправкой
7. **ТАЙМАУТЫ:** если 3 follow-up без ответа — архивируем (не спамим дальше)

**Последствие нарушения:** домен попадает в черный список и теряет репутацию.

## Мониторинг и метрики

Трекировать для каждой кампании:

| Метрика | Формула | Норма |
|---------|---------|-------|
| **Reply Rate** | ответы / письма | 15-25% |
| **Conversion Rate** | ссылки+статьи / письма | 5-10% |
| **Time to Reply** | дни до ответа | 1-7 дней |
| **Follow-up Success** | ответы на follow-up / follow-up отправлено | 40-50% |

Если Reply Rate < 10% → переоценить целевые сайты или улучшить персонализацию.

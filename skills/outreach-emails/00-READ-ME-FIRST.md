## Типы писем

### 1. GUEST_POST
Размещение готовой экспертной статьи. Лучший результат (бэклинк + трафик).

**Пример:** "Вот статья про налоговые риски для вашего блога — вы публикуете как есть"

### 2. EXPERT_COMMENT
Дополнение к существующей статье экспертным комментарием.

**Пример:** "Могу добавить 3 абзаца про налоговые аспекты к вашей статье про суд"

### 3. LINK_EXCHANGE
Предложение взаимного размещения ссылок (они у вас, вы у них).

**Пример:** "Обменяемся ссылками — я добавлю вас, вы добавите нас"

### 4. MENTION_IN_REVIEW
Добавление в рейтинг, список лучших сайтов или подборку.

**Пример:** "Добавьте нас в ваш рейтинг 'Топ 10 юридических сайтов'"

## Нормы успеха

- **Reply Rate:** 15-25% (1 ответ из 5-7 писем)
- **Conversion Rate:** 5-10% (1 бэклинк из 10-20 писем)
- **Time to Reply:** 1-7 дней

Если Reply Rate < 10% → переоценить целевые сайты или улучшить персонализацию.

## Основные команды

```bash
# Добавить письмо
python3 tracker_manager.py add \
  --campaign "ant-partners" \
  --website "example.com" \
  --recipient "Ivan" \
  --email "ivan@example.com" \
  --type "GUEST_POST" \
  --subject "Subject"

# Показать статус
python3 tracker_manager.py status

# Показать метрики
python3 tracker_manager.py metrics

# Ожидающие follow-up
python3 tracker_manager.py pending

# Обновить статус
python3 tracker_manager.py update --id "email-001" --status "positive"

# Отметить follow-up
python3 tracker_manager.py follow-up --id "email-001" --number 1

# Валидировать письмо
python3 validate_email.py --subject "..." --body "..."
```

## Anti-spam правила

1. НЕ отправлять более 3 писем одному контакту
2. МИНИМУМ 1 день между письмами разным сайтам
3. ОБЯЗАТЕЛЬНО вручную прочитать сайт (не рассылка)
4. Только сайты с DA 20+
5. Максимум 3 follow-up, потом архивируем

**Нарушение = домен в чёрный список**

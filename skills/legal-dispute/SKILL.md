# Скилл: Правовой спор / Legal Dispute

## Когда использовать
- Штрафы (ГИБДД, каршеринг, парковка)
- Споры с компаниями (каршеринг, кафе, магазины, сервисы)
- Нарушения прав потребителя (ЗоЗПП)
- Любые ситуации требующие юридически обоснованной позиции

## Pipeline (строго по порядку)

### 1. СБОР ФАКТОВ
- Зафиксировать: что произошло, когда, где, кто участники
- Координаты / адрес (GPS, карты)
- Фото / видео / скриншоты — всё что есть
- Переписки, уведомления, SMS
- Сохранить в `personal/[case-name]/facts.md`

### 2. ЮРИДИЧЕСКОЕ ИССЛЕДОВАНИЕ (параллельно 2-3 агента)
Запустить Task агентов с subagent_type="research-analyst" и "legal-advisor":

**Агент 1 — Нормативная база:**
- Какие законы/статьи регулируют ситуацию
- КоАП, ГК РФ, ЗоЗПП, ПДД, отраслевые законы
- Каждая статья → к какому МОМЕНТУ кейса относится и ПОЧЕМУ

**Агент 2 — Судебная практика:**
- Аналогичные дела в судах (WebSearch по судебным базам)
- Решения в пользу потребителя/гражданина
- Суммы компенсаций, формулировки судов

**Агент 3 — Форумы и опыт:**
- vc.ru, drive2.ru, pikabu, правовые форумы
- Реальный опыт людей с аналогичной проблемой
- Что сработало, что нет

**ПРАВИЛО 200%**: НЕ писать претензию пока не проверено 2-3 источниками.
Каждое утверждение = ссылка на конкретную статью закона + судебное решение.

Сохранить в `personal/[case-name]/legal-research.md`

### 3. ДОКАЗАТЕЛЬНАЯ БАЗА (максимум из терминала)
- Карты: OpenStreetMap Overpass API, Nominatim, 2ГИС, Яндекс
- Расчёты: Python (haversine, vincenty, координаты)
- Скриншоты: Playwright MCP или headless Chrome
- Календарь: Python calendar (дни недели, праздники)
- Официальные данные: геопорталы, транспортные порталы
- HTML + PDF визуализация для приложения к претензии
- Сохранить в `personal/[case-name]/evidence/`

### 4. ПРЕТЕНЗИЯ
Структура:
```
1. КТО: ФИО, контакты
2. КОМУ: юрлицо, адрес, email
3. ФАКТЫ: что произошло (дата, время, место, обстоятельства)
4. ОСНОВАНИЯ: пронумерованные аргументы, каждый со ссылкой на закон
   — Каждый аргумент = конкретный МОМЕНТ кейса + статья + почему применима
5. ПРОШУ: конкретные требования (пронумерованные)
6. ПОСЛЕДСТВИЯ: что будет при отказе (Роспотребнадзор, суд, ст.13 ч.6 ЗоЗПП)
7. ПРИЛОЖЕНИЯ: список документов
8. ДАТА, ФИО, ПОДПИСЬ
```
Сохранить в `personal/[case-name]/pretenziya.md`

### 5. ПАКЕТ ДОКУМЕНТОВ
Таблица с чеклистом:
```
| # | Документ | Статус | Файл |
|---|----------|--------|------|
| 1 | Претензия | ✅/⬜ | ... |
| 2 | Расчёты (PDF) | ✅/⬜ | ... |
| ...
```

### 6. ОТПРАВКА
- Email через Mail.app (AppleScript с вложениями)
- Чат поддержки (текст для копипаста)
- Скриншот отправки
- Дедлайны и сроки ответа

### 7. ЭСКАЛАЦИЯ (если отказ)
- Роспотребнадзор: petition.rospotrebnadzor.ru
- Пост vc.ru/claim (публичное давление)
- Иск в суд по месту жительства (ст. 17 ЗоЗПП, госпошлина = 0)
- При выигрыше: возврат + 50% штраф (ст. 13 ч.6 ЗоЗПП) + моральный вред

## Ключевые законы (шпаргалка)

### Защита прав потребителей (ЗоЗПП)
- **ст. 10** — право на информацию
- **ст. 13 ч.6** — штраф 50% в пользу потребителя при выигрыше
- **ст. 15** — компенсация морального вреда
- **ст. 16** — недействительность условий, ущемляющих права
- **ст. 17** — подсудность по месту жительства потребителя
- **ст. 22** — 10 дней на ответ на претензию
- **ст. 28** — последствия нарушения сроков
- **ст. 29** — права при обнаружении недостатков

### ГК РФ
- **ст. 15** — возмещение убытков
- **ст. 150-152** — нематериальные блага, честь, достоинство
- **ст. 165.1** — юридически значимые сообщения (доставка)
- **ст. 333** — снижение несоразмерной неустойки
- **ст. 426** — публичный договор (кафе, магазины, сервисы)
- **ст. 1064** — возмещение вреда
- **ст. 1102** — неосновательное обогащение

### КоАП РФ
- **ст. 24.5** — основания прекращения дела
- **ст. 26.2** — доказательства
- **ст. 26.8** — показания технических средств
- **ст. 28.2** — протокол
- **ст. 30.1-30.3** — обжалование (10 дней)

### Конституция РФ
- **ст. 19** — равенство прав
- **ст. 45** — защита прав и свобод
- **ст. 46** — судебная защита

## Антипаттерны
- НЕ отправлять претензию без юридической проверки
- НЕ ссылаться на статьи без проверки что они применимы к конкретному моменту
- НЕ использовать generic формулировки — каждый аргумент = конкретика
- НЕ игнорировать сроки (5 дней, 10 дней, 20 дней)

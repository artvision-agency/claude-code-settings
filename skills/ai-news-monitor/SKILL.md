# AI News Monitor — Мониторинг AI-новостей

## Цель
Собирать и фильтровать важные новости из мира AI, отправлять дайджест пользователю.

## Источники

### Веб-поиск (WebSearch)
Ключевые запросы:
- "AI news today {date}"
- "artificial intelligence breakthrough {date}"
- "LLM release announcement {date}"
- "Claude Anthropic update {date}"
- "OpenAI GPT update {date}"
- "AI agent framework new {date}"

### X/Twitter аккаунты (через WebFetch/API)
Приоритетные:
- @kaboroevich (Андрей Карпати)
- @AnthropicAI
- @OpenAI
- @GoogleDeepMind
- @xaboroev
- @alexalbert__
- @sama
- @ylecun

### Telegram каналы (через парсинг)
- Каналы определяются пользователем через фидбек

## Алгоритм

### 1. Сбор
```
WebSearch → последние 24ч AI новости
WebFetch → проверка X аккаунтов (если доступно)
```

### 2. Фильтрация (по важности)
**URGENT (немедленно)**:
- Новая модель от Anthropic/OpenAI/Google/Meta
- Крупный релиз (Claude 5, GPT-5, Gemini 3)
- Смена CEO / крупные кадровые изменения
- Регуляторные решения (запрет AI, новые законы)

**HIGH (в дайджест)**:
- Новые фреймворки для агентов
- Бенчмарки и сравнения моделей
- Крупные раунды финансирования AI-стартапов
- Прорывы в исследованиях

**NORMAL (если место в дайджесте)**:
- Обновления существующих инструментов
- Мнения и аналитика
- Кейсы применения AI

### 3. Форматирование дайджеста

```markdown
🤖 AI Digest — DD.MM.YYYY

🔴 URGENT
• [Заголовок](ссылка) — 1-2 предложения

📈 ВАЖНОЕ
• [Заголовок](ссылка) — 1-2 предложения
• [Заголовок](ссылка) — 1-2 предложения

📋 ИНТЕРЕСНОЕ
• [Заголовок](ссылка) — кратко
```

### 4. Доставка
- Отправить в Telegram через бот @avportal_bot
- chat_id: 161261562 (Антон)
- Формат: HTML с ссылками

### 5. Фидбек-луп
Пользователь реагирует:
- 👍 = больше таких новостей
- 👎 = меньше таких
- 💬 "больше про агентов" = корректировка фильтров

Фидбек сохраняется в `~/.claude/projects/-Users-antonk/memory/news-preferences.md`

## Скрипт для VPS

Создать `/root/artvision-tg-bot/ai_news_monitor.py`:
- Используй OpenRouter для суммаризации (работает из РФ)
- WebSearch через API или RSS
- Крон: каждые 4 часа (6:00, 10:00, 14:00, 18:00, 22:00 MSK)
- Лог: /var/log/ai_news_monitor.log

## Ручной запуск
При вызове `/ai-news-monitor` или "что нового в AI":
1. WebSearch за последние 24ч
2. Отфильтровать по важности
3. Показать пользователю
4. Предложить отправить в Telegram

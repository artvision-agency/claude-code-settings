# /ppc-ad-check — проверка текстов объявлений по нашим правилам

Цель: проверить, что тексты объявлений соответствуют **`~/.claude/rules/ppc-ad-copy-relevance.md`** — одинаково, детерминированно, каждый раз (не «на память»).

## Вход
- Файл с текстами (напр. `clients/<slug>/ppc/AD-TEXTS-*.md` или JSON-бэкап), ИЛИ выгрузка из кабинета (`ads.get` через API — read-only), ИЛИ текст в чате.
- Если источник не указан — спросить путь/клиента ОДНОЙ строкой.

## Шаги (выполнять по порядку)
1. **Прочитать правило целиком:** `Read ~/.claude/rules/ppc-ad-copy-relevance.md` (5 правил текста + структура полей + Поиск/РСЯ + интент-шпаргалка + запреты + DoD + конкретика AVpro с пометками актуальности).
2. **Сверить лимиты со справкой:** актуальные брать из `knowledge/services/yandex-direct/` (Заголовок1 ≤56, Заголовок2 ≤30, Текст ≤81 — на дату проверки). 🕔-пункты правила не применять вслепую.
3. **Собрать тексты** из источника (по группам: Заголовок1 / Заголовок2 / Текст / посадочная / тип Поиск|РСЯ).
4. **Прогнать каждое объявление** по чек-листу (ниже). Проверки лимитов/вхождений — кодом (длина, вхождение ключа), не на глаз (`numbers-deterministic-meaning-llm`).
5. **Вывести ОТЧЁТ одной таблицей** (формат ниже) + итог «N из M прошли».

## Чек-лист на каждое объявление (= DoD правила)
1. Ключ группы входит в Заголовок 1 (коммерч.) ИЛИ заголовок = релевантная инфо (инфо-интент).
2. Заголовок нормализован в именительный падеж (нет кривизны от склонённого ключа).
3. Интент текста = интент ключей группы (коммерч/инфо/гео/бренд/конкурент — не смешаны).
4. Текст уникален под услугу/интент (НЕ один шаблон на N групп).
5. Ключ входит и в Текст (где уместно); текст заполнен полно (близко к лимиту), не куце.
6. Оффер/акция видны в Заголовок 2 / Тексте (не спрятаны в уточнениях).
7. Посадочная релевантна запросу + HTTP 200.
8. Поиск ≠ РСЯ (в поиске точное вхождение+жёсткий CTA; в РСЯ польза/оффер, CTA мягче).
9. Быстрые ссылки = преимущества (не функц. названия); Уточнения = преимущества, ≥3.
10. Отображаемая ссылка отражает тематику запроса.
11. Лимиты символов не превышены (проверено кодом, по актуальной справке).
12. Запреты: нет AI/нейросетей; нет «Тут»/«Жми»; нет выдуманных цифр/гарантий/«опыт N лет» без подтверждения клиентом; обычная капитализация (НЕ каждое слово с большой).
13. Заливка будет OFF (`ppc-upload-always-off`); после модерации — проверить «Мало показов» (`ppc-low-impressions-zero`).

## Формат отчёта (ОДНА таблица, `single-table-progress-report`)
```
| # | Группа/объявление | Проблема (если есть) | Правило | Статус |
|---|-------------------|----------------------|---------|--------|
| 1 | Имплантация       | —                    | —       | ✅     |
| 2 | Лечение под наркозом | один текст на 14 услуг | #4 уникальность | ❌ |
| 3 | РСЯ Город         | жёсткий CTA «Звоните!» в РСЯ | #8 Поиск≠РСЯ | ⚠️ |
```
Подвал: «Прошли: X из M · ❌ критичных: Y · ⚠️ замечаний: Z · 🕔 сверить со справкой: …».
Каждое ❌ → конкретная правка (что заменить). Не «в целом ок» — только конкретика (`no-smoothing`).

## Что НЕ делает
- Не правит кабинет и не заливает (только ПРОВЕРКА; правки — отдельно, с CONFIRM Антона, `ppc-upload-always-off`).
- Не сверяет ставки/бюджеты (это другие правила).

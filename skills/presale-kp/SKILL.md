### ШАГ 2.5: АНАЛИЗ КОНКУРЕНТОВ ИЗ SERP (ОБЯЗАТЕЛЬНО!)

**Конкуренты = ТОЛЬКО из SERP.** НЕ придумывать, НЕ брать "лидеров отрасли", НЕ подставлять гигантов.

**Алгоритм:**
1. Определить 5-7 ключевых запросов клиента (из семантики или логики бизнеса)
2. WebSearch по каждому запросу → собрать ТОП-10 из Яндекс и Google
3. Найти пересечения: кто появляется в ТОП по 3+ запросам = РЕАЛЬНЫЙ конкурент
4. Отфильтровать: агрегаторы (avito, yandex.market), справочники (2gis, zoon) — не конкуренты
5. Итого: 5-8 РЕАЛЬНЫХ конкурентов, которые борются за те же позиции

**Для каждого конкурента собрать:**
- Домен, позиции по целевым запросам
- Количество проиндексированных страниц (`site:domain.com`)
- Schema.org (есть/нет)
- Контент (статьи, маршрутные страницы, калькуляторы)
- Визуальная оценка (устарел / современный)

**ЗАПРЕЩЕНО:**
- Включать в конкуренты компании которых НЕТ в SERP по запросам клиента
- Включать гигантов (Деловые Линии, ПЭК, Ozon) если они не ранжируются по тем же запросам
- Брать конкурентов "по бизнесу" без проверки их SERP-присутствия

**Результат:** `presales/[name]/reports/serp-competitors.md`

## СТРУКТУРА КП (обязательные секции)

### Вариант A — Презентационное КП (10 секций)

```
1. HERO — заголовок, метрики, CTA
2. ЭКСПРЕСС-АУДИТ — конкретные проблемы с оценками
3. О НАС — опыт, цифры
4. КЕЙС — результаты в нише
5. ПРОЦЕССЫ — этапы работы
6. КУРАТОРСТВО — проблема → решение
7. УСЛУГИ — карточки услуг
8. ФОРМАТЫ СОТРУДНИЧЕСТВА — 2 формата (см. ниже)
9. ROI / KPI
10. CTA + FOOTER
```

### Вариант B — Развёрнутый SEO-КП (15 разделов) — для сайтов с большим аудитом

```
1.  HERO + score-плашка (XX / 100)
2.  TOC С ГРУППАМИ: Аудит и диагностика / Стратегия SEO / Коммерческое предложение
3.  Три красных флага
4.  Сводный балл сайта (8 проверенных блоков)
5.  Видимость в поиске (ТОП-10 по N запросам региона)
6.  Технические находки (CRITICAL / HIGH / MEDIUM)
7.  Цена в рынке (только для коммерческих ниш)
8.  Конкуренты СПб/региона для бенчмарка
9.  Маркетплейсы / отраслевая ниша (если применимо)
10. NAP и каталоги
11. Видимость в генеративном поиске + репутация юрлица
12. СВОДНЫЙ SEO-АУДИТ — pulse-радар 4 модулей × 0–100, dashboard, «Суть аудита»
13. РАСПРЕДЕЛЕНИЕ РАБОТ — горизонты 3 / 6 / 12 мес с ожидаемыми результатами
14. ФОРМАТЫ СОТРУДНИЧЕСТВА — 2 формата (одноразовый + ежемесячный)
15. KPI на 3/6/12 мес + следующий шаг
```

**Обязательно для Варианта B:**
- Раздел «Суть аудита» в конце сводного аудита: 3 параграфа (что нашли → почему не делается за раз → почему 3/6/12)
- Sticky mini-TOC справа на ≥1024px с active-highlight
- 4 matplotlib-графика: pulse-radar / sitemap-diff / backlinks / traffic
- Виджет чата «Анна Ширшова» через `POST /api/lead`
- Mobile responsive: 6 breakpoints + `overflow-x: clip`

## WOW-ЭФФЕКТЫ (обязательны для presale!)

- Scroll-triggered fade-in (IntersectionObserver)
- Counter animation (цифры от 0 до значения)
- Card hover (подъём + тень)
- Typewriter effect на заголовке
- Progress bars для метрик аудита
- Smooth scroll по якорям
- Sticky navigation
- Floating elements / parallax (опционально)
- SVG wave dividers между секциями (если на сайте клиента)

## ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ

- **Автономный HTML** — ZERO внешних зависимостей
- **Системные шрифты** — НЕ Google Fonts CDN
- **CSS/JS inline** — в `<style>` / `<script>`
- **SVG иконки inline**
- **iOS Safari** совместимый
- **Responsive** — 1024, 768, 480px breakpoints
- **Размер** < 500KB
- **Язык** — русский (если клиент RU)

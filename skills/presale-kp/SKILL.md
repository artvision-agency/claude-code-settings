# Presale КП Generator

Создание коммерческого предложения для клиента Artvision. Полный автоматизированный pipeline.

## ⚠️ ОБЯЗАТЕЛЬНАЯ ВЕРСТКА И ДИЗАЙН (правило `feedback_kp_layout_and_design.md`)

**ВЕРСТКА — slide-каркас CAMEO/starclinic (фиксированная).** НЕ обычный одностраничник.
- **Эталон каркаса:** `clients/advertmed/40-audits/starclinic/kp.html` (915 строк) или `clients/kamey/presale/kp/cameo_kp.html`
- **Формат:** 1280×720 slide-based с навигацией dots + counter, opacity-switching
- **Типографика:** заголовки Georgia/serif, текст system sans
- **Генератор для мед-клиник:** `python3 clients/advertmed/40-audits/scripts/make_clinic_kp.py <slug>` (читает `configs/<slug>.yaml`)

**ДИЗАЙН — палитра + шрифты ИЗ САЙТА КЛИЕНТА** (`presales/<slug>/design-system.md`):
- `--primary` = top-1 hex с сайта клиента
- `--accent` = контрастный hex с того же сайта
- Шрифт — в КП system stack (без CDN), но Georgia для заголовков сохраняется как стилевой акцент

**Запрет:**

**Прецедент:** spadent v1 (11.05.2026) — собран одностраничником через Write, потребовал пересборки в slide-каркас 12.05.2026.

## Входные данные

- Аргумент 1 (обязательный): URL сайта клиента (например `demosmed.ru`)
- Аргумент 2 (опциональный): `--profile <name>` — профиль ниши клиента (см. секцию «Профили» ниже)

Если URL не указан — спросить у пользователя. Если `--profile` не указан — определить автоматически по сигналам (мед.лицензия / B2B-форма «запросить КП» / SaaS-плэны и т.д.) ИЛИ спросить пользователя при неоднозначности.

## Профили (флаг `--profile`)

Профиль определяет ДОПОЛНИТЕЛЬНЫЕ обязательные шаги/правила/цены поверх базового pipeline. **Профиль НЕ заменяет базовый pipeline** — расширяет его.

| Профиль | Когда применять | Обязательные доп. модули |
|---------|-----------------|--------------------------|
| **`medical`** | Клиника, стоматология, флебология, косметология, репродуктив, реабилитация, офтальмология | Правило `medical-kp.md` (8 инструментов аудита) + `aggregator_audit.py` (8 медкаталогов) + цены **105/135/175 K/мес** (1 филиал, см. `feedback_medical_kp_pricing_1branch.md`) + region detection из `address.city` |
| **`b2b`** | Промышленность, оптовая торговля, услуги для бизнеса, сырьё | Запрет B2C-метрик (правило R9 Puratos) — нет ARPU/GMV/корзины. Поиск соцсетей по паттерну `{brand}_russia` / `{brand}RU` (R8). B2B-маркетплейсы: TIU/B2B-Center/Дистриклуб (НЕ WB/Ozon). Метрики: lead-to-deal, цикл сделки, retention. |
| **`seo`** | Чистый SEO без узкой ниши (массовые B2C сервисы, инфо-ресурсы) | Горизонты 3 / 6 / 12 мес из `seo-kp-horizons.md` (3 цветные карточки + блок «Суть аудита»). 2 формата сотрудничества (одноразовый план + ежемесячный). |
| **`saas`** | SaaS-продукт с подпиской / freemium | Метрики MRR / CAC / LTV / Churn. Воронка: Trial → Activation → Subscription. Функционал и интеграции в фокусе. |
| **`local`** | Местный бизнес: салон, кафе, автосервис, ремонт, услуги района | Я.Карты + 2GIS как канал #1 (см. `local-seo` skill). NAP-консистентность в 6+ каталогах. Отзывы как KPI. |
| **`industrial`** | Тяжёлая промышленность, бурение, инжиниринг, заводы | B2B-промышленный — длинный цикл (3-9 мес), госконтракты/тендеры, реквизиты юрлица в видимом месте, фокус на доверие. |

**Правила выбора профиля:**
- Если в КП попадает мед.клиника — ВСЕГДА `medical` (правило `medical-kp.md` обязательно).
- Если есть наложение (B2B-фарма, медицинский SaaS) — приоритет `medical`, дополнительные модули из второго профиля подключаются вручную.
- Профиль `seo` — дефолтный fallback, если ничего другого не подходит.

### ШАГ 2.5: АНАЛИЗ КОНКУРЕНТОВ ИЗ SERP (ОБЯЗАТЕЛЬНО!)

**Конкуренты = ТОЛЬКО из SERP.** НЕ придумывать, НЕ брать "лидеров отрасли", НЕ подставлять гигантов.

**Алгоритм:**
1. Определить 5-7 ключевых запросов клиента (из семантики или логики бизнеса)
2. WebSearch по каждому запросу → собрать ТОП-10 из Яндекс и Google
3. Найти пересечения: кто появляется в ТОП по 3+ запросам = РЕАЛЬНЫЙ конкурент
4. Отфильтровать: агрегаторы (avito, yandex.market), справочники (2gis, zoon) — не конкуренты
5. Итого: 5-8 РЕАЛЬНЫХ конкурентов, которые борются за те же позиции

**Для каждого конкурента собрать:**
- Домен, позиции по целевым запросам
- Количество проиндексированных страниц (`site:domain.com`)
- Schema.org (есть/нет)
- Контент (статьи, маршрутные страницы, калькуляторы)
- Визуальная оценка (устарел / современный)

**ЗАПРЕЩЕНО:**
- Включать в конкуренты компании которых НЕТ в SERP по запросам клиента
- Включать гигантов (Деловые Линии, ПЭК, Ozon) если они не ранжируются по тем же запросам
- Брать конкурентов "по бизнесу" без проверки их SERP-присутствия

**Результат:** `presales/[name]/reports/serp-competitors.md`

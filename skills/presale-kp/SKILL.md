# Presale КП Generator

Создание коммерческого предложения для клиента Artvision. Полный автоматизированный pipeline.

## Входные данные

Аргумент: URL сайта клиента (например `demosmed.ru`)

Если URL не указан — спросить у пользователя.

## PIPELINE (выполнять СТРОГО последовательно!)

### ШАГ 1: ИЗВЛЕЧЕНИЕ ДИЗАЙН-СИСТЕМЫ КЛИЕНТА

**Агент:** `design-system-architect`

**ОБЯЗАТЕЛЬНО перед любой генерацией!**

Извлечь с сайта клиента:

```bash
# Цвета
curl -sL [URL] | grep -oE '#[0-9a-fA-F]{3,8}' | sort -u

# Шрифты
curl -sL [URL] | grep -oE 'font-family:[^;]+' | sort -u

# Визуальный анализ
WebFetch [URL] → "Extract complete design system: brand colors (hex), fonts, button styles, card styles, backgrounds, gradients, section layout"
```

Playwright скриншоты (если доступен):
- Hero секция
- Карточки/услуги
- Footer
- Full page

**Результат:** Сохранить в `presales/[name]/design-system.md`:

### ШАГ 2.5: АНАЛИЗ КОНКУРЕНТОВ ИЗ SERP (ОБЯЗАТЕЛЬНО!)

**Конкуренты = ТОЛЬКО из SERP.** НЕ придумывать, НЕ брать "лидеров отрасли", НЕ подставлять гигантов.

**Алгоритм:**
1. Определить 5-7 ключевых запросов клиента (из семантики или логики бизнеса)
2. WebSearch по каждому запросу → собрать ТОП-10 из Яндекс и Google
3. Найти пересечения: кто появляется в ТОП по 3+ запросам = РЕАЛЬНЫЙ конкурент
4. Отфильтровать: агрегаторы (avito, yandex.market), справочники (2gis, zoon) — не конкуренты
5. Итого: 5-8 РЕАЛЬНЫХ конкурентов, которые борются за те же позиции

**Для каждого конкурента собрать:**
- Домен, позиции по целевым запросам
- Количество проиндексированных страниц (`site:domain.com`)
- Schema.org (есть/нет)
- Контент (статьи, маршрутные страницы, калькуляторы)
- Визуальная оценка (устарел / современный)

**ЗАПРЕЩЕНО:**
- Включать в конкуренты компании которых НЕТ в SERP по запросам клиента
- Включать гигантов (Деловые Линии, ПЭК, Ozon) если они не ранжируются по тем же запросам
- Брать конкурентов "по бизнесу" без проверки их SERP-присутствия

**Результат:** `presales/[name]/reports/serp-competitors.md`

## СТРУКТУРА КП (обязательные секции)

```
1. HERO — заголовок, метрики, CTA (typewriter/counter animations)
2. ЭКСПРЕСС-АУДИТ — конкретные проблемы сайта клиента с оценками
3. О НАС — Artvision: опыт, цифры, уникальные преимущества
4. КЕЙС — конкретные результаты в нише клиента (counter animations)
5. ПРОЦЕССЫ — этапы работы, timeline, roadmap
6. КУРАТОРСТВО — подробная секция (проблема → решение → формат)
7. УСЛУГИ — карточки с иконками и hover-эффектами
8. ТАРИФЫ — 3 колонки (стартовый / оптимальный / комплексный)
9. ROI — прогноз результатов (animated counters)
10. CTA + FOOTER — контакты, призыв к действию
```

## WOW-ЭФФЕКТЫ (обязательны для presale!)

- Scroll-triggered fade-in (IntersectionObserver)
- Counter animation (цифры от 0 до значения)
- Card hover (подъём + тень)
- Typewriter effect на заголовке
- Progress bars для метрик аудита
- Smooth scroll по якорям
- Sticky navigation
- Floating elements / parallax (опционально)
- SVG wave dividers между секциями (если на сайте клиента)

## ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ

- **Автономный HTML** — ZERO внешних зависимостей
- **Системные шрифты** — НЕ Google Fonts CDN
- **CSS/JS inline** — в `<style>` / `<script>`
- **SVG иконки inline**
- **iOS Safari** совместимый
- **Responsive** — 1024, 768, 480px breakpoints
- **Размер** < 500KB
- **Язык** — русский (если клиент RU)


### Блок 2: Видимость в AI-поисковиках (AIvision)
```html
<section class="upsell">
  <h2>Дополнительно: видимость в ChatGPT, Алисе, Perplexity</h2>
  <p>Ваши конкуренты уже появляются в ответах AI.
```

Только "партнёрские ресурсы", "авторская методология", "экспертный анализ".

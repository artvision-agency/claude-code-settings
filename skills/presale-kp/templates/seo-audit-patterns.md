## 1. Графики (matplotlib) — обязательный набор из 4

Палитра единая для всех КП:
- `PRIMARY=#2c3e88` (синий) — наши данные / положительная динамика
- `WARN=#d97706` (оранжевый) — проблемы / отстающие конкуренты
- `GREEN=#15803d` (зелёный) — целевое состояние / лидеры
- `GREY=#9ca3af` — нейтральные/референс линии

Скрипт-источник: `~/.claude/skills/presale-kp/templates/gen-charts.py` (параметризован по `--client <slug>`).

| График | Что показывает | Когда обязателен | Размер |
|--------|----------------|------------------|--------|
| **pulse-radar** | 4-модульный SEO-аудит на круге (commercial / text / link / behavioral × 0-100) | Все SEO-КП с аудитом | 800×800, square |
| **sitemap-diff** | Объём индексируемого контента: клиент vs 3 конкурента (страницы услуг / блог / статичные) | Клиент жалуется на низкий трафик / сравниваем нишу | 1000×600, horizontal |
| **backlinks** | Динамика ссылочного профиля 12 мес: клиент vs 3 конкурента (RD на временной оси) | Линкбилдинг в плане работ | 1000×500, line chart |
| **traffic** | Поисковый трафик за 12 мес: клиент vs 3 конкурента (visits на временной оси) | Есть данные SimilarWeb / metrika | 1000×500, line chart |

**Важно:** график без данных = НЕ генерить. Лучше отсутствие графика, чем «примерные» цифры.

## 2. Структура SEO-КП — Вариант B (15 разделов)

Применять когда есть полноценный аудит из 4 модулей. Простые лендинги — Вариант A (10 секций) из `SKILL.md`.

```
1.  HERO + score-плашка (XX / 100)
2.  TOC С ГРУППАМИ: Аудит / Стратегия / КП
3.  Три красных флага  ← быстрые wins на 2-м экране
4.  Сводный балл сайта (8 проверенных блоков)
5.  Видимость в поиске (ТОП-10 по N запросам региона)
6.  Технические находки (CRITICAL / HIGH / MEDIUM)
7.  Цена в рынке (только для коммерческих ниш)
8.  Конкуренты СПб/региона для бенчмарка
9.  Маркетплейсы / отраслевая ниша (если применимо)
10. NAP и каталоги
11. Видимость в генеративном поиске + репутация юрлица
12. СВОДНЫЙ SEO-АУДИТ — pulse-радар, dashboard, «Суть аудита»
13. РАСПРЕДЕЛЕНИЕ РАБОТ — горизонты 3 / 6 / 12 мес
14. ФОРМАТЫ СОТРУДНИЧЕСТВА — 2 формата (одноразовый + ежемесячный)
15. KPI на 3/6/12 + следующий шаг
```

Полный скелет: `seo-kp-structure.md`.

## 4. Принцип «диагностика без рекомендаций»

В разделах 1-9 (диагностические) — **только проблемы и факты, без рекомендаций «нужно сделать X»**.

Рекомендации — только в разделе 13 (план работ), и **общими формулировками**:
- ✅ «внедрение структурированных данных»
- ❌ «JSON-LD: LocalBusiness + Service + PostalAddress»

Чтобы клиент сам по плану не делал → детали остаются в реализации (формат 70К/мес).

## 5. Хук `pre-kp-bred-block.sh` — 7 категорий блокировки

Срабатывает на Write/Edit в `clients/*/kp/*.html` или `presale/kp/*.html`. Блокирует:
1. **FINANCIALS / REVENUE_DELTA** — выручка/прибыль клиента в КП запрещены
2. **INTERNAL_MARKERS** — UNCONFIRMED/CONFIRMED/curl/WebFetch/API в видимом тексте
3. **ARTVISION_PRO / ARTVISION_BRAND** — упоминания artvision.pro / Flow/Radar в КП партнёра (AdvertMed)
4. **AI_MODELS / AI_PROVIDERS / LLM_MENTIONS** — табу AI/LLM/Llama/ChatGPT/Groq
5. **HARSH_WORDS** — обвал/мина/токсичн/галлюциниру/диссонанс
6. **SALES_CLICHES** — гарантирую ТОП / стать №1 / премиум / уникальное / под ключ
7. **PLAN_OVER_DETAIL** — JSON-LD: LocalBusiness + (избыточная техническая детализация плана)
8. **ARTVISION_CONTACTS** — телефон/email/Telegram Артвишн в КП клиента

Тесты: `~/.claude/hooks/tests/test-pre-kp-bred-block.sh` (21 PASS).

## 7. Audit-папка клиента — 5 модулей

Структура `clients/<name>/audit/`:
```
audit/
├── index.html                    # сводный — со score, ссылками на 4 модуля
├── commercial-YYYY-MM-DD.html   # коммерческие факторы
├── text-YYYY-MM-DD.html         # текстовые факторы (TF-IDF, Title/H1, дубли)
├── link-YYYY-MM-DD.html         # ссылочные факторы
└── behavioral-YYYY-MM-DD.html   # поведенческие факторы (Я.Карты, отзывы)
```

`pulse-radar.png` строится из 4 модулей × 0-100.

## 8. Антипаттерны

| ❌ | ✅ |
|---|---|
| Графики с «примерными» цифрами без источника | График без данных лучше, чем фейк |
| 3-колоночные тарифы (стандарт/опт/комплекс) | 2 формата (одноразовый план + ежемесячное сопровождение) |
| Title с «× Artvision» в КП клиента | Без упоминания агентства в title |
| Контакты Артвишн (тел/email/TG) в КП клиента | Только виджет чата с менеджером (псевдо-имя) |
| Технический план с конкретикой (JSON-LD: ...) | Общие формулировки в плане, детали в реализации |
| AI/LLM/ChatGPT/Groq в видимом тексте | «генеративные ассистенты поиска», «авторская методология» |
| Резкие слова (обвал, мина, токсичн) | Деловой нейтральный язык |

# Quality Gates — ОБЯЗАТЕЛЬНЫЕ проверки по типу задачи

> **ЖЁСТКОЕ ПРАВИЛО:** каждый тип задачи имеет свой обязательный набор инструментов.
> Пропуск любого шага = потенциальная ошибка, которую клиент найдёт за нас.
> Инцидент: 3 фактчека на КП Roman Mebel, каждый находил новые ошибки (2026-03-23).

## Корневая причина инцидента

1. **Агенты research-analyst** НЕ имеют Bash → не делают HTTP HEAD → не проверяют URL
2. **Замена URL "вслепую"** — подставлены выдуманные URLs без проверки что они существуют
3. **Нет обязательного скрипта** — factcheck-v2.py не вызывался автоматически до деплоя

## ОБЯЗАТЕЛЬНЫЕ GATES по типу задачи

### 📄 КП / HTML для клиента

| Шаг | Инструмент | Что проверяет | Кто |
|-----|-----------|--------------|-----|
| 1. Сбор данных | WebFetch + WebSearch | Реальные данные, 2+ источника | Claude |
| 2. Генерация HTML | Write/Edit | Создание файла | Claude |
| 3. **URL-валидация** | `factcheck-v2.py --standard` | HTTP HEAD на ВСЕ ссылки и картинки | **СКРИПТ (обязательно!)** |
| 4. Визуальная проверка | Playwright screenshot | Скриншот на 3 breakpoints | Claude |
| 5. **Фактчекинг чисел** | Senior-агент (`code-reviewer`) | Перекрёстная проверка утверждений | **Агент с Bash** |
| 6. Деплой на VPS | scp | Загрузка | Claude |
| 7. **Post-deploy проверка** | curl -sI на каждый URL в HTML | Все ресурсы доступны? | **СКРИПТ** |

**БЛОКЕР:** шаги 3 и 5 ОБЯЗАТЕЛЬНЫ перед шагом 6. Без них → НЕ деплоить.

### 🔗 Замена URL в HTML

| Шаг | Что делать |
|-----|-----------|
| 1. Найти реальный URL | Playwright → page.evaluate → собрать img src с сайта |
| 2. Проверить URL | `curl -sI URL` → 200? |
| 3. Заменить | Edit tool |
| 4. Перепроверить | `factcheck-v2.py` |

**ЗАПРЕЩЕНО:** подставлять URL по памяти или по шаблону (resize_cache/iblock/xxx). ТОЛЬКО реальные URL, проверенные HTTP-запросом.

### 📊 Данные/числа в документах клиента

| Шаг | Что делать |
|-----|-----------|
| 1. Найти число | WebSearch/WebFetch из 2+ источников |
| 2. Маркировать | CONFIRMED / UNCONFIRMED / WRONG |
| 3. Источник | Прямая ссылка рядом с числом |
| 4. Проверить ссылку | curl -sI → 200? |

### 🤖 Выбор агента по задаче

| Задача | Нужен Bash? | Агент | Почему |
|--------|:-----------:|-------|--------|
| Фактчекинг URL/ассетов | ✅ | `general-purpose` или скрипт | HTTP HEAD требует Bash |
| Фактчекинг чисел | ✅ | `code-reviewer` / `general-purpose` | WebSearch + Bash для проверки |
| Анализ конкурентов | ⚪ | `research-analyst` | Только сбор данных, без HTTP |
| Деплой на VPS | ✅ | `general-purpose` / `devops-engineer` | scp требует Bash |
| SEO аудит | ✅ | `seo-analyzer` | Краул + анализ |
| Код-ревью | ⚪ | `code-reviewer` | Только чтение кода |
| Визуальная проверка | ✅ | `ui-visual-validator` | Скриншоты через Playwright |

**ПРАВИЛО:** если задача требует HTTP-запросов или работы с файловой системой → агент ОБЯЗАН иметь Bash. `research-analyst` НЕ подходит.

## Автоматика (хуки)

- `factcheck-v2.py` → вызывать ПЕРЕД каждым `scp` в clients/
- Post-deploy: `curl -sI` на 5 случайных URL из HTML
- Если CRITICAL > 0 → БЛОК деплоя, показать ошибки

## Памятка для Антона и Андрея

```
ПЕРЕД отправкой клиенту — ВСЕГДА:
1. /factcheck <файл>        ← скрипт, не агент
2. Проверить VERDICT         ← FAILED = не отправлять
3. Исправить CRITICAL        ← все до нуля
4. Перепроверить              ← повторный /factcheck
5. Только после PASS/REVIEW  ← можно отправлять
```

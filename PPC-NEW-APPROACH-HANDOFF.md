## НОВЫЙ ПОРЯДОК (поступательно, HARD)
1. **ЗАГОТОВКИ в файлах (БЕЗ API):** тексты, семантика, структура РК, баннеры — всё в Excel/CSV/HTML-превью. API Яндекса НЕ дёргать.

4. **ВВОД В АККАУНТ:** только после согласования всего → заливка скриптом, всё OFF (`ppc-upload-always-off`).

## ЖЁСТКИЕ ПРАВИЛА API (когда дошли до Фазы 4)
- **CONFIRM-ГЕЙТ:** любое API-write (заливка/правка кампаний/объявлений/ставок/статусов/баннеров) — СНАЧАЛА запрос Антону «собираюсь сделать X — подтверди» → ждать «да» → выполнять. Как finance-gate.
- Ответ API → в ФАЙЛ (`clients/usmile/ppc/data/*.json`), в чат только СВОДКА. НЕ печатать полный JSON.
- FieldNames-минимум `["Id","State","CampaignId"]`. jq-фильтр точечно. cabinet-verify → summary.

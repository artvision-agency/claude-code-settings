# Калькулятор недвижимости — обязательные факторы учёта

> **HARD-ENFORCE правило** для любого калькулятора ипотеки / квартирного инвест-анализа Антона.
> Установлено: 2026-05-16 (correction Антона #21).
> Связано: `~/.claude/projects/-Users-antonk/memory/feedback_always_cite_date_time_source.md`.

## 7 обязательных факторов в калькуляторе квартир

Каждый калькулятор/анализ квартир для Антона ОБЯЗАН учитывать или хотя бы явно показывать наличие/отсутствие этих факторов:

### 1. Сравнение обещаний застройщика vs реальности по сданным объектам
- WebSearch + Я.Карты reviews по УЖЕ построенным ЖК этого застройщика
- Анализ паттерна: что обещали в рекламе (виды, инфраструктура, отделка) vs что получили дольщики
- Источники: spbguru.ru/companies/<id>/reviews, novostroy.spb.ru/company/<name>/otzyvy, Я.Карты org reviews
- Метрика: «delivered ≥ promised ?», 🟢 точное соответствие / 🟡 расхождения / 🔴 системный обман

### 2. Управляющая компания (УК) — оценка работы
- Время приёмки квартиры (пример ПИК — 60 дней на каждую правку)
- Скорость реакции на гарантийные обращения
- Стоимость обслуживания ₽/м²/мес (если выше среднего по СПб 35-50 ₽/м² → flag)
- Источники: chatdoma.ru, spbguru.ru reviews конкретного ЖК → блок «УК»
- Я.Карты org reviews самой УК (часто отдельная org от застройщика)
- Метрика: 🟢 быстро/дёшево / 🟡 средне / 🔴 жалобы массовые

### 3. Видовые риски — проверка дезинформации через кадастр
- Если в маркетинге ЖК «N% видовых квартир» — проверить:
  - Кадастровая карта Росреестра (pkk.rosreestr.ru) — есть ли участки под застройку в радиусе 500-1000 м
  - Genplan СПб (gov.spb.ru/gov/admin/otrasl/c_economy/development) — план застройки района
  - КГА СПб — разрешения на строительство соседних участков
  - Высота соседних зданий + этажность будущих
- Метрика: реальный % видовых = заявленный % × (1 − заслонённость)
- Если заявленный обманчив — risk-badge 🟠

### 4. Стоимость отделки и ремонта
- Тип отделки в базовой цене: «без отделки» / «подчистовая (white-box)» / «чистовая (под ключ)» / «с мебелью»
- Доп.стоимость доведения до жилого:
  - White-box → «эконом»: 15-20 К/м²
  - White-box → «комфорт»: 25-35 К/м²
  - Без отделки → «эконом»: 30-45 К/м²
  - Без отделки → «комфорт»: 50-70 К/м²
  - Чистовая → «комфорт»: 5-10 К/м²
- Мебель: +200-400 К студия / +400-700 К однушка
- Учитывать в полной стоимости владения (TCO) И в cashflow если под сдачу
- Источник: artum.studio, prorabneva.ru, vse-podklyuch.ru, ремонт-цены-СПб (16.05.2026)

### 5. Кредит на ремонт (отдельно от ипотеки)
- Если ремонт > 500К — учесть как отдельный кредит (потребительский 18-25% / ипотечный +500К сверху по той же ставке)
- Расчёт: payment(ремонт_сумма, потребительская_ставка, 5_лет) добавляется к ипотеке в первые 5 лет
- Альтернатива: ремонт из накоплений (cashflow в первые годы должен покрыть)
- Опция в калькуляторе: чекбокс «Кредит на ремонт»

### 6. Расчёт по выбранному режиму (сценарию)
- **Аренда:** обязательно чистовая (иначе мебель → ремонт → 6+ мес простой); опция мебель
- **Долгосрок продажа (5-10 лет):** минимизация capex — без отделки и без ремонта, цена за рост
- **Флип (купил→ключи→продал):** косметика 50-100К опционально для предпродажи; только готовые объекты ≤12 мес от сегодня

Каждый сценарий ВКЛЮЧАЕТ свои расходы в формулу прибыли — не одна универсальная таблица для всех.

### 7. Внешние факторы влияющие на стоимость и аренду
- Соседние ЖК (когда сдаются → конкурентное предложение)
- Транспорт (метро открытие → +X% к цене за 6-12 мес)
- Школы/инфраструктура (детсад в шаговой → +5-10% к аренде семьям)
- Промзоны / экология (фарм-производство рядом → −5-15% к цене)
- Источники: research-агент по инфраструктуре + новости КГА

## Применение

При работе с любым калькулятором квартир Антону Claude обязан:
1. Прочитать это правило ПЕРЕД написанием калькулятора
2. Каждый из 7 факторов либо реализовать в коде/UI, либо явно пометить «УПУЩЕНО — почему»
3. В калькуляторе показать tooltip/блок «Учтены факторы: N/7» с разбивкой

## Антипаттерны

- ❌ Считать прибыль только из цены × ставки, без отделки/ремонта/УК
- ❌ Доверять маркетинговому «N% видовых» без проверки кадастра
- ❌ Игнорировать УК — она съедает 5-15% дохода под сдачу через переплату ЖКХ
- ❌ Одинаковая формула для аренды/продажи/флипа

- Если найдено <4 из 7 → WARN с напоминанием правила

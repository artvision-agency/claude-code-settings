# КП — начинается с КОНКУРЕНТНОГО РАЗРЫВА (трафик + позиции)

> **Установлено:** 2026-05-12, Антон.
> **Применять:** ВСЕ presale-КП Artvision где мы продаём SEO.
> **Прецедент:** spadent КП v1 (11.05) начинался с «3 красных флага по сайту» (тех. долг, скорость, Schema) — Антон поправил: «мы продаём позиции и трафик, а не правки сайта».

## Главный принцип

**Мы продаём ПОЗИЦИИ и ТРАФИК.** Технический долг — следствие, не главное.

КП открывается **разрывом с конкурентами**, не диагностикой сайта.

## Структура первой содержательной секции КП (после hero)

### Заголовок: «Что делают конкуренты — а вы нет»

3-4 факта формата «**Они → У вас → Разрыв**»:

| Что делает конкурент | У вас сейчас | Разрыв |
|---|---|---|
| Юлистом — публикует прайс на главной (от 3 300 ₽) | Цены скрыты | -25-40% конверсии с холодного трафика |
| Витаника (сеть 12) — публикует 8 статей/мес в блог | Блог брошен с 11.2023 | -100% информационного трафика |
| СтомаГрад — собрал 80+ отзывов на ProDoctorov | 15 отзывов | -50% доверия в локальной выдаче |
| Юлистом — mobile Perf 70 | Mobile Perf 47-57 | -30% мобильного ранжирования |

### Заголовок: «Конкуренты собирают трафик — вы остаётесь на сарафане»

| Конкурент | Органический трафик/мес (оценка) | Позиций в ТОП-10 Я. | Канал #1 |
|---|---|---|---|
| Витаника (12 клиник) | ~10 000+ визитов | 80-150 | Поиск + блог |
| Юлистом (Дунайский) | ~2 000-3 000 | 30-50 | Поиск + карты |
| СтомаГрад | ~1 500-2 500 | 20-40 | Поиск + крауд |
| **SpaDent** | **<500** (оценка) | **<10** | Я.Карты + сарафан |

→ **Разрыв с лидером района ≈ ×20-30** по органическому трафику.
→ Каждый месяц без SEO — упущенные 30-60 первичных пациентов из поиска.

### Заголовок: «Это НАДО делать, потому что:»

1. **Конкуренты уже это делают** (доказательство: их позиции и трафик)
2. **Стоимость пациента из поиска <CPL Директа в 3-5×** (доказательство: средние данные по нише)
3. **Канал устойчив** — карты могут заблокировать, рекламу остановить. Органика — актив, который остаётся

## Запрет на старте КП

В первой секции **НЕ начинать с:**
- ❌ «3 красных флага сайта» (тех. долг, мобильность, Schema)
- ❌ «Что не так на сайте» (исправление как продукт)
- ❌ Lighthouse оценки (это диагностика, не аргумент к покупке)
- ❌ «Чтобы получить ТОП — нужно сделать X» (общие слова)

Эти блоки оставлять — но **ПОСЛЕ** разрыва с конкурентами.

## Источники данных для разрыва

**Обязательные:**
- Топ-10 Я. по 5-7 целевым запросам (Topvisor с lr=регион клиента) → позиции конкурентов
- SEMrush / Keys.so → траффик конкурентов и клиента (organic visits/month)
- Я.Карты / 2GIS / ProDoctorov → отзывы и рейтинги (если local)
- Open data сайтов конкурентов → cены публичные / нет, есть ли блог, сколько статей

**Если SEMrush недоступен** (UI session expired) — взять оценки через:
- Я.Метрика конкурентов (если есть открытый счётчик)
- SimilarWeb-snippet через WebSearch «site:similarweb.com <domain>»
- Pr-cy.ru → страниц в индексе × средний CTR
- Заявить «оценка», не выдавать за факт

# PPC FILE-ONLY режим — Claude НЕ грузит в кабинет, только файлы (HARD, по требованию Антона)

> **Установлено:** 2026-06-22 (Антон, USmile PPC, дословно: «мы можем работать так чтобы ты вообще ничего не грузил туда? только с файлами? мне это очень важно»). Контекст: Антон начал править кампании в Я.Директ ВРУЧНУЮ.
> **Связано:** `ppc-upload-always-off.md`, `pre-bash-ppc-api-write-gate.sh` (CONFIRM-гейт на API-write), `orchestration-method-selection.md` ОСЬ #3 (антиколлизия — 2 писателя в один ресурс = race), `determinism-first-and-verify.md`, `explicit-approval-tracking.md`.

## Правило (HARD)
Когда включён FILE-ONLY режим — Claude **НЕ выполняет НИ ОДНОГО API-write** в рекламный кабинет (Я.Директ/eLama/VK Ads): запрещены `ads.add/update/moderate`, `campaigns.add/update/suspend/resume`, `keywords.add/update`, `adgroups.*`, любые заливки/импорты/правки структуры. Результат работы Claude = **только файлы** (CSV/Excel для Директ-Коммандера, JSON, build-выгрузки, тексты, ключи, минус-слова, URL-инвентарь, документы). **Заливку/правку в кабинет делает Антон сам** (вручную / Коммандер).

## Почему (корень)
Антон правит кабинет вручную. Если Claude параллельно пишет в тот же кабинет — **перезатирание правок / race condition** (ОСЬ #3 antiколлизия: 2 писателя в один ресурс). FILE-ONLY = один писатель (Антон) → коллизий нет.

## Что Claude МОЖЕТ в этом режиме
- ✅ READ из кабинета (`.get`) — только по явной просьбе, результат помечать «снимок на ЧЧ:ММ ДД.ММ» (данные могут устареть, т.к. Антон правит параллельно).
- ✅ Готовить файлы-деливераблы: структура РК, тексты объявлений (по `ppc-ad-copy-relevance`), кластеры, ключи, минус-слова, URL-инвентарь, отчёты, чек-листы.
- ✅ Формат под ручную загрузку: CSV/XLSX для Директ-Коммандера ИЛИ инструкция «что куда вставить».

## Что Claude НЕ может
- ❌ Любой API-write в кабинет (заливка/правка/модерация/пауза/включение/ставки).
- ❌ «Я сам быстро залью выключенными» — НЕТ. Даже OFF-заливка = write в общий ресурс → коллизия с ручными правками Антона.
- ❌ Считать READ-снимок «текущим» без пометки времени (Антон правит → снимок устаревает мгновенно).

## Как выключить режим
Только по явному «теперь можешь грузить сам / залей в кабинет» от Антона. По умолчанию для USmile PPC (2026-06-22) — режим ВКЛЮЧЁН.

## Антипаттерны
- ❌ Залить/поправить что-либо в кабинет пока Антон правит вручную (перезатрём друг друга).
- ❌ Игнорировать режим «раз задача срочная».
- ❌ Выдать READ-снимок за актуальное состояние без метки времени.

## Sync
`~/.claude/rules/` → 3 аккаунта. Дефолт для USmile; для других PPC-клиентов уточнять у Антона (он сказал «это очень важно»).

# PPC: групп со статусом «Мало показов» должно быть ≈0 (HARD, отслеживать)

> **Установлено:** 2026-06-21 (Антон, USmile PPC, подробно по шагам). «Группировка ключей очень важна. У группы объявлений есть статус „мало показов" — такие группы НЕ работают. Корень — плохая кластеризация / мало показов в группе. ВАЖНО: пока не загрузишь аккаунт, не понять, достаточно ли показов. Поэтому в наш флоу добавить: после заливки+модерации проверить ВСЕ группы ВСЕХ кампаний, и склеить/перегруппировать так, чтобы групп „мало показов" было ≈0.»
> **Связано:** `tfidf-clustering.md` (SERP-кластеризация), `ppc-upload-always-off`, `determinism-first-and-verify`, `ppc-launch-playbook`, BUILD-SPEC USmile.

## Правило (HARD)
Цель сборки PPC-аккаунта: **число групп объявлений со статусом «Мало показов» (Rarely served) ≈ 0.** Такие группы НЕ показываются → не работают → ключи в них мёртвые.

## Почему нельзя предугадать до заливки
Статус «мало показов» Яндекс присваивает группе по СОВОКУПНОЙ частотности её ключей — и виден **только ПОСЛЕ заливки в аккаунт + модерации** (живой сигнал, не из Wordstat/прогноза). Поэтому это **пост-загрузочный шаг флоу**, а не пред-расчёт.

## Шаги флоу (добавить после заливки всех кампаний)
1. Залить все кампании (OFF) → отправить на модерацию (CONFIRM Антона, помнить flip→ON→suspend).
2. После модерации — **прочитать статус ВСЕХ групп ВСЕХ кампаний** (`adgroups.get` FieldNames ServingStatus / Status — статус «Мало показов» = `RARELY_SERVED` / низкий показ).
3. Для каждой группы «мало показов»: **НЕ удалять ключи**, а:
   - перенести ключи в существующую группу того же интента/кластера, где показов достаточно (склеить), ЛИБО
   - склеить несколько «мало показов» групп между собой в одну (если суммарно набирают объём).
   - решение по каждой — обдумать (какой кластер ближе), не механически.
4. Повторять, **пока групп со статусом «мало показов» не станет ≈0.**
5. Зафиксировать: число таких групп = 0 (или обоснованный минимум) — критерий готовности аккаунта.

## Связь с кластеризацией (корень)
Если «мало показов» групп МНОГО — корень в **плохой кластеризации** (слишком дробные группы). Пересмотреть группировку: укрупнять кластеры до достаточной частотности (tfidf-clustering: объём показов на группу — критерий укрупнения), сохраняя единый интент/посадочную.

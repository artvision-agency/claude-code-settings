# Figma MCP — массовая генерация редактируемых макетов (мастер-макет + CSV)

> **Установлено:** 2026-06-12 (Антон). Источник: video-learn видео «Claude сам работает в Figma — 800 макетов за минуты» (канал «Контент продаёт», youtube -Fm3Kh3VrcM). Конспект: `~/artvision-data/personal/video-learn/2026-06-12-figma-mcp-bulk/`.
> **Цель Антона:** иметь ВОЗМОЖНОСТЬ (используем/не используем) генерить серии бренд-точных карточек/баннеров через Figma, а не только text-to-image.
> **Связано:** `model-bakeoff.md` (выбор инструмента + PROVENANCE), `template-selection-map.md` (классы артефактов), `ad-creative`/`yandex-direct-creatives` (РСЯ-форматы), `smm-post-production.md`, `figma-export` (чтение Figma), `proven-tools-first.md`, `image-quality-standard.md`, скилл `/figma-bulk-creative`.

## Что это (метод)
Claude + **Figma MCP (write-capable)** + **мастер-макет на автолейаутах** + **CSV-номенклатура** → массовая генерация УНИКАЛЬНЫХ **РЕДАКТИРУЕМЫХ** фреймов (карточки маркетплейса, РСЯ-баннеры серией, SMM-серии). Код читает ID фрейма и текстовых/слой-блоков в Figma → мапит на строки CSV → создаёт фрейм на каждую строку. Каждая строка = уникальная обложка. Результат редактируемый (каждый слой доступен).

## Развилка инструментов (главное — «Figma-MCP vs image-gen», не «или-или»)
ДВА слоя, выбирать под задачу (это и есть `model-bakeoff`):

| Слой | Инструмент | Когда |
|---|---|---|
| **Бренд-точный макет/типографика/раскладка серией** | **Figma MCP** (этот метод) | нужны редактируемые, пиксельно-точные, бренд-консистентные макеты в N вариациях (карточки товара, серия баннеров, SMM-серия по шаблону). Переменные текст/цвет/иконка/фон по CSV. |
| **Генерация самого изображения (товар/сцена/фон)** | image-gen (Nano Banana Pro / FLUX / ComfyUI / «Хиксл»-class) — `model-bakeoff` | нужно СОЗДАТЬ картинку (товар в среде, фон, креатив с нуля). |
| **Комбо (полная карточка)** | image-gen → картинка → Figma MCP вставляет в макет | товарное фото + инфографика по шаблону. |

- **Браузерная версия Claude (computer vision + Chrome)** для визуала СЛАБА (JPEG-референс → неточно). Годится для изучения интерфейсов/заявок, НЕ для пиксельного дизайна. Точность даёт ТОЛЬКО работа с редактируемым макетом (Figma-приложение + MCP).
- Подписывать автора результата (PROVENANCE, `model-bakeoff`): `AUTHOR: <Figma MCP | image-модель> · <скилл> · дата`.

## Лестница автоматизации дизайна (честно — что видео даёт, что нет)
| Уровень | Claude сам | Нужно от человека 1 раз | Применимость |
|---|---|---|---|
| **1. Размножение (это видео)** | клонирует мастер-макет с подстановкой из CSV, редактируемо | дизайнер делает мастер-макет на автолейаутах | карточки SKU, серии РСЯ, SMM-серии |
| **2. Композиция (ближе к «дизайнеру-агенту»)** | официальный Figma MCP **строит новые** фреймы из **дизайн-системы** (компоненты+токены) | собрать дизайн-систему в Figma (компоненты) 1 раз | когда есть бренд-кит — собирает новые экраны сам |
| **3. Полная генерация (без Figma)** | image-gen (Nano Banana/ComfyUI) рисует с нуля по промту | ничего, но результат **не редактируемый, не бренд-точный** | разовые креативы, фоны |
> Видео = уровень 1 (mail-merge шаблона, дизайн делает человек). «Авто-дизайнер без спецов» — это уровень 2-3, и даже там бренд-систему/направление задаёт человек один раз. Полностью без подготовки = только уровень 3 (жертвуя точностью). База уровня 2 = дизайн-система клиента в токенах (эталон: `clients/avtoworld/design/design-tokens.json` + `design-system.md`).

## Когда применять Figma-MCP-метод
- ≥10-15 однотипных вариаций по шаблону с переменными (карточки SKU, баннеры серией, SMM-серия).
- Маркетплейс-карточки (Avto.world, Madwave-class), РСЯ-баннеры N товаров × форматы, серия постов.
- Нужны РЕДАКТИРУЕМЫЕ макеты + бренд-консистентность + быстрая правка.
- НЕ применять: 1-2 уникальных креатива (overkill — обычный `/ad-creative`/Figma вручную); чисто генеративная картинка без шаблона (→ image-gen bakeoff).

## Предусловия (что НУЖНО, честно)
1. **Write-capable Figma MCP** — официальный **remote** Figma MCP (Figma+Anthropic): создаёт/правит фреймы/компоненты/переменные/автолейаут. Доступен на ВСЕХ тарифах вкл. бесплатный; запись в бету бесплатна (позже платно). Ставится плагином Claude Code: `claude plugin install figma@claude-plugins-official` → авторизация Figma. Fallback на free-аккаунтах без Dev Mode: community `arinspunk/claude-talk-to-figma-mcp` (Figma plugin-bridge). Чтение макетов — наш `/figma-export` (REST). Детали setup: `~/artvision-data/personal/video-learn/2026-06-12-figma-mcp-bulk/figma-mcp-setup.md`.
2. **Мастер-макет на АВТОЛЕЙАУТАХ** (готовит дизайнер) — все переменные блоки адаптивны (плашки сами разъезжаются), подогнан под МАКСИМАЛЬНЫЕ значения параметров. Без этого серия «поедет». Каждый переменный блок — именованный слой/текст-нода.
3. **CSV-номенклатура** — строка = вариация. Колонки = переменные (название/модель/размер/сезон/цена/буллеты…). Одна колонка может влиять на НЕСКОЛЬКО параметров макета (напр. сезон → фон+иконка+цвет). Коду удобнее CSV, чем диалог.
4. **Материалы** — товарные фото/фоны/иконки (файлы), промт «что за что отвечает».

## Промт-шаблон (метод из видео)
«Ознакомься с дизайн-файлом и фреймом <N>. Создай серию фреймов, где для КАЖДОЙ строки CSV <путь> подставлены: <колонка>→<слой/текст-нода>, <колонка>→<фон+иконка+цвет (правило сезон)>… Имя фрейма = <шаблон>. Соблюди <диапазон/исключения>. Не меняй прочие слои.»

## Антипаттерны
- ❌ Генерить серию text-to-image, когда нужны редактируемые бренд-макеты (Figma-MCP точнее/правимо).
- ❌ Figma-MCP без мастер-макета на автолейаутах (серия «поедет»).
- ❌ Браузерная версия Claude для пиксельного визуала (неточно — JPEG-референс).
- ❌ Адаптировать без CSV (диалогом — путаница на 10 переменных).
- ❌ Результат без PROVENANCE-подписи (нельзя выбрать/сравнить — `model-bakeoff`).

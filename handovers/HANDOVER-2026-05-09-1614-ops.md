## 📚 Уроки (новое знание для memory)

- **Slug rename ломает 4 системы одновременно**: (1) папка clients/, (2) symlinks snapshots/latest+prev, (3) LaunchAgent Label + ProgramArguments, (4) script slug args. Кандидат-хук: `pre-client-rename.sh` который ищет все упоминания старого slug и предлагает batch-update. → `feedback_slug_rename_cascading.md`
- **TG Markdown parse ломается на `(` `)` `/` `_` в именах** — `(Иришка/Андрей К.)` не отправлялось 3 раза. Универсально: либо MarkdownV2 с escape, либо plain text mode. → дописать в `tg-send.sh` опцию `--no-parse`. → `feedback_tg_markdown_breaks_on_parens.md`
- **Sheet-vs-live ≠ удаления**: отсутствие в crawl-1000 = либо удалено, либо на странице 1000+ (yandex relevance sort). Точно удалено = только diff между snapshot'ами. → расширить `quality.md` секцией про false-positive в crawl-based детекции.
- **Replacement-pinger разделяет internal/external compose** — это правильный pattern для всех клиентов с подрядчиками (не только BluMart). → перенести в общий `orm-pulse` skill для будущих ORM-клиентов.
- **TurboText API gated by paid tier** — login есть, но API-key выдаётся только на Премиум. Аналогично с advego (XML-RPC доступен без плата, но базовая регистрация нужна). → `feedback_orm_api_keys_gated.md`

## ⚠️ Гачи (gotchas)

- **Slug = `blumart`** (не `bluemart`! rename коммит `09b3def8d` 09.05). Все скрипты теперь работают с `blumart`. Если видишь `bluemart` где-то — broken legacy.
- **Markdown в TG message** — НЕ использовать `**` `(` `)` `/` `_` в content. Используй `_safe_for_markdown()` из `replacement-pinger.py:153` или plain text.
- **playwright-full-crawl** не запускать в 2 параллельных процесса — race за `/tmp/orm-pulse-pw-blumart` profile. Если запускаешь вручную — убедись что cron не крутится.
- **Sheet snapshot symlink** `latest`/`prev` могут «провиснуть» после любого rename папки клиента. Чек: `readlink snapshots/latest`.
- **Внешним исполнителям** (биржам, копирайтерам) — НИКОГДА не упоминать в тексте: BluMart, Блюмарт, blumart.ru, reviews.yandex.ru, имена авторов из Sheet. Это правило `kp-brand.md` + `feedback_orm_executors_hidden_from_client.md`.
- **TurboText API key** ≠ password. Сейчас в `tokens.json/turbo_text` только email+password (для UI login). API-ключ выдаётся в ЛК на Премиум-тарифе отдельно.
- **TG bot @avportal_bot** теряет UTF-8 в HANDOFF лог (видно `mojibake` в `sync/HANDOFF_2026-05-09.md`) — это display-баг лога, само сообщение в TG корректное.

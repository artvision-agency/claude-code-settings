## 📋 Ключевые факты (CONFIRMED, yandex.cloud/docs 30.05.2026)

- **Причина удаления:** платёжный аккаунт в `SUSPENDED` (неоплата) или `TRIAL_EXPIRED`. После SUSPENDED — 60 дней хранения данных, но у облака свой delete-таймер.
- **Стадии:** `PENDING_DELETION` (данные живы, отмена возможна) → `DELETING` (до 72ч, отмена НЕВОЗМОЖНА, восстановления нет).
- **Грант новым:** **4000 ₽** (физлицо/юрлицо картой) или 10000 ₽ (юрлицо банк.переводом), 60 дней, один раз. «1000 ₽» — **миф, нет в офиц. источниках**.
- **Промокода-слова НЕТ** — грант начисляется автоматически при привязке карты. «Промокоды на 4000₽» на сайтах = маркетинговая подача того же гранта.
- **Free tier (0 ₽ постоянно):** Cloud Functions 1М вызовов, Object Storage 1 ГБ, DNS, API GW 100К, YDB serverless. ВМ/Managed PostgreSQL/статический IP — **НЕ бесплатны**.

4. **LOW:** Бэкап критичного наружу (Object Storage `aws s3 sync --endpoint storage.yandexcloud.net`, БД `pg_dump`, диски через yc-disk-export-tool).

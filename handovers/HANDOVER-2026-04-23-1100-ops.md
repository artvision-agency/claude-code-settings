## 📚 Уроки для memory

- **curl без JS даёт ложные отрицания на CSR-сайтах** — Revyline и MegaGen рендерят title/H1 через JS, мой исходный curl их не увидел. Playwright обязателен. → обновить `lessons.md` или создать `feedback_playwright_over_curl.md`
- **WebFetch режет head-секцию** — ненадёжен для meta-тегов. Использовать только для контент-анализа, не для SEO-метатегов. → `feedback_webfetch_limitations.md`
- **Топвизор может долго доуточнять замер** — первые данные неполные (5/28 у Стомарт), через 15-30 мин 100%. Правило: `checker/go → wait 30min → pull final`. → обновить `feedback_topvisor_checker_wait.md`
- **«Окна Века» = клиент, не формат** — я путал имена артефактов с форматами → обновить `shorthand.md` в явных клиентах
- **factcheck ДО deploy, а не после** — 3 раза за сессию вскрыл ошибки post-factum. Правило R2 (`factcheck-v2.py --standard` ПЕРЕД scp) надо поставить блокирующим хуком
- **Генераторы в scripts/, НЕ в /tmp** — при reboot /tmp очищается, /tmp/gen_dental_reports.py потерялся и пришлось пересоздавать

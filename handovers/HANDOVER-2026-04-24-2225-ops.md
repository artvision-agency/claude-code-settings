## 🧠 Решения и ПОЧЕМУ

| Решение | Альтернатива | Почему выбрали |
|---------|--------------|----------------|
| Гибрид BPMN + Event-Graph + RACI + MECE | Чистый BPMN / чистый DDD | Round-table: BPMN даёт визуализацию, DAG — зависимости, RACI — ответственных, MECE — непересечение |
| 5 типов блоков (не 10, не 3) | 10 детальных / 3 крупных | 5 покрыли 90% задач в пилоте, без overhead |
| 7 фаз (отделили DISCOVER от RESEARCH) | 5-6 фаз одним потоком | Пилот Грелки: видно сразу что задача не ready — нужен clarification BLK |
| `means` как объект с kind/ref/version/namespace | строка `skill:paid-ads` | Пилот Грелки: `paid-ads` без подварианта (yandex vs meta) не работает |
| `condition` + `branch_id` в триггере | линейная цепочка if/else в коде | Пилот Aleksandra: ветвление OK/правки не ложится в плоскую таблицу |
| `deps_mode: all\|any` | implicit AND | Пилот Aleksandra: merge-point BLK-012 = "BLK-011a OR BLK-011b" был неоднозначен |
| `overdue_by` авто-поле | ручной priority | Пилот Saodat: due=20.04, сегодня=24.04 — P0 должен считаться автоматом |
| `escalation.to: anton` дефолт | `owner.parent` | Команда 3 человека — parent-путей нет |
| Модель = markdown YAML primary, таблица = summary view | только таблица | Плоская таблица не рендерит DAG (branching + deps) |

## 📚 Уроки (новое знание для memory)

1. **Никогда не делать `git pull --rebase` на VPS без `git log` проверки расхождений** — VPS может содержать локальные коммиты которых нет в origin (нарушение R1, но факт). Сначала: `ssh root@VPS "git log --oneline origin/branch..HEAD"` чтобы увидеть VPS-only коммиты, затем `git push origin/branch` с VPS если есть, ТОЛЬКО потом `git pull --rebase`. Если push не проходит — спросить Антона. → `feedback_vps_rebase_safety.md`
2. **vitest "мёртвые тесты" из прошлых сессий могут быть живыми** — recap 6a25ae4d говорил "tests written, vitest не подключён". После `npm install vitest --save-dev` 4 ранее-мёртвых suite (handleExecCallback, parseClaudeJson, pollExecResults, queueExecTaskFromRefinement) дали 57/57 PASS. → урок: **не верить статусу "мёртвый код" без проверки** + добавь vitest в devDeps если он есть в qa-full.sh.
3. **Auto-sync hook `~/.claude/hooks/...` коммитит после Edit/Write** — мой Edit за Edit'ом не было видно в `git diff` потому что хук уже закоммитил их в `771c591`. Это OK когда работает, но "no local changes to save" может ввести в заблуждение. Знать что hook делает.
4. **bot.js 80.90.181.152 авто-удаляет webhook при старте** — `Webhook cleared` в out.log это нормально, не предупреждение. Polling работает только когда webhook URL пуст. Guard `/root/scripts/advisor-webhook-guard.sh` (cron `*/10 * * * *`) держит webhook пустым.

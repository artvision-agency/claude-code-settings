### Pre-clarify factcheck (4 источника)

| Источник | Что ищет | Условие evidence |
|---|---|---|
| `tg_responses.jsonl` (7д) | confirmed/partial ответ с keywords | classify=confirmed/partial + ≥2 kw match |
| `clients/*/context-log.md` (48ч) | строка с keywords + маркер | ≥2 kw + маркер в окне ±2 строки |
| `git log artvision-data` (48ч) | коммит с feat/fix/publish/deploy | ≥2 kw + action verb |
| `archive/*.md` | закрытые похожие запросы | ≥2 kw + confirmed/✅ |

Если evidence найден → вопрос `confirmed` с пометкой `[auto-factcheck: <источник>]`, follow-up НЕ отправляется.

## 🧠 Решения и ПОЧЕМУ

| Решение | Альтернатива | Почему |
|---|---|---|
| Telethon MTProto userbot | Bot API | Bot API не видит чужие сообщения в групповом чате |
| LaunchAgent (Mac-only) | systemd на VPS | Быстрый MVP на localhost; миграция = session-файл + telethon на VPS |
| Regex-классификатор | llm-consilium ask_auto | Дёшево, 90% случаев покрыто; LLM fallback оставлен как TODO |
| 4 источника factcheck с жёсткими условиями | 1 источник / мягкие | "Better false-negative" — лучше спросить лишний раз, чем ложно закрыть |
| ≥2 keyword match + маркер выполнения | 1 keyword | Тест показал false-positive при 1 keyword ("Tilda docx" матчился на "Avto.world статей") |
| JSONL append-only | SQLite | Диагностика грепом + совместимость с shell-пайплайнами |

## ⚠️ Гачи

- **Listener работает с session-файлом** (`~/.claude/tg-session.session`) — НЕ коммитить в git (есть в .gitignore? проверь)
- **Responder запускается каждые 120s** без `RunAtLoad` — первый запуск только через 2 минуты после load
- `git log` в `_factcheck_git_log` имеет 10s timeout — если repo большой или git hang → factcheck вернёт None, это ОК (better false-negative)
- Classifier regex чувствителен к формам глаголов — если попадёт неучтённая форма ("выложил"?), класс → ambiguous → factcheck подберёт
- **НЕ править responder/listener на лету без перезапуска** LaunchAgent:
  ```
  launchctl unload ~/Library/LaunchAgents/pro.artvision.tg-listener.plist
  launchctl load ~/Library/LaunchAgents/pro.artvision.tg-listener.plist
  ```
- **tg-send-tracked.sh — обязателен** вместо tg-send.sh для любых статус-запросов (иначе ответы не ловятся)

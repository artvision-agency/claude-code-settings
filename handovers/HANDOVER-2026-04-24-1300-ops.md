## ⚠️ Гачи

- **`/Applications/`**: `rm -rf` на любой .app даёт permission deny в Claude Code. Использовать `mv ... ~/.Trash/` + `ditto`
- **settings.json**: 720 строк, редактировать только через `Edit` с большим контекстом, риск сломать JSON
- **`inject-knowledge.sh`** НЕ включать обратно как был — сначала baseline-замер + лимиты
- **TaskCreate hook (`prompt-taskcreate-nag.sh`)** уже self-disable после первого TaskCreate — безопасно включать
- **Claude Code voice** требует Claude.ai аккаунт (не API key/Bedrock/Vertex), стримит звук на серверы Anthropic — **не локально**. Не использовать для конфиденциальных диктовок.
- **Refund request** через App Store/Google Play НЕ работает через Anthropic — сразу к Apple/Google если подписка через стор
- **Self-challenge hook**: при любых процентах/цифрах в ответах без замеров — хук ловит и требует пересмотра. Соблюдать: цифра → источник или «оценка без замера»

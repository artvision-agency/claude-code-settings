1. **ECC install conflict-check:** при копировании из `.agents/skills/` (curated bundle) проверять конфликты ИМЕННО против `.agents/skills/`, а не против `/skills/` корневой папки. У ECC два каталога с пересечениями — `claude-api` есть в обоих.
   → создать `feedback_ecc_dual_skills_dirs.md` ИЛИ дописать в `~/.claude/ecc-version.md`

2. **Telethon `tg-chat-export.py` — баг с `--since`:** скрипт передаёт `since` как `offset_date` в `client.get_messages()`. По API Telethon `offset_date` означает «получить сообщения СТАРШЕ этой даты», а не «новее». Поэтому `--since 2026-04-21` отдал сообщения только ДО 2026-04-20. Workaround: использовать `--limit N` без `--since` → возвращает последние N (свежие).
   → пофиксить `~/.claude/scripts/tg-chat-export.py:export_chat()` — заменить `offset_date` на post-фильтр по `m.date`

3. **DentalExpo контакты не были сохранены в репо** — Антон записывал их В TG Saved Messages, не в `clients/dentalexpo/`. Работа на выставке = TG-only, потом надо переносить руками.
   → правило: после любой выставки/нетворкинга — `/tg-chat-export` Saved Messages → парсить контакты → `clients/<event>/contacts/contacts.yaml`

4. **Хук `pre-client-lexicon.sh`** молча блокирует Write если в content есть запрещённое слово — `No stderr output` непонятно, надо запускать `lexicon-lint.py` руками для диагностики.

## ⚠️ Гачи (gotchas)

- **outbound-gate.sh хук блокирует multi-line bash с `scp`** → деплой делать ОДНОЙ строкой с IP 80.90.181.152 в той же строке (иначе grep -qvE срабатывает на строки без IP)
- **auto-sync хук** коммитит файлы между моими командами → часто «no changes to commit» при ручном git commit (это норма, изменения уже в репо)
- **LiteSpeed Cache на artvision.pro** — после scp визуально может быть старая версия; `curl` без кэша / wp litespeed-purge all (но purge через CLI даёт 400, не критично)
- **Verify фильтров** — через self-test mode: добавить `?test=1` query + временный скрипт что прокликивает чипы и пишет state в `<div id=test-log>`, скриншот Chrome headless. (test-script удалён из прода)
- **agent-browser** — это SKILL (`/agent-browser`), НЕ subagent_type. Через Agent tool не вызывается.

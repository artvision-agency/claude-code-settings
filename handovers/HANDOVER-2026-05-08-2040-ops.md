## 📚 Уроки (новое знание для memory)

- **Topvisor v2 API quirks** (зафиксировано в `markup-2026-05-08.md`):
  - `name` при `add/keywords_2/groups` — массив строк, не строка
  - `to_id` (не `group_id`) в `edit/keywords_2/keywords/move`
  - `del/keywords_2/groups` — НЕ `delete/`, не `remove/`
  - `IN`-фильтр работает для `del`/`get`, но `checker/go` всё равно требует EQUALS [single_id] — иначе broadcast по всем проектам и сжигание баланса (хук `pre-bash-topvisor-guard.sh`)
- **Python 3.14 + Topvisor SSL** — flaky. Если делаешь долгий цикл API-вызовов, юзай `subprocess.run(['curl',...])` или `requests` с `urllib3.Retry`. Кандидат на правило: `feedback_python_curl_for_topvisor.md`.
- **Hooks chain deadlock** — `pre-tool-recap-goal-check.sh` блокировал Bash, `pre-tool-skill-required.sh` блокировал Edit. Catch-22. Решение: первая попытка через Edit (skill-required легче проходит после Skill invocation), потом Bash. Кандидат на правило: при старте сессии **сразу** заполнять recap goal перед любым tool вызовом.
- **Auto-sync хук** — параллельно коммитит файлы (sessions/, recaps/, gantt-data.json) каждые 1-2 мин. Если делаешь свой commit — бывает гонка за `.git/index.lock`. Workaround: ретраить через `for i in 1..5; sleep 2; ...`.

## 📚 Уроки

1. **Topvisor API endpoint discovery:** `add/positions_2/searchers` + `add/positions_2/searchers_regions` (через подчёркивание!) — РАБОТАЮТ для добавления searcher и региона. Не верить старым handover'ам про "только UI".
   - **depth/region_depth ловушка:** параметр называется `region_depth` (не `depth`). Значение 1 = **TOP-100** для Яндекса (а не TOP-1!). 1→100, 2→200, 3→300 — это уровни-множители. Никогда не править если depth=1, оно уже корректное.
   - **Checker:** `edit/positions_2/checker/go` принимает `filters: [{name:"id", operator:"EQUALS", values:[project_id]}]` + `regions_indexes:[1]`
2. **SPA для аудита:** WebFetch/curl покажут "Loading..." или пустой DOM. Playwright обязателен для acteongroup.com, revyline.ru, megagen.ru. Использовать `wait_until="domcontentloaded"` (не networkidle — трекеры никогда не "молчат").
3. **Юзер говорит "интеграции настроены" → проверяй ПЕРВЫМ ДЕЛОМ.** Не описывай блокеры — пробуй варианты.
